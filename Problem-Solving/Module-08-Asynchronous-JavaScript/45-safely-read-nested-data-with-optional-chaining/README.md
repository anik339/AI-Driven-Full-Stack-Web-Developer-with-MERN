# Problem 45: Safely Read Nested Data with Optional Chaining

## Task
Read a user's city even when the address property may be missing.

## Main concept
optional chaining, ?.

## Expected output
Maya: Dhaka; Rafi: City not available.

## Explanation
?. stops property access and returns undefined when the value before it is null or undefined.

## Practice challenge
Read company?.contact?.email safely.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
