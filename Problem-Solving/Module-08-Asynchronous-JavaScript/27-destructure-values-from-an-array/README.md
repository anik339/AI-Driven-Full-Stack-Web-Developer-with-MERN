# Problem 27: Destructure Values from an Array

## Task
Extract the first three skills from an array.

## Main concept
array destructuring

## Expected output
First: HTML; Second: CSS; Third: JavaScript.

## Explanation
Array destructuring assigns values according to position. Empty commas can skip values.

## Practice challenge
Skip the first array value and store the second and third.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.

## Files
- `index.html` — lesson, output and code viewer.
- `styles.css` — page styling.
