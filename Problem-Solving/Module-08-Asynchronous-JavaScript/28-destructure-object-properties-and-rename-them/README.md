# Problem 28: Destructure Object Properties and Rename Them

## Task
Extract name and rename role to jobTitle.

## Main concept
object destructuring, alias

## Expected output
Name: Maya; Job title: Frontend Developer; City: Dhaka.

## Explanation
Object destructuring uses property names, not positions. role: jobTitle reads role into a new variable name.

## Practice challenge
Extract email from a user object and rename it to userEmail.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
