# Problem 50: Retry an Asynchronous Operation

## Task
Retry a failing operation a limited number of times until it succeeds.

## Main concept
async/await, try/catch, retry logic

## Expected output
Attempt 1 fails, attempt 2 fails, and attempt 3 succeeds.

## Explanation
Retry logic can recover from temporary failures. Use a maximum attempt count so the program does not retry forever.

## Practice challenge
Add a delay between retries and stop after four attempts.
