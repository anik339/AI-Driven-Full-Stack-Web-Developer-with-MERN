# Problem 22: Race Promises with Promise.race()

## Task
Display the result of the first Promise that settles.

## Main concept
Promise.race()

## Expected output
Fast task wins.

## Explanation
Promise.race() settles as soon as the first input Promise settles, whether fulfilled or rejected.

## Practice challenge
Race three timers with different delays and predict the winner.
