# Problem 44: Transform an Array of Objects with map()

## Task
Create an array containing only product names.

## Main concept
map(), object arrays, destructuring

## Expected output
Keyboard, Mouse, Monitor.

## Explanation
map() can use object destructuring in its callback to read only the property needed.

## Practice challenge
Create an array containing each product name and formatted price.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
