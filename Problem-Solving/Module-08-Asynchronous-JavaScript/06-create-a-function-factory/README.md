# Problem 06: Create a Function Factory

## Task
Return a function that remembers a multiplier.

## Main concept
closure, function factory

## Expected output
Double 8: 16; Triple 8: 24; Double 5: 10.

## Explanation
A factory function returns another function. Each returned function remembers its own multiplier.

## Practice challenge
Create createGreeter(name) that returns a greeting function.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
