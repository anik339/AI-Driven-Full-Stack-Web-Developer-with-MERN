# Problem 02: Lexical Scope in Nested Functions

## Task
Return a value from an inner function using an outer variable.

## Main concept
lexical environment, nested function

## Expected output
I am learning JavaScript.

## Explanation
Lexical scope means a function's variable access is determined by where the function was written, not where it is called.

## Practice challenge
Create a nested function that reads a user's name from an outer function.
