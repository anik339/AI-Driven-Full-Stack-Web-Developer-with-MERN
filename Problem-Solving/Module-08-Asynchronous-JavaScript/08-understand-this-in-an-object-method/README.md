# Problem 08: Understand this in an Object Method

## Task
Use this to read a property from the object that calls a method.

## Main concept
this, object method

## Expected output
I am Jordan, a Developer.

## Explanation
In a regular object method call, the object before the dot becomes this.

## Practice challenge
Create a car object with brand and a describe() method that uses this.brand.
