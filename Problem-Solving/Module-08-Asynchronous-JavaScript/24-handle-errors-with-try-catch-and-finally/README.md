# Problem 24: Handle Errors with try, catch and finally

## Task
Protect a calculation from invalid input and always run cleanup code.

## Main concept
try, catch, finally, throw

## Expected output
A handled division-by-zero message appears and the cleanup message is shown.

## Explanation
throw creates an error, catch handles it, and finally runs whether the operation succeeds or fails.

## Practice challenge
Change the divisor to 4 and compare successful and failed outputs.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
