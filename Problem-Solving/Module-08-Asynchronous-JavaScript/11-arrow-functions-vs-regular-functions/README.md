# Problem 11: Arrow Functions vs Regular Functions

## Task
Compare syntax and understand lexical this in arrow functions.

## Main concept
arrow function, regular function, lexical this

## Expected output
Both add functions return 10. The regular method returns Sam; the arrow method does not use user as this.

## Explanation
Arrow functions capture this from their surrounding scope. Regular functions get this from how they are called.

## Practice challenge
Rewrite a regular callback as an arrow function and compare.
