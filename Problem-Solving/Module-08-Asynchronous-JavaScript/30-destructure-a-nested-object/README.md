# Problem 30: Destructure a Nested Object

## Task
Read city and country from a nested address object.

## Main concept
nested destructuring

## Expected output
Nila lives in Dhaka, Bangladesh.

## Explanation
Nested destructuring follows the object's structure. This pattern does not create a separate address variable.

## Practice challenge
Extract company.address.city from a company object.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
