# Problem 09: Use Class Inheritance with extends and super

## Task
Create a Developer class that inherits from Employee.

## Main concept
extends, super, inheritance

## Expected output
Mia is working. Mia writes JavaScript. Is Employee: true.

## Explanation
extends creates inheritance. super(name) calls the parent constructor before using this in a derived constructor.

## Practice challenge
Create a Manager class that extends Employee and adds teamSize.

## How to run

2. Start `index.html` with the **Live Server** extension.
