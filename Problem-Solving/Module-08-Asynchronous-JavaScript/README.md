# Module 8 — Advanced and Asynchronous JavaScript — 50 JavaScript Problems

50 practical problems covering scope, closures, OOP, this, inheritance, hoisting, Promises, async/await, error handling, ES modules, destructuring, spread/rest, Fetch API, browser storage, IIFE, map/reduce, optional chaining, nullish coalescing, truthy/falsy values, event loop, debounce and retry logic.

## Study method
1. Read the task and predict the output.
2. Run `index.html` with VS Code Live Server.
3. Click **Run Solution**.
4. Read `script.js` carefully; comments explain the important lines.
5. Read the expected output and explanation.
6. Try the extra challenge without copying the solution.
