# Problem 16: Reject a Promise and Catch the Error

## Task
Reject a Promise and display its error message.

## Main concept
reject, catch, Error

## Expected output
Handled rejection: Demo data could not be loaded.

## Explanation
A rejected Promise should be handled with catch() or try/catch when using await.

## Practice challenge
Create a Promise that rejects when a number is negative.

## How to run

2. Start `index.html` with the **Live Server** extension.
