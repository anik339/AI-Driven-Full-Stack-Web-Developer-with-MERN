# Problem 33: Use Rest Parameters

## Task
Collect any number of function arguments into an array.

## Main concept
rest parameters, ...numbers, reduce

## Expected output
sum(2, 3) = 5; sum(2, 3, 4, 5) = 14.

## Explanation
Rest parameters collect remaining arguments into an array and must be the final parameter.

## Practice challenge
Create an average(...scores) function.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
