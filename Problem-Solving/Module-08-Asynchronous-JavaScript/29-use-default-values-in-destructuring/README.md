# Problem 29: Use Default Values in Destructuring

## Task
Provide fallback values when object properties are undefined.

## Main concept
destructuring defaults

## Expected output
Name: Rafi; Score: 0; City: Not provided.

## Explanation
A destructuring default is used only when the value is undefined, not when it is null.

## Practice challenge
Give a default country to a user object that has no country property.
