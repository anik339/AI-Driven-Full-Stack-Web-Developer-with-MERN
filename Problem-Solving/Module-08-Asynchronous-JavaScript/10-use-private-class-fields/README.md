# Problem 10: Use Private Class Fields

## Task
Protect a balance field using the # private-field syntax.

## Main concept
private fields, encapsulation

## Expected output
Balance: 750.

## Explanation
Private fields are accessible only inside the class body. Public methods provide controlled access.

## Practice challenge
Add withdraw() and reject withdrawals larger than the balance.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
