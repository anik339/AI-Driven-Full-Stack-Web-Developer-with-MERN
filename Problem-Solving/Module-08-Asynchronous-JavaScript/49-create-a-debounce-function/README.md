# Problem 49: Create a Debounce Function

## Task
Wait until the user stops typing before showing a search message.

## Main concept
debounce, setTimeout, clearTimeout

## Expected output
After you stop typing for 500 ms, the final search value appears.

## Explanation
Debouncing prevents a function from running too often. It is useful for search fields and resize handlers.

## Practice challenge
Change the delay to 800 ms and explain how the behaviour changes.
