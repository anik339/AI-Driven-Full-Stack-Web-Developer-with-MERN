# Problem 17: Use then(), catch() and finally()

## Task
Handle success, failure and cleanup in a Promise chain.

## Main concept
then, catch, finally

## Expected output
Two step messages appear, followed by the finally message.

## Explanation
then handles a fulfilled value, catch handles rejection, and finally runs after either outcome.

## Practice challenge
Make the second step throw an Error and observe the output.
