# Problem 03: Variable Shadowing

## Task
Use the same variable name in two separate nested scopes.

## Main concept
shadowing, block scope

## Expected output
Inside block: green; Outside block: blue.

## Explanation
Shadowing happens when an inner scope declares a variable with the same name as an outer variable.

## Practice challenge
Use the same variable name in a function and nested block, then explain each value.
