# Problem 25: Use Named Exports and Imports

## Task
Import add and subtract from a separate JavaScript module file.

## Main concept
ES modules, named export, named import

## Expected output
add(12, 5) = 17; subtract(12, 5) = 7.

## Explanation
Named exports are imported inside curly braces using the exported names. Run with VS Code Live Server.

## Practice challenge
Add multiply() to math.js and import it.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.

## Files
- `index.html` — lesson, output and code viewer.
- `styles.css` — page styling.
- `script.js` — complete JavaScript solution with comments.
- Supporting files: math.js

## Important
This problem uses ES modules. Run it through Live Server; opening index.html directly with file:// will not work.
