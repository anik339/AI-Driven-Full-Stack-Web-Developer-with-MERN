# Problem 47: Identify Truthy and Falsy Values

## Task
Convert common JavaScript values to Boolean.

## Main concept
Boolean(), truthy, falsy

## Expected output
false, zero, empty string, null, undefined and NaN are falsy. Empty arrays and objects are truthy.

## Explanation
Falsy values include false, 0, -0, 0n, empty string, null, undefined and NaN. Most other values are truthy.

## Practice challenge
Predict Boolean([]), Boolean({}), Boolean('0') and Boolean('false').
