# Problem 01: Global, Function and Block Scope

## Task
Read variables from the scopes where they are available.

## Main concept
global scope, function scope, block scope, let, const

## Expected output
Three messages are displayed from their valid scopes.

## Explanation
Global scope is broadly available. Function scope belongs to a function. let and const are block-scoped.

## Practice challenge
Create a variable inside an if block and try to access it outside.
