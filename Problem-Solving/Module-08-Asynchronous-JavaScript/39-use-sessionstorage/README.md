# Problem 39: Use sessionStorage

## Task
Store a temporary value for the current tab session.

## Main concept
sessionStorage.setItem(), getItem(), removeItem()

## Expected output
The draft appears first; after removeItem the value is null.

## Explanation
sessionStorage is scoped to a tab session and is cleared when that tab session ends.

## Practice challenge
Store a temporary checkout step in sessionStorage.
