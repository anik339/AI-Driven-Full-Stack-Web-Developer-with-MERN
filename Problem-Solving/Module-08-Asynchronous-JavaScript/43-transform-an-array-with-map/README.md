# Problem 43: Transform an Array with map()

## Task
Create a new array with a 10% tax added to every price.

## Main concept
map(), callback, new array

## Expected output
With 10% tax: 110.00, 220.00, 330.00.

## Explanation
map() returns a new array with the same number of items. Use it to transform each value.

## Practice challenge
Convert Celsius temperatures to Fahrenheit.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
