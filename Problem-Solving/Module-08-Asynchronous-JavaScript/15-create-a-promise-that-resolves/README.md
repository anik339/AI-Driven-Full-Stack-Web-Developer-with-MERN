# Problem 15: Create a Promise that Resolves

## Task
Resolve a Promise after a short delay.

## Main concept
Promise, resolve, then

## Expected output
After about half a second, the success message appears.

## Explanation
resolve() fulfils the Promise. A Promise can be pending, fulfilled or rejected.

## Practice challenge
Create a Promise that resolves with 100 after one second.
