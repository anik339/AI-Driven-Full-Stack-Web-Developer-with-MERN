# Problem 31: Copy and Merge Arrays with Spread

## Task
Merge two arrays and create a separate copy.

## Main concept
spread operator, array copy

## Expected output
Merged array has four skills; copied array has five.

## Explanation
Spread expands array values into a new array. It creates a shallow copy, not a deep copy of nested objects.

## Practice challenge
Merge two arrays of student names and remove duplicates.
