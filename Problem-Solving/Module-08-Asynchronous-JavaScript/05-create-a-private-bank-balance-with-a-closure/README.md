# Problem 05: Create a Private Bank Balance with a Closure

## Task
Expose deposit, withdraw and getBalance methods while keeping balance private.

## Main concept
closure, data privacy, factory function

## Expected output
Deposited 500; withdrew 200; balance is 1300.

## Explanation
The balance cannot be accessed directly. The returned methods form a controlled interface.

## Practice challenge
Add a method that returns the balance only if a correct PIN is supplied.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.

## Files
- `index.html` — lesson, output and code viewer.
- `styles.css` — page styling.
- `script.js` — complete JavaScript solution with comments.
- Supporting files: None
