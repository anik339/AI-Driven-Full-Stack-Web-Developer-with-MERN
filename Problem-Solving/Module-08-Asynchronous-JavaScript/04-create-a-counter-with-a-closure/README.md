# Problem 04: Create a Counter with a Closure

## Task
Create a counter that remembers its value between function calls.

## Main concept
closure, lexical environment

## Expected output
First: 1; Second: 2; Third: 3.

## Explanation
The returned function keeps access to count. This remembered outer variable is a closure.

## Practice challenge
Create two counters and prove their values are independent.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
