# Problem 21: Handle Every Result with Promise.allSettled()

## Task
Collect successful and failed results without stopping at the first rejection.

## Main concept
Promise.allSettled(), fulfilled, rejected

## Expected output
Two tasks succeed and one failure is reported.

## Explanation
Promise.allSettled() waits for every Promise and returns an outcome object for each one.

## Practice challenge
Use allSettled() for four API requests and count successful results.
