# Problem 12: Understand var Hoisting

## Task
Read a var variable before its assignment line.

## Main concept
hoisting, var

## Expected output
Before assignment: undefined; After assignment: JavaScript.

## Explanation
The var declaration is hoisted and initialized as undefined. The assignment stays on its original line.

## Practice challenge
Predict the output of a function containing var score before its assignment.
