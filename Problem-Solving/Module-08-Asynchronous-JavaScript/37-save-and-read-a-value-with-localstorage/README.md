# Problem 37: Save and Read a Value with localStorage

## Task
Save a learning goal in the browser and read it back.

## Main concept
localStorage.setItem(), getItem()

## Expected output
The learning goal is displayed from localStorage.

## Explanation
localStorage stores strings by key and persists across browser restarts for the same origin.

## Practice challenge
Save your favourite programming language and read it after reloading.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
