# Problem 46: Use Nullish Coalescing (??)

## Task
Use a fallback only when a value is null or undefined.

## Main concept
nullish coalescing, ??, falsy values

## Expected output
?? preserves 0, false and empty string; || replaces them with fallback values.

## Explanation
Use ?? when zero or false is valid. Use || when every falsy value should trigger a fallback.

## Practice challenge
Set a default page size only when pageSize is null or undefined.
