# Problem 13: Function Declaration Hoisting

## Task
Call a function declaration before the line where it appears.

## Main concept
function declaration, hoisting

## Expected output
Hello from a hoisted function declaration!

## Explanation
Function declarations are available throughout their scope. Function expressions assigned to const are not available before initialization.

## Practice challenge
Compare a function declaration with a const arrow function.
