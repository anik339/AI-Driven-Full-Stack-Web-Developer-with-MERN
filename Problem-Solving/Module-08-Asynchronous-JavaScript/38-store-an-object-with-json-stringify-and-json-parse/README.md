# Problem 38: Store an Object with JSON.stringify() and JSON.parse()

## Task
Save and restore a user profile object.

## Main concept
JSON.stringify(), JSON.parse(), localStorage

## Expected output
The restored profile values appear.

## Explanation
Storage accepts strings. Use JSON.stringify() before storing objects and JSON.parse() after reading them. Parsing invalid JSON can throw.

## Practice challenge
Store an array of three skills in localStorage.
