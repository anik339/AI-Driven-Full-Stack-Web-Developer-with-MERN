# Problem 42: Group Data with reduce()

## Task
Calculate total spending for each expense category.

## Main concept
reduce(), accumulator object

## Expected output
Food: 35, Travel: 30, Books: 25.

## Explanation
reduce() can build an object, not only a number. Return the accumulator from the callback.

## Practice challenge
Group student names by their class.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
