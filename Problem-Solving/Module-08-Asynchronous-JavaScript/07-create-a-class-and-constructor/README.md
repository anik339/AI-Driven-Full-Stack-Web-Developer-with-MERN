# Problem 07: Create a Class and Constructor

## Task
Create two Student objects from one class blueprint.

## Main concept
class, constructor, new, instance

## Expected output
Ava is studying JavaScript. Noah is studying React.

## Explanation
The constructor initializes each new object. Class methods define behaviour shared by instances.

## Practice challenge

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
