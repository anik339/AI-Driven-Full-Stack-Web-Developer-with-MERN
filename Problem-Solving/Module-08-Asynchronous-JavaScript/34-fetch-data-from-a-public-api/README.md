# Problem 34: Fetch Data from a Public API

## Task
Request three sample posts from JSONPlaceholder and display their titles.

## Main concept
fetch(), response.json(), async/await

## Expected output
Three post titles appear if the internet and demo API are available.

## Explanation
fetch() returns a Promise. Check response.ok, then call response.json() to parse the JSON body.

## Practice challenge
Fetch five users and display their names. Internet is required.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.

- `index.html` — lesson, output and code viewer.
