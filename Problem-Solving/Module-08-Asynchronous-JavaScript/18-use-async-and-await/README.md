# Problem 18: Use async and await

## Task
Wait for a Promise and display its result in readable async code.

## Main concept
async function, await

## Expected output
The message appears after approximately 600 milliseconds.

## Explanation
async makes a function return a Promise. await waits for the Promise without blocking the browser's main thread.

## Practice challenge
Write an async function that waits for two different messages.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
