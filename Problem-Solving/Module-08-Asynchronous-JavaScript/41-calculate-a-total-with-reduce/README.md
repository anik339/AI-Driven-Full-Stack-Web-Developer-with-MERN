# Problem 41: Calculate a Total with reduce()

## Task
Add every price in an array using reduce().

## Main concept
reduce(), accumulator, initial value

## Expected output
Total: 400.

## Explanation
The accumulator stores the result so far. The initial value 0 makes the sum predictable, even for an empty array.

## Practice challenge
Calculate the average of five exam scores using reduce().
