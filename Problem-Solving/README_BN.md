# Problem-Solving — ব্যবহার নির্দেশিকা

এই ফোল্ডারে Module 01 থেকে Module 08 পর্যন্ত মোট ৪০০টি topic-wise practice problem রাখা হয়েছে। প্রতিটি Module-এর আলাদা folder এবং প্রতিটি problem-এর আলাদা folder আছে।

## VS Code দিয়ে চালানোর নিয়ম

1. ZIP Extract করো।
2. `Problem-Solving` folder-টি তোমার `AI-Driven-Full-Stack-Web-Developer-with-MERN` repository-এর root-এ কপি করো।
3. VS Code দিয়ে repository ওপেন করো।
4. যে Module শিখছ, সেই Module folder খুলে 01, 02, 03 এভাবে problem folder ওপেন করো।
5. `index.html` থাকলে Live Server দিয়ে চালাও।
6. `README.md` পড়ে task বুঝে নাও।
7. `script.js` বা `style.css`-এর comment পড়ে code বোঝো।
8. শেষে নিজে challenge solve করো।

## গুরুত্বপূর্ণ

- Module 01: HTML only.
- Module 02: CSS.
- Module 03: Tailwind CSS v4; CDN ব্যবহারের জন্য internet লাগবে।
- Module 04: Responsive Design.
- Module 05: Claude Code, AI workflow এবং Git/GitHub practice.
- Module 06: JavaScript fundamentals.
- Module 07: DOM manipulation এবং Events.
- Module 08: Advanced ও Asynchronous JavaScript.

প্রতিটি problem শুধু copy করবে না। আগে নিজে চেষ্টা করবে, তারপর solution দেখে বুঝবে, পরিবর্তন করে আবার run করবে। GitHub-এ push করার আগে `git status` এবং `git diff` দেখে নেবে।
