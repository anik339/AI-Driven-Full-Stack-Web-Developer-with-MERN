# Frontend Problem Solving: 5 Modules / 5 Days / 50 Problems

This practice pack supports my learning journey toward full-stack web development with MERN.

**One day = one module = ten small exercises.** These are reference solutions to read, edit, test, and explain.

| Day | Module | Focus | Problems |
| --- | --- | --- | --- |
| Day-01 | Module 1 | HTML5 fundamentals | 01-10 |
| Day-02 | Module 2 | CSS3 fundamentals | 11-20 |
| Day-03 | Module 3 | Real compiled Tailwind CSS v4 utilities | 21-30 |
| Day-04 | Module 4 | Responsive Design, GitHub, AI review | 31-40 |
| Day-05 | Module 5 | Claude Code setup and AI-assisted HTML/CSS | 41-50 |

## Getting started

1. Open `index.html`, or open the day folder's `START_HERE.html`.
2. Open a problem's `index.html` in your browser (or VS Code Live Server).
3. Read the short English source comments explaining **what** and **why**.
4. Follow the **Try yourself** task and manually check the **Test** statement.
5. Write down the changes you really made before committing them.

## Important boundaries

- All 50 problem pages are static HTML/CSS. There is **no custom JavaScript application**.
- Forms use built-in browser validation but do not send data or connect to a backend.
- Day-03 uses genuine Tailwind-generated CSS saved locally; newly invented utility classes require a rebuild.
- Day-04 includes practice Git commands: running HTML alone does not create a branch or PR.
- Day-05 provides Claude Code rules and examples: the pages do not install Claude Code or run an assistant.
- Code can be used as a study reference. Adapt examples, test them, and describe your own work accurately.

## A manageable daily study pattern

- 15 minutes: Read the goal and comments for 2 problems.
- 30-45 minutes: Change the HTML/CSS and compare results.
- 15 minutes: Check small and large viewport widths.
- 5 minutes: Make a meaningful Git commit when you have a real change.

Ten problems per day is an organisation system, not a requirement to rush all ten in one sitting.
