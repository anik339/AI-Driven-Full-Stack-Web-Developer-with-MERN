Sticky Reading Sidebar

Make a table of contents stay in view as a reader scrolls a long article, without overlapping content.

Understanding a small website

Contents

  • Structure
  • Style
  • Responsive
  • Testing

1. Structure

Semantic HTML describes what each part of the page means. A main element marks the central content, while nav contains navigation links.

Clear headings allow both people and assistive technologies to understand sections. Use one meaningful page title and a logical heading hierarchy.

2. Style

CSS controls spacing, typography, colours, and positioning. A reusable class keeps the same style on related elements.

When a page looks wrong, inspect the box model first. Check padding, width, border, margin, and overflow.

3. Responsive design

Start with the smallest useful layout and add columns when there is enough room. Avoid fixed widths wider than the viewport.

At small widths, text should wrap and controls should remain accessible to keyboard and touch.

4. Testing

Resize the browser to 360px, 768px, and 1280px. Check links, focus outlines, scrolling, and text legibility.

Test with keyboard Tab and Enter. If the page is usable without a mouse, you have improved accessibility.
