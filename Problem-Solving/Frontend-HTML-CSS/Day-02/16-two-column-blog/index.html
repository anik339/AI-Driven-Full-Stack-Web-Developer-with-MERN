Responsive Article with Sidebar

Fix a blog layout so the sidebar moves below the main article on narrow screens.

Learning notes

What makes a page responsive?

Responsive design means the page remains useful as the available space changes. A phone, a tablet, and a laptop should all show the content in a readable order.

Begin with the content

Use headings and paragraphs to establish a meaningful document structure before adding layout rules.

Add flexible dimensions

Use percentage widths, max-width, Flexbox, Grid, and media queries when needed. Avoid forcing all content into fixed pixel dimensions.

Test at different widths

Check for horizontal overflow, clipping, inaccessible controls, and overly small text. Verify the layout with keyboard navigation too.
