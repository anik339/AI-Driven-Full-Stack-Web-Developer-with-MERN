# Day-03: Tailwind CSS

Ten reference exercises covering **Module 3**.

## Practice routine

1. Open `START_HERE.html` in VS Code with Live Server, or open it directly in a browser.
2. Try each example without changing anything first.
3. Read the short English comments beside important lines.
4. Complete **Try yourself**, then test at mobile and desktop widths.
5. Save your own changes and commit only after reviewing them.

No viva questions. No custom JavaScript exercises.

## Tailwind implementation

This day uses **real Tailwind CSS v4.1.10 utilities**, precompiled into `assets/tailwind-compiled.css`. The HTML pages reference that local CSS. You do not need Node.js, a CDN, or JavaScript to open the working examples. **If you add a new Tailwind class that is not already present in the generated CSS, it will not be styled until you regenerate the build** (or use classes already present). This is a learning snapshot, not a live Tailwind build pipeline.
