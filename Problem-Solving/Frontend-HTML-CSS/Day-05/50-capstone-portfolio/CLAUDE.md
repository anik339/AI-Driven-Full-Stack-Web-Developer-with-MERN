# Final mini portfolio: project rules

This is a beginner HTML/CSS practice project.

- Preserve semantic HTML, working anchors, and readable focus.
- Keep mobile-first styles; do not add JavaScript.
- Before editing, explain the planned changes in 2-3 bullets.
- Make small changes and show a diff.
- Never invent real work experience, deployments, or test results.
- Do not add secrets, API tokens, or personal details not supplied.
