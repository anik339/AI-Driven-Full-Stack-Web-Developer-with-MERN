# Sample beginner prompt

I have a small static HTML/CSS workshop banner in this folder.

Goal: Improve the banner layout on 360px-wide screens.

Constraints:
- Do not add JavaScript or frameworks.
- Preserve semantic HTML and links.
- Propose at most three focused CSS changes.
- Explain what each change does in simple English.

Acceptance:
- No horizontal overflow at 360px.
- Heading and link stay readable.
- Show the diff before editing the rest of the project.
