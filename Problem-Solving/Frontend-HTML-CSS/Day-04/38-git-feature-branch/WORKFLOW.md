# Branch practice (Module 4)

1. Open your real Git repository root.
2. Run `git status` and confirm you understand existing changes.
3. Run `git switch -c practice/update-board` (use a unique branch name if it exists).
4. Change one sentence in `index.html`, then save it.
5. Run `git diff` and read the actual change.
6. Stage only this file: `git add index.html` while inside this folder.
7. Commit with an accurate message.
8. Compare with `git diff main...HEAD`.
9. When ready, push your feature branch and create a PR in GitHub.

Do not force-push; do not claim a PR was merged unless you completed it.
