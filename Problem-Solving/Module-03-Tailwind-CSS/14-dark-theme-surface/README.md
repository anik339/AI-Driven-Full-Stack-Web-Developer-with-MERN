# Dark Theme Surface

## Task
Create a dark themed card using explicit dark classes.

## Main concept
dark: variant and theme colours

## Expected result
The card has light-mode defaults and dark-mode utility variants.

## Explanation
Dark mode styling is attached to dark: utilities. Browser CDN behaviour follows Tailwind's configured dark variant.

## Try it yourself
Try adding dark:border-slate-700.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
