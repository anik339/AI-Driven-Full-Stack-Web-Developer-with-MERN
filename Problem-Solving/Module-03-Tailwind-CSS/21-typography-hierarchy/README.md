# Typography Hierarchy

## Task
Style a page title, subtitle and supporting text.

## Main concept
font size, weight, tracking and leading

## Expected result
The heading stands out while supporting text remains readable.

## Explanation
Use a limited type scale and readable line-height rather than arbitrary sizes everywhere.

## Try it yourself
Try text-4xl for the heading on large screens.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
