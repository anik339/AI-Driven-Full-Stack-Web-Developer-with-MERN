# Transition and Duration

## Task
Animate a button colour change smoothly.

## Main concept
transition-colors and duration-*

## Expected result
The button colour changes smoothly on hover.

## Explanation
Choose the property to transition and use a duration that feels responsive.

## Try it yourself
Try duration-150 and compare.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
