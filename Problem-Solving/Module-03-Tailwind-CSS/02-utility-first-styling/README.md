# Utility-First Styling

## Task
Build a simple notice using small utility classes.

## Main concept
utility-first CSS approach

## Expected result
A blue information notice appears.

## Explanation
Tailwind utilities describe single styling decisions. Composing utilities creates a component without writing a new selector.

## Try it yourself
Change the colour family to emerald.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
