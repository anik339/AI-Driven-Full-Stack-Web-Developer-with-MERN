# Reusable Component Pattern

## Task
Create two consistent cards from the same utility pattern.

## Main concept
repeatable component styling

## Expected result
Both cards share the same visual structure.

## Explanation
Repeated utility patterns are candidates for components when using a framework. In static HTML, keep the markup consistent.

## Try it yourself
Create a third card named Review.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
