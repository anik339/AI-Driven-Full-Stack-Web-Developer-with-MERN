# Sizing and Min/Max Width

## Task
Constrain a content card while letting it shrink on mobile.

## Main concept
w-full, max-w-* and mx-auto

## Expected result
The card fills the available mobile width and stops growing on desktop.

## Explanation
Combine fluid width with max-width for flexible content containers.

## Try it yourself
Try max-w-md.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
