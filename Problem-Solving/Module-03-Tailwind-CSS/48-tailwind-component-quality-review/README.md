# Tailwind Component Quality Review

## Task
Review a card for readability, responsiveness and accessibility.

## Main concept
accessibility, semantic HTML and responsive review

## Expected result
The card includes image alternative text, readable text and a focus-visible link.

## Explanation
Utility classes do not automatically guarantee accessibility. Check semantics, contrast, keyboard access and responsive behaviour.

## Try it yourself
Test the card with keyboard navigation and a narrow viewport.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
