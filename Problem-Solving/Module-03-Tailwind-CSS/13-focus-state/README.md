# Focus State

## Task
Make a button visibly focused for keyboard users.

## Main concept
focus-visible and ring utilities

## Expected result
Press Tab to see a clear focus ring.

## Explanation
focus-visible: applies when the browser determines that keyboard-style focus indication is needed.

## Try it yourself
Add focus-visible:ring-offset-2.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
