# Hover State

## Task
Change a card border and shadow on hover.

## Main concept
hover: variant and transition utilities

## Expected result
The card lifts slightly and gains a shadow on hover.

## Explanation
State variants such as hover: apply styles only while the state is active.

## Try it yourself
Add hover:bg-indigo-50.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
