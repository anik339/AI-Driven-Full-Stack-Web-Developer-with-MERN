# Dark Mode Card

## Task
Create a dark-mode-aware profile panel.

## Main concept
dark mode variants and nested utility combinations

## Expected result
The profile panel includes light and dark surface/text styles.

## Explanation
Dark variants help maintain readable contrast in both themes.

## Try it yourself
Add a dark border and a hover state.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
