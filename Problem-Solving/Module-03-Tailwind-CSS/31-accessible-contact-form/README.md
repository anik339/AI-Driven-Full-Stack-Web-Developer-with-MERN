# Accessible Contact Form

## Task
Style form controls with visible labels and focus states.

## Main concept
form layout, label, border and focus ring

## Expected result
A form has readable labels and clear focus feedback.

## Explanation
Always associate labels with controls. Focus styles must remain visible for keyboard users.

## Try it yourself
Add a textarea and required attributes.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
