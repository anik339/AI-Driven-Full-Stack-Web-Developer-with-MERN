# Background and Padding

## Task
Create a coloured card with internal spacing.

## Main concept
bg-*, p-* and rounded-* utilities

## Expected result
A purple card with white text appears.

## Explanation
Background and padding utilities let you style a component quickly.

## Try it yourself
Try bg-emerald-600 and p-5.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
