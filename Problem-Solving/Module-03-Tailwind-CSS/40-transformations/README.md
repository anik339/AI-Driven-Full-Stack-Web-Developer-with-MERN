# Transformations

## Task
Rotate an icon and translate a small decorative shape.

## Main concept
rotate and translate utilities

## Expected result
The icon rotates and the text shifts slightly.

## Explanation
Transform utilities alter visual position or orientation without changing normal flow.

## Try it yourself
Remove rotate-6 and use -rotate-6.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
