# Text Colour and Weight

## Task
Create a title hierarchy with text colour and font weight.

## Main concept
text colour, font size and font weight utilities

## Expected result
The title is bold, the technology line is indigo and supporting text is muted.

## Explanation
Use text-* utilities for size and colour and font-* utilities for weight.

## Try it yourself
Make the supporting text base size.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
