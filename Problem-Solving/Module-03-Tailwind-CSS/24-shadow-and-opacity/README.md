# Shadow and Opacity

## Task
Create depth using a soft shadow and muted secondary content.

## Main concept
shadow and opacity modifiers

## Expected result
The card has depth and subdued secondary text.

## Explanation
Use shadows sparingly to establish hierarchy. Opacity modifiers can soften secondary information.

## Try it yourself
Change shadow-xl to shadow-md.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
