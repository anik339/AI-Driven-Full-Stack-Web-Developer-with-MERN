# Object Position

## Task
Control which part of an image remains visible when cropped.

## Main concept
object-cover and object-position

## Expected result
Two crops show different image positions.

## Explanation
object-position changes the focus point of a cropped image.

## Try it yourself
Try object-center.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
