# Box Shadow and Opacity

## Task
Create a badge with a soft shadow and translucent surface.

## Main concept
shadow and opacity modifiers

## Expected result
A status badge appears with a subtle shadow.

## Explanation
Small shadow and opacity changes create hierarchy without overwhelming the interface.

## Try it yourself
Add shadow-md and compare.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
