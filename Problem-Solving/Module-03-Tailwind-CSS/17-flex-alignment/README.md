# Flex Alignment

## Task
Center a call-to-action group.

## Main concept
items-center, justify-center and flex-wrap

## Expected result
The buttons are centered and wrap if space becomes limited.

## Explanation
Use flex-wrap for responsive toolbars that should not overflow.

## Try it yourself
Try justify-between inside a wider container.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
