# Positioning

## Task
Place a notification badge on an avatar.

## Main concept
relative, absolute, top/right offsets

## Expected result
A small red badge appears on the avatar's top-right corner.

## Explanation
The parent uses relative positioning; the badge is absolutely positioned inside it.

## Try it yourself
Move the badge to bottom-right.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
