# Scroll Behaviour

## Task
Add smooth scrolling to a long in-page navigation example.

## Main concept
scroll-smooth and scroll-mt-*

## Expected result
The page has clear anchor targets and smooth scrolling when enabled by the browser style.

## Explanation
Smooth scrolling can improve navigation, but respect reduced-motion preferences in a production project.

## Try it yourself
Add scroll-mt-6 to the target sections.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
