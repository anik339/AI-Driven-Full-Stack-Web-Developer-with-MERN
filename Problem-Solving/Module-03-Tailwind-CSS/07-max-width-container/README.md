# Max Width Container

## Task
Keep a long reading section comfortable on wide screens.

## Main concept
max-w-* and mx-auto

## Expected result
The article remains centered and limited in width.

## Explanation
max-w-* limits how wide an element can grow; mx-auto centers it when space is available.

## Try it yourself
Try max-w-xl and compare.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
