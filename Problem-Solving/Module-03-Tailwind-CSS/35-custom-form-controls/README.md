# Custom Form Controls

## Task
Create a checkbox row with accent colour.

## Main concept
accent-* and flex alignment

## Expected result
The checkbox has an indigo accent and aligned text.

## Explanation
Native controls can be styled lightly while preserving familiar browser interaction.

## Try it yourself
Add a second checkbox for product announcements.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
