# Responsive Dashboard

## Task
Build a simple dashboard with sidebar and content grid.

## Main concept
responsive grid with arbitrary column sizes

## Expected result
The sidebar stacks on mobile and sits beside the content on wider screens.

## Explanation
Tailwind supports arbitrary grid column values in square brackets when a custom layout is needed.

## Try it yourself
Add a third dashboard metric card.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
