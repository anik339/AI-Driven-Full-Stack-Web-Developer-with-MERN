# Cursor and Pointer Events

## Task
Show disabled interaction on a button.

## Main concept
cursor-pointer, cursor-not-allowed and disabled

## Expected result
The disabled button looks and behaves unavailable.

## Explanation
Use the disabled attribute for actual disabled behaviour; cursor utilities only change the pointer appearance.

## Try it yourself
Add opacity-60 to the disabled button.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
