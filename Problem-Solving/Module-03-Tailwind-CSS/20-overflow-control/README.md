# Overflow Control

## Task
Clip a card's image to rounded corners.

## Main concept
overflow-hidden and object-cover

## Expected result
The image stays inside the rounded card corners.

## Explanation
overflow-hidden clips child content outside the parent's box. object-cover fills the image frame.

## Try it yourself
Change object-cover to object-contain.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
