# Filters and Backdrop Blur

## Task
Create a translucent panel with backdrop blur.

## Main concept
backdrop-blur and translucent background

## Expected result
The panel has a frosted-glass appearance.

## Explanation
Backdrop filters affect what is behind an element. Keep text contrast strong.

## Try it yourself
Change backdrop-blur-md to backdrop-blur-xl.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
