# Image Filter Effects

## Task
Use grayscale and hover variants to change an image on interaction.

## Main concept
grayscale, transition and group-hover

## Expected result
The image is grayscale until the card is hovered.

## Explanation
Filter utilities can create visual emphasis. Keep the image understandable when colour is removed.

## Try it yourself
Try blur-sm and remove it on hover.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
