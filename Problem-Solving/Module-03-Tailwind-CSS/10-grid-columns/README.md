# Grid Columns

## Task
Create a three-column feature grid.

## Main concept
grid, grid-cols-* and gap-*

## Expected result
The cards become two columns at small screens and three at large screens.

## Explanation
Grid utilities define the number of columns and the gap between cells.

## Try it yourself
Add a fourth card and test the wrapping.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
