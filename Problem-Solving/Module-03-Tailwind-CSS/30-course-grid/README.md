# Course Grid

## Task
Display course cards with responsive columns.

## Main concept
grid breakpoints and card spacing

## Expected result
Course cards respond to viewport width.

## Explanation
Use responsive grid utilities to control how many columns appear at different breakpoints.

## Try it yourself
Add React as a fourth course.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
