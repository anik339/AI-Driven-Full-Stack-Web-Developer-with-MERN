# Colour Palette

## Task
Use consistent colour shades for a status message.

## Main concept
Tailwind colour scale

## Expected result
A green success message appears.

## Explanation
Tailwind colour families use shade steps such as 50, 100, 500 and 900. Keep text contrast readable.

## Try it yourself
Create a warning message with amber shades.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
