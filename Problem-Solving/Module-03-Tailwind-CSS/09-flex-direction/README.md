# Flex Direction

## Task
Stack profile content vertically on a narrow card.

## Main concept
flex-col and responsive sm:flex-row

## Expected result
The profile stacks on small screens and becomes horizontal on wider screens.

## Explanation
Tailwind responsive prefixes apply utilities at and above a breakpoint.

## Try it yourself
Change sm:flex-row to md:flex-row.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
