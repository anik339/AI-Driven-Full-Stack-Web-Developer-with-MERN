# Background Image and Overlay

## Task
Place readable text over a background image.

## Main concept
background utilities, opacity and layering

## Expected result
Text remains readable above a muted image.

## Explanation
Use an overlay to preserve contrast when placing text over imagery. Decorative images can have empty alt text.

## Try it yourself
Increase image opacity and adjust overlay strength.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
