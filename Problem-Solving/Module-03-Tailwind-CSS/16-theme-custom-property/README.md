# Theme Custom Property

## Task
Use an arbitrary value for a project-specific colour.

## Main concept
arbitrary values and opacity modifiers

## Expected result
A custom navy card appears.

## Explanation
Square-bracket syntax can express a value not included in the default scale. Prefer theme tokens for repeated values.

## Try it yourself
Replace the arbitrary value with a standard indigo shade.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
