# Margin and Space Between

## Task
Create vertical spacing between content blocks.

## Main concept
space-y-* and margin utilities

## Expected result
Three cards have equal vertical gaps.

## Explanation
space-y-* applies spacing between direct children. It keeps repeated layouts consistent.

## Try it yourself
Replace space-y-4 with space-y-2.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
