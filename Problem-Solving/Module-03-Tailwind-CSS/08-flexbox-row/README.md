# Flexbox Row

## Task
Place a logo and navigation links in one row.

## Main concept
flex, items-center, justify-between and gap

## Expected result
Brand and navigation links appear on opposite sides.

## Explanation
Flex utilities arrange items on a row or column and align them along both axes.

## Try it yourself
Add a fourth navigation link.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
