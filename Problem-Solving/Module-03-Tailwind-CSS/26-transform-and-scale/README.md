# Transform and Scale

## Task
Scale a card slightly on hover.

## Main concept
scale and transform variants

## Expected result
The card grows slightly when hovered.

## Explanation
Transforms can add feedback but should not make important content jump unexpectedly.

## Try it yourself
Use hover:-translate-y-1 instead.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
