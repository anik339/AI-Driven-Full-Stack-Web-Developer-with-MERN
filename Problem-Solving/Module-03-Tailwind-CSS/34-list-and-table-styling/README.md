# List and Table Styling

## Task
Style a list and a compact data table.

## Main concept
list-style, table width, border and padding utilities

## Expected result
The list and table are readable and aligned.

## Explanation
Tables should remain semantic; utility classes style the visual presentation but do not replace proper headers.

## Try it yourself
Add a third row and a caption.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
