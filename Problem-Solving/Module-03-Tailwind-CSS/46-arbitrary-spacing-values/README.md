# Arbitrary Spacing Values

## Task
Use a one-off spacing value and compare it with the scale.

## Main concept
arbitrary values p-[22px]

## Expected result
The card uses 22 pixels of padding.

## Explanation
Prefer the design-system scale for consistency. Use arbitrary values only when there is a clear need.

## Try it yourself
Replace p-[22px] with p-6 and compare.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
