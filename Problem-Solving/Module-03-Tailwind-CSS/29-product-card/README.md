# Product Card

## Task
Build a product card with image, rating and CTA.

## Main concept
card, image, spacing, button and hover utilities

## Expected result
A polished product card appears.

## Explanation
Keep product information, price and action clearly separated.

## Try it yourself
Add a small stock-status badge.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
