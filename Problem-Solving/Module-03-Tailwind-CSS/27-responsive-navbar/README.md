# Responsive Navbar

## Task
Build a navigation row that wraps on small screens.

## Main concept
flex-wrap, justify-between and gap

## Expected result
Navigation remains usable at narrow widths by wrapping.

## Explanation
A simple wrapping navbar is a useful starting point. A real mobile menu that collapses needs a deliberate interaction pattern.

## Try it yourself
Add a small call-to-action button to the navigation.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
