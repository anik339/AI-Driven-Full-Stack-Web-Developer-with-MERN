# Tailwind Browser Setup

## Task
Load Tailwind CSS v4 in a standalone HTML page.

## Main concept
Tailwind browser CDN and utility-first workflow

## Expected result
A white rounded card appears with spacing and a shadow.

## Explanation
The browser CDN scans the page and generates styles for the utility classes it finds. It needs an internet connection.

## Try it yourself
Change rounded-xl to rounded-2xl and compare.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
