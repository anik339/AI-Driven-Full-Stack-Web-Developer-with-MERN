# Responsive Prefixes

## Task
Change text size and padding at different breakpoints.

## Main concept
sm:, md:, lg: responsive prefixes

## Expected result
Padding and heading size increase at larger viewport widths.

## Explanation
Unprefixed utilities apply by default; prefixed utilities apply at the breakpoint and above.

## Try it yourself
Add md:text-3xl to the heading.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
