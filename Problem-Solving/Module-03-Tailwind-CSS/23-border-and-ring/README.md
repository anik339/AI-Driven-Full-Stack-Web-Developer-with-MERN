# Border and Ring

## Task
Highlight a selected option with a border and ring.

## Main concept
border-* and ring-*

## Expected result
The selected plan has a clear highlighted boundary.

## Explanation
Borders define component edges; ring utilities create an outline-like shadow around an element.

## Try it yourself
Create an unselected state with a slate border.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
