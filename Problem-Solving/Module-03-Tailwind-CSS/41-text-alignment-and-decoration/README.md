# Text Alignment and Decoration

## Task
Use alignment and decoration utilities for links and headings.

## Main concept
text-center, underline and decoration utilities

## Expected result
Heading and paragraph are centered; link underline is clearly visible.

## Explanation
Text decoration can improve link recognition. Do not remove underlines without another clear visual cue.

## Try it yourself
Change text-center to text-left.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
