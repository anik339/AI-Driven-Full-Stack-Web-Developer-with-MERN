# Tailwind Build Workflow

## Task
Read a small local build setup checklist.

## Main concept
package.json, CLI build and generated CSS

## Expected result
A four-step build checklist appears.

## Explanation
The CDN is convenient for learning. Production projects should use a local build workflow so CSS can be optimized and versioned.

## Try it yourself
Open the module's BUILD_GUIDE.md and identify the build command.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
