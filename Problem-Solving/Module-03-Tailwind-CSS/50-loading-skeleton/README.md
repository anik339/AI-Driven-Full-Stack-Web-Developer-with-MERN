# Loading Skeleton

## Task
Create a simple loading placeholder using animate-pulse.

## Main concept
animate-pulse and skeleton placeholders

## Expected result
A set of pulsing placeholder blocks appears.

## Explanation
Skeletons communicate loading state while content is being prepared. Avoid using animation for long periods or ignoring reduced-motion preferences.

## Try it yourself
Add a circular avatar placeholder using size-12 and rounded-full.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
