# Aspect Ratio Media

## Task
Keep a video preview in a consistent aspect ratio.

## Main concept
aspect-video and object-cover

## Expected result
The media frame stays 16:9.

## Explanation
Aspect ratio utilities preserve a consistent shape while the container changes size.

## Try it yourself
Try aspect-square.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
