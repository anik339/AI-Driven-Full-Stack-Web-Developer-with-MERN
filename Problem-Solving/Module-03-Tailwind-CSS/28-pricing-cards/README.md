# Pricing Cards

## Task
Create three pricing cards using responsive grid.

## Main concept
responsive grid and card composition

## Expected result
Three pricing cards stack on mobile and align in columns on wider screens.

## Explanation
Use the same spacing and type scale across cards. Highlight one plan without hiding important information.

## Try it yourself
Add a feature list to each pricing card.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
