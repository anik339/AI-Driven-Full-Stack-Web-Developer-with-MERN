# Spacing Scale

## Task
Build a card using consistent spacing utilities.

## Main concept
p-*, mt-*, space-y-* and tracking-*

## Expected result
Content has consistent vertical spacing.

## Explanation
Tailwind's spacing scale encourages repeatable layout values.

## Try it yourself
Reduce the card padding to p-4.

## How to run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server.
3. Make sure the browser has an internet connection so Tailwind CSS v4 can load.
4. Read the class names and change one utility at a time.
5. Try the challenge and compare the mobile and desktop layouts.
