# Module 03 — Tailwind CSS — 50 Problems

50 Tailwind CSS v4 problems covering utility-first styling, spacing, colours, typography, Flexbox, Grid, responsive prefixes, hover/focus states, forms, cards, dashboards, theme variants and component review.

## How to practise

Open each `index.html` with Live Server. Tailwind v4 loads from its browser CDN, so an internet connection is required.

## Recommended routine
1. Read the problem statement before opening the solution.
2. Predict what the page or code will do.
3. Run the provided solution and compare the result.
4. Read the code comments and explain the important lines in your own words.
5. Complete the challenge without copying the solution.
6. Commit your completed work to GitHub with a clear message.
