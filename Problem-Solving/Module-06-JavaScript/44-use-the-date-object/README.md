# Use the Date Object

## Task
Read the current date and format year, month and day.

## Main concept
Date constructor and date getters

## Expected result
The current local date appears in YYYY-MM-DD format.

## Explanation
getMonth() returns a zero-based month, so add one for the human-readable month number.

## Try it yourself
Display the current hour and minute.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
