# Use else if for Multiple Ranges

## Task
Convert a numeric score into a grade.

## Main concept
if, else if and else

## Expected result
Score 82 → Grade B.

## Explanation
Conditions are checked from top to bottom. Put the most restrictive higher ranges first.

## Try it yourself
Test scores 95, 75, 60 and 42.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
