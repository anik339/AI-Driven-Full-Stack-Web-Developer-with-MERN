# Use Assignment and Increment Operators

## Task
Update a running score using assignment operators.

## Main concept
=, +=, *=, -= and ++

## Expected result
Final score: 27.

## Explanation
Compound assignment updates the current variable using the selected operation.

## Try it yourself
Start at 20 and use -=, /= and ++ to reach a new result.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
