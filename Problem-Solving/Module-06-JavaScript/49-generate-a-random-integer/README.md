# Generate a Random Integer

## Task
Generate a random whole number from 1 to 10.

## Main concept
Math.random and Math.floor

## Expected result
A whole number from 1 through 10 appears.

## Explanation
Math.random() returns a value from 0 inclusive to 1 exclusive. Multiply and floor to create a range.

## Try it yourself
Generate a random integer from 20 to 50.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
