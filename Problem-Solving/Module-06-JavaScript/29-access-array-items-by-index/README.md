# Access Array Items by Index

## Task
Read the first and last items of an array.

## Main concept
zero-based array index

## Expected result
First: red; Last: purple

## Explanation
Array indexes start at zero. The last index is length minus one.

## Try it yourself
Read the second item and the third item.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
