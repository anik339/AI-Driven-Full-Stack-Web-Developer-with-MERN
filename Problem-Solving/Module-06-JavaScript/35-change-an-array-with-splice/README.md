# Change an Array with splice

## Task
Remove and insert array items at a chosen position.

## Main concept
splice() mutating method

## Expected result
Updated: Apple, Mango, Orange; Removed: Banana

## Explanation
splice() changes the original array by removing, replacing or inserting items.

## Try it yourself
Insert Pineapple at index 1 without removing anything.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
