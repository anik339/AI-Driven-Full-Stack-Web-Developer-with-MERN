# Use parseInt and parseFloat

## Task
Extract an integer and decimal number from strings.

## Main concept
parseInt(), parseFloat() and radix

## Expected result
Integer: 42; Decimal: 19.95

## Explanation
parseInt reads an integer prefix and should usually receive radix 10. parseFloat reads a decimal prefix.

## Try it yourself
Try parseInt('08') with radix 10 and compare.
