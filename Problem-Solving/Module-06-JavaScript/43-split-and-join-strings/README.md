# Split and Join Strings

## Task
Convert a comma-separated list into an array and back.

## Main concept
split() and join()

## Expected result
Items: 4; HTML | CSS | JavaScript | React

## Explanation
split() turns a string into an array; join() combines array items into a string.

## Try it yourself
Split a full name into first and last names.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
