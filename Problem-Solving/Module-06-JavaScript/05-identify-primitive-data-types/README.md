# Identify Primitive Data Types

## Task
Create string, number, boolean, undefined, null and bigint values.

## Main concept
primitive data types and typeof

## Expected result
The output shows string, number, boolean, undefined, object for null, and bigint.

## Explanation
JavaScript has several primitive types. typeof null returns 'object' for historical reasons; null is still a primitive value.

## Try it yourself
Add a Symbol value and inspect its typeof result.
