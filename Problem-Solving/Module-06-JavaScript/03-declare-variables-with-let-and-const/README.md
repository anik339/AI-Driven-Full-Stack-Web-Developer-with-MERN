# Declare Variables with let and const

## Task
Store a learner name and course name in variables.

## Main concept
let and const

## Expected result
Anik is studying Data Types.

## Explanation
Use const by default. Use let when you need to reassign a variable. Avoid var in modern code unless you understand its scope rules.

## Try it yourself
Create a const country and a let currentYear.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
