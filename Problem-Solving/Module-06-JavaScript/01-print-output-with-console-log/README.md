# Print Output with console.log

## Task
Print a message in the browser developer console and on the lesson page.

## Main concept
console.log and output values

## Expected result
Hello, JavaScript!

## Explanation
console.log() is a useful way to inspect values while learning and debugging. The output element displays the same result on the page.

## Try it yourself
Change the message to introduce yourself.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
