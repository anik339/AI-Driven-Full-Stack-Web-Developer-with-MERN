# Combine Conditions with Logical Operators

## Task
Check whether a learner qualifies for a certificate.

## Main concept
&&, || and !

## Expected result
Qualifies: true; Needs review: false.

## Explanation
&& requires both conditions to be true. || requires at least one. ! reverses a Boolean value.

## Try it yourself
Add a third condition requiring all assignments to be submitted.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
