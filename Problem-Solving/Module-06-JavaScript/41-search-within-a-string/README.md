# Search Within a String

## Task
Check whether a sentence contains a word.

## Main concept
includes(), startsWith() and endsWith()

## Expected result
All three checks return true.

## Explanation
String search methods return Boolean results and are case-sensitive.

## Try it yourself
Check whether an email ends with .com.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
