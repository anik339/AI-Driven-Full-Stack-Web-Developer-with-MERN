# Add Items with push and Remove with pop

## Task
Add a skill and remove the last skill.

## Main concept
push() and pop()

## Expected result
Skills: HTML, CSS; Removed: JavaScript

## Explanation
push() adds one or more items to the end. pop() removes and returns the last item.

## Try it yourself
Use push() to add two skills and pop() once.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
