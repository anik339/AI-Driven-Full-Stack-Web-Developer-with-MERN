# Convert Strings to Numbers

## Task
Convert numeric text using Number and handle invalid input.

## Main concept
Number() and Number.isNaN()

## Expected result
Price: 149.5; Invalid result: NaN; Is invalid NaN: true.

## Explanation
Number() converts a numeric string to a number. Invalid numeric text becomes NaN.

## Try it yourself
Convert an empty string and a whitespace-only string and explain the results.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
