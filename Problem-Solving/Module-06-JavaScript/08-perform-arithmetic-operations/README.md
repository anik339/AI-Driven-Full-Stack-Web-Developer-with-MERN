# Perform Arithmetic Operations

## Task
Calculate the total price and remainder.

## Main concept
addition, subtraction, multiplication, division and modulo

## Expected result
Total price: 375; remainder: 2.

## Explanation
The modulo operator % returns the remainder after division.

## Try it yourself
Calculate a 10% discount on a product price.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
