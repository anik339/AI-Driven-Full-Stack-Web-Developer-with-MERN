# Find an Item and Test Conditions

## Task
Use find, some and every on a product list.

## Main concept
find(), some() and every()

## Expected result
Found Keyboard; expensive item exists true; all prices valid true.

## Explanation
find() returns the first match. some() checks whether at least one item passes. every() checks whether all items pass.

## Try it yourself
Find the first score below 40 and test whether all scores are positive.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
