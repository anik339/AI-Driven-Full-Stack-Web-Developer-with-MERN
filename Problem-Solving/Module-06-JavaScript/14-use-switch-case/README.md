# Use switch...case

## Task
Display a message based on a selected day.

## Main concept
switch, case, break and default

## Expected result
Wednesday

## Explanation
switch compares one expression against case values. break prevents execution from falling through to the next case.

## Try it yourself
Add Saturday and Sunday cases.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
