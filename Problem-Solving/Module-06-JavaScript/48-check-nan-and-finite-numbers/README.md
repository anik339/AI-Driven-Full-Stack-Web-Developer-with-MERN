# Check NaN and Finite Numbers

## Task
Validate numeric results before using them.

## Main concept
Number.isNaN and Number.isFinite

## Expected result
25 is finite; NaN is not finite; Infinity is not finite; string '25' is not a number.

## Explanation
Number.isFinite() checks whether a value is an actual finite number without coercing strings.

## Try it yourself
Convert the string first, then check if it is finite.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
