# Pass Function Parameters

## Task
Send a name into a greeting function.

## Main concept
parameters and arguments

## Expected result
Hello, Anik!

## Explanation
A parameter is the variable in the function definition; an argument is the value passed when calling the function.

## Try it yourself
Pass two different names to the same function.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
