# Filter an Array

## Task
Keep only numbers greater than or equal to 50.

## Main concept
filter()

## Expected result
Passed scores: 72, 90, 55

## Explanation
filter() returns a new array with items that pass the callback test.

## Try it yourself
Filter a list of products to show prices under 100.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
