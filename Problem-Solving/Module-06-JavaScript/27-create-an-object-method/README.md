# Create an Object Method

## Task
Add a method that uses this to describe an object.

## Main concept
object methods and this

## Expected result
Toyota Corolla

## Explanation
When a regular method is called as car.describe(), this refers to car.

## Try it yourself
Add a year property and include it in describe().

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
