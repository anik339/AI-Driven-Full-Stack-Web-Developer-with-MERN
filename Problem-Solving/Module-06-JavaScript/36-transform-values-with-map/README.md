# Transform Values with map

## Task
Create a new array with prices including tax.

## Main concept
map()

## Expected result
110.00, 220.00, 330.00

## Explanation
map() returns a new array containing the result of calling the callback for each item.

## Try it yourself
Convert a list of Celsius temperatures to Fahrenheit.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
