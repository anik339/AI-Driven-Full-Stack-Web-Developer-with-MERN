# Use a do...while Loop

## Task
Run a block once before checking its condition.

## Main concept
do...while loop

## Expected result
Attempt 1, Attempt 2, Attempt 3

## Explanation
do...while always runs the body at least once because the condition is checked afterward.

## Try it yourself
Set attempt to 5 and see whether the body still runs once.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
