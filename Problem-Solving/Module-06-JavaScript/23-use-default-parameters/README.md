# Use Default Parameters

## Task
Provide a default country when no argument is supplied.

## Main concept
default function parameters

## Expected result
Anik is from Bangladesh. Maya is from India.

## Explanation
A default parameter is used when the argument is missing or undefined.

## Try it yourself
Create a function with a default role of Student.
