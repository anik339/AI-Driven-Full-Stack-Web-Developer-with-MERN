# Slice, Replace and Trim a String

## Task
Clean a user-entered name and replace a word.

## Main concept
trim(), replace() and slice()

## Expected result
Whitespace is removed, anik is replaced with Anik, and the first four characters are shown.

## Explanation
trim() removes whitespace from both ends. replace() returns a new string. slice() extracts a portion.

## Try it yourself
Clean an email value and convert it to lowercase.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
