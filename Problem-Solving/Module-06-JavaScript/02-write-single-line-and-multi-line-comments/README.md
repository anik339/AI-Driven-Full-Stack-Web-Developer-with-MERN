# Write Single-Line and Multi-Line Comments

## Task
Add comments that explain why code is written.

## Main concept
// and /* */ comments

## Expected result
Topic: Comments; Comments are not executed.

## Explanation
Comments help a future reader understand intent. Avoid comments that merely repeat obvious code.

## Try it yourself
Write a comment explaining why a variable is const.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
