# Loop Through an Array with for...of

## Task
Visit each item in a skills array.

## Main concept
for...of iterable loop

## Expected result
Three sentences, one for each skill.

## Explanation
for...of reads values from an iterable such as an array or string.

## Try it yourself
Loop through a list of prices and display each one.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
