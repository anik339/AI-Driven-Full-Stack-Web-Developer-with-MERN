# Return a Value from a Function

## Task
Create a function that calculates a rectangle area.

## Main concept
return statement

## Expected result
Area: 40

## Explanation
return sends a value back to the caller and ends that function execution.

## Try it yourself
Create calculatePerimeter(width, height).

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
