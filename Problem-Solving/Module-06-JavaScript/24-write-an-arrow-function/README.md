# Write an Arrow Function

## Task
Convert a simple function into arrow-function syntax.

## Main concept
arrow functions and implicit return

## Expected result
Multiply: 24; Square: 49

## Explanation
Arrow functions offer concise syntax. A single expression can be returned implicitly when braces are omitted.

## Try it yourself
Write an arrow function that converts minutes to seconds.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
