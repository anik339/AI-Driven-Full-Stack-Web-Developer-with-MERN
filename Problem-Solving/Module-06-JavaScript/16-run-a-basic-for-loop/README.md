# Run a Basic for Loop

## Task
Print the numbers from 1 through 5.

## Main concept
for loop initialization, condition and update

## Expected result
1, 2, 3, 4, 5

## Explanation
A for loop repeats while its condition remains true. The update expression changes the counter after each iteration.

## Try it yourself
Print even numbers from 2 to 20.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
