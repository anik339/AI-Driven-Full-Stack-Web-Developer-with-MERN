# Calculate a Shopping Cart Total

## Task
Combine arrays, objects, loops and arithmetic to calculate a cart.

## Main concept
array of objects, map(), reduce() and arithmetic

## Expected result
Keyboard 35; Mouse 40; USB Cable 24; Grand total 99.

## Explanation
A cart is naturally represented as an array of objects. map() formats each line; reduce() calculates one total.

## Try it yourself
Add a 5% tax and display the final amount.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
