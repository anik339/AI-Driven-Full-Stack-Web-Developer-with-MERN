# Loop Through Object Keys with for...in

## Task
Read each key and value from an object.

## Main concept
for...in object property keys

## Expected result
name: Ava; role: Developer; city: Dhaka

## Explanation
for...in iterates enumerable property keys. Use Object.hasOwn() if inherited properties must be excluded.

## Try it yourself
Use Object.entries() to create the same output.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
