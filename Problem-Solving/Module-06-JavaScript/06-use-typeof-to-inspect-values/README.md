# Use typeof to Inspect Values

## Task
Print the type of several values.

## Main concept
typeof operator

## Expected result
The output lists string, number, boolean, undefined, object, object and function.

## Explanation
typeof is useful for quick inspection, but arrays and null both return 'object'. Use Array.isArray() to check arrays.

## Try it yourself
Add null and Array.isArray([1,2]) to the example.
