# Compare Values

## Task
Use strict comparison operators to compare two scores.

## Main concept
comparison operators and strict equality

## Expected result
A > B is true; A === B is false; A !== B is true.

## Explanation
Comparison operators return Boolean values. Prefer === and !== to avoid unexpected type conversion.

## Try it yourself
Compare a string number '10' with the number 10 using == and ===.

## How to run

2. Open `index.html` with Live Server.
