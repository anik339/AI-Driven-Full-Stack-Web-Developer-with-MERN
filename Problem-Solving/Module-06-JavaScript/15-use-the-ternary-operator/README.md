# Use the Ternary Operator

## Task
Choose a message with a short conditional expression.

## Main concept
conditional (ternary) operator

## Expected result
Welcome back!

## Explanation
The ternary operator is useful for a simple two-way choice. Avoid deeply nested ternaries because they become hard to read.

## Try it yourself
Create a ternary that labels a score as pass or fail.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
