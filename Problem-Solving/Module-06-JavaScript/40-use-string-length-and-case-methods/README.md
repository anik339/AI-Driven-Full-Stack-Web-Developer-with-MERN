# Use String Length and Case Methods

## Task
Read a string's length and change its letter case.

## Main concept
length, toUpperCase and toLowerCase

## Expected result
Length: 10; Upper: JAVASCRIPT; Lower: javascript

## Explanation
Strings are immutable. Methods return new strings rather than changing the original.

## Try it yourself
Convert a user's name to title case.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
