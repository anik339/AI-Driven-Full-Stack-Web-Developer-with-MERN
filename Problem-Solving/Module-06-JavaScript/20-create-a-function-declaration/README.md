# Create a Function Declaration

## Task
Write a reusable function that greets a learner.

## Main concept
function declaration and function call

## Expected result
Hello, learner! Keep practising.

## Explanation
A function declaration defines reusable behaviour. Call the function to execute its body.

## Try it yourself
Create a function named showWelcome that returns a welcome message.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
