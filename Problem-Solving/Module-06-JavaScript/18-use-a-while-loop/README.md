# Use a while Loop

## Task
Repeat a counter while it is less than or equal to five.

## Main concept
while loop

## Expected result
1 → 2 → 3 → 4 → 5

## Explanation
A while loop checks the condition before each iteration. Update the condition variable to avoid an infinite loop.

## Try it yourself
Count down from 5 to 1.
