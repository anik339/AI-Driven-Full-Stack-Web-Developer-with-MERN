# Use break and continue

## Task
Skip one number and stop the loop at a limit.

## Main concept
break and continue

## Expected result
1, 2, 4, 5, 6, 7

## Explanation
continue skips the current iteration. break exits the loop completely.

## Try it yourself
Skip all odd numbers and stop after 20.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
