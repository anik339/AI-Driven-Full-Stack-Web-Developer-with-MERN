# Module 06 — JavaScript Foundations — 50 Problems

50 JavaScript fundamentals problems covering variables, data types, operators, conditions, switch, loops, functions, parameters, return values, objects, arrays, array methods, strings, Date, Math and number conversion.

## How to practise

Open each `index.html` with Live Server. Click Run Solution, read `script.js`, then solve the challenge yourself.

## Recommended routine
1. Read the problem statement before opening the solution.
2. Predict what the page or code will do.
3. Run the provided solution and compare the result.
4. Read the code comments and explain the important lines in your own words.
5. Complete the challenge without copying the solution.
6. Commit your completed work to GitHub with a clear message.
