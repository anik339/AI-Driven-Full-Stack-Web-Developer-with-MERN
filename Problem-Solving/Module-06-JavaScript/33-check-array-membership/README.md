# Check Array Membership

## Task
Use includes and indexOf to find a value.

## Main concept
includes() and indexOf()

## Expected result
Has Git: true; Chrome index: 1; Firefox index: -1

## Explanation
includes() returns a Boolean. indexOf() returns the first index or -1 when not found.
