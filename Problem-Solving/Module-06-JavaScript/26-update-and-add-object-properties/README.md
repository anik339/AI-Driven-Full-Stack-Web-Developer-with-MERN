# Update and Add Object Properties

## Task
Change an object property and add a new one.

## Main concept
object property assignment

## Expected result
The product price becomes 32 and inStock becomes true.

## Explanation
Objects are mutable. Dot notation can update an existing property or add a new one.

## Try it yourself
Add a category property.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
