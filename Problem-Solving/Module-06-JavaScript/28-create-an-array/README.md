# Create an Array

## Task
Store a list of skills and read its length.

## Main concept
array literal and length

## Expected result
Skills: HTML, CSS, JavaScript, React; Count: 4

## Explanation
An array stores an ordered collection. Its length property reports the number of items.

## Try it yourself
Add Node.js as a fifth skill.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
