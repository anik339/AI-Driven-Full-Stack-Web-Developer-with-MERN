# Use Template Literals

## Task
Build a sentence from variables using backticks.

## Main concept
template literals and interpolation

## Expected result
Rafi is learning JavaScript in lesson 6.

## Explanation
Template literals use backticks and ${expression} to insert values into a string.

## Try it yourself
Create a sentence with your name, current module and favourite topic.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
