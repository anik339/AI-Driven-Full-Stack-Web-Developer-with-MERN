# Responsive Disclosure Panel

## Task
Create a help panel that stays readable on mobile and desktop.

## Main concept
native details with responsive spacing

## Expected result
The panel expands with readable text and increased padding on wider screens.

## Explanation
Native disclosure elements are keyboard accessible and avoid hover-only interactions.

## Try it yourself
Add a second details panel and ensure the two panels have consistent spacing.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
