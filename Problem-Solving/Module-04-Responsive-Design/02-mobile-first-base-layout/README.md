# Mobile-First Base Layout

## Task
Start with one column and enhance the layout for wider screens.

## Main concept
mobile-first CSS and min-width media query

## Expected result
Cards stack on mobile and become three columns on wider screens.

## Explanation
Write the base mobile layout first. Add a min-width query when more space is available.

## Try it yourself
Change the breakpoint from 700px to 600px.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
