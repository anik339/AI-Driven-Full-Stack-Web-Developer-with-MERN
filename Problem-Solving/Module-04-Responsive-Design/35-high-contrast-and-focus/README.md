# High Contrast and Focus

## Task
Keep focus outlines visible and avoid relying only on colour.

## Main concept
focus-visible and contrast

## Expected result
Controls have visible boundaries and keyboard focus indicators.

## Explanation
Colour contrast and visible focus help people with low vision and keyboard-only navigation.

## Try it yourself
Test the page using only Tab, Shift+Tab and Enter.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
