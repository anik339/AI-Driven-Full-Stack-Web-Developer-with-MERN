# Orientation Query

## Task
Adjust a landscape layout when the device is in portrait orientation.

## Main concept
orientation media feature

## Expected result
The card changes layout in landscape orientation.

## Explanation
Orientation queries can help in a few specific layouts, but width-based responsive design is usually more reliable.

## Try it yourself
Test the same layout at different widths without rotating.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
