# Container Query Basics

## Task
Adapt a component to its own container width.

## Main concept
container-type and @container

## Expected result
The card changes from stacked to horizontal when its parent is wide enough.

## Explanation
Container queries are useful when a component may be placed in different-width regions of the same page.

## Try it yourself
Place the card in two containers of different widths.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
