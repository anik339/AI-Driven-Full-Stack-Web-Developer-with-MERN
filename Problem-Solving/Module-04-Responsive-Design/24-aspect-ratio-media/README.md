# Aspect Ratio Media

## Task
Keep a video preview at a 16:9 ratio.

## Main concept
aspect-ratio and object-fit

## Expected result
The video preview keeps a consistent widescreen ratio.

## Explanation
aspect-ratio defines the width-to-height relationship; object-fit fills the frame.

## Try it yourself
Change the ratio to 4 / 3.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
