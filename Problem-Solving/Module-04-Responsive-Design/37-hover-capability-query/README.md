# Hover Capability Query

## Task
Apply hover styling only when the device supports convenient hover.

## Main concept
hover and pointer media features

## Expected result
Hover styling is applied only on devices with a fine hover pointer.

## Explanation
Touch devices do not always have hover. Do not make essential actions available only on hover.

## Try it yourself
Add a focus-visible state so keyboard users receive equivalent feedback.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
