# Responsive Footer

## Task
Stack footer columns on mobile and align them on desktop.

## Main concept
responsive footer grid

## Expected result
Footer sections stack on mobile and become columns on desktop.

## Explanation
Keep footer links easy to scan and maintain adequate touch spacing.

## Try it yourself
Add a fourth column for legal links.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
