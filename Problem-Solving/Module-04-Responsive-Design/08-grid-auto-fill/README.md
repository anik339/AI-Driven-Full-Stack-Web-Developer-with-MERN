# Grid Auto-Fill

## Task
Compare auto-fill behaviour in a grid.

## Main concept
auto-fill and minmax

## Expected result
The grid creates available tracks even when there are fewer cards.

## Explanation
auto-fill preserves empty tracks while auto-fit collapses them, allowing existing items to expand.

## Try it yourself
Replace auto-fill with auto-fit and compare a wide screen.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
