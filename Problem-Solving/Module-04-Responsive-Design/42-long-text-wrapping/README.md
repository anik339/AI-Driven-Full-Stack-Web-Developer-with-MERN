# Long Text Wrapping

## Task
Prevent long words and URLs from breaking a mobile layout.

## Main concept
overflow-wrap and min-width

## Expected result
The long URL wraps inside the card.

## Explanation
Use overflow-wrap for unbroken strings that could cause horizontal scrolling.

## Try it yourself
Try word-break: break-all and compare readability.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
