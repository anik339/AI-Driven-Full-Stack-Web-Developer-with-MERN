# Tablet Breakpoint

## Task
Create a two-column layout for medium screens.

## Main concept
tablet breakpoint and grid

## Expected result
The menu moves beside the content on tablet and desktop widths.

## Explanation
Choose breakpoints based on where the content needs more room, not on specific device models.

## Try it yourself
Test at 680px and 720px and note the change.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
