# Responsive Card Grid

## Task
Create cards that automatically fit available space.

## Main concept
auto-fit and minmax

## Expected result
Cards automatically rearrange based on available width.

## Explanation
This pattern avoids multiple hard-coded breakpoints for simple card grids.

## Try it yourself
Change the minimum card width to 260px.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
