# Viewport Meta Tag

## Task
Set the viewport so mobile browsers use the device width.

## Main concept
viewport meta tag and device-width

## Expected result
The page scales to the device width instead of appearing zoomed out.

## Explanation
The viewport meta tag is essential for mobile layout calculations. It belongs in the document head.

## Try it yourself
Remove the viewport meta tag and compare the mobile preview.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
