# Split Screen to Stacked Layout

## Task
Stack a two-panel layout on narrow screens.

## Main concept
responsive split layout

## Expected result
Two panels stack on mobile and align side-by-side on desktop.

## Explanation
Use a one-column base layout for narrow screens and add two columns when both panels fit.

## Try it yourself
Add a third panel and make it span both columns on desktop.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
