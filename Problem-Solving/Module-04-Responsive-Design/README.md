# Module 04 — Responsive Design — 50 Problems

50 responsive design problems covering mobile-first layouts, breakpoints, fluid containers, clamp(), Flexbox, Grid, responsive images, forms, tables, navigation, sidebars, dashboards, media queries, reduced motion, print styles and final page composition.

## How to practise

Open each `index.html` with Live Server. Test at 320px, 375px, 768px, 1024px and 1280px using browser DevTools.

## Recommended routine
1. Read the problem statement before opening the solution.
2. Predict what the page or code will do.
3. Run the provided solution and compare the result.
4. Read the code comments and explain the important lines in your own words.
5. Complete the challenge without copying the solution.
6. Commit your completed work to GitHub with a clear message.
