# Touch Target Size

## Task
Make buttons comfortable to tap on a touch screen.

## Main concept
minimum touch target size and spacing

## Expected result
Buttons have a larger tap area and space between them.

## Explanation
Touch controls should be large enough and separated enough to reduce accidental activation.

## Try it yourself
Test the controls at 200% zoom.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
