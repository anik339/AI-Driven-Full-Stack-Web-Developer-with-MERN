# Responsive Video Embed

## Task
Keep an embedded video frame responsive.

## Main concept
aspect-ratio for embedded media

## Expected result
The iframe keeps a 16:9 ratio as the width changes.

## Explanation
Give every iframe a descriptive title. A wrapper with aspect-ratio prevents a fixed-height video from overflowing.

## Try it yourself
Change the ratio to 4:3 and compare.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
