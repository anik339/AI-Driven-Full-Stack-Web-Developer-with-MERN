# Dashboard Responsive Layout

## Task
Create a dashboard that changes from one to three metric columns.

## Main concept
progressive grid breakpoints

## Expected result
Metrics show one, two or three columns as the screen grows.

## Explanation
Add breakpoints only where the cards need more horizontal space.

## Try it yourself
Add a fourth metric and test the grid.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
