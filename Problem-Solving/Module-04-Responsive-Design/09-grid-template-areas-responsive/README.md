# Grid Template Areas Responsive

## Task
Rearrange header, sidebar and content for mobile.

## Main concept
grid-template-areas and media queries

## Expected result
Mobile layout stacks; desktop layout places sidebar beside content.

## Explanation
Named areas make layout changes readable and maintainable.

## Try it yourself
Add a right-side widget at desktop widths.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
