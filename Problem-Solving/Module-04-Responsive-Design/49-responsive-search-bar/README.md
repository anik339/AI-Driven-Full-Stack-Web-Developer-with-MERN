# Responsive Search Bar

## Task
Make a search form fill the available space and keep its button usable.

## Main concept
responsive form controls and flex layout

## Expected result
The search input stacks above the button on mobile and aligns beside it on wider screens.

## Explanation
Use min-width:0 for flexible input controls and preserve a comfortable button tap size.

## Try it yourself
Add a clear button and test keyboard focus.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
