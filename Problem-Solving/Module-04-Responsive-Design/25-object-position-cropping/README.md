# Object Position Cropping

## Task
Keep the subject visible in a cropped portrait image.

## Main concept
object-position and cover

## Expected result
The portrait crop focuses toward the top of the image.

## Explanation
object-position chooses the focal point after object-fit crops the image.

## Try it yourself
Try object-position: center bottom.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
