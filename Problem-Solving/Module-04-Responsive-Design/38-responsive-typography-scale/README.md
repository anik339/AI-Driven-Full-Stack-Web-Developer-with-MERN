# Responsive Typography Scale

## Task
Use clamp to scale h1, h2 and body text.

## Main concept
fluid type scale

## Expected result
The heading and paragraph scale smoothly.

## Explanation
Fluid typography can reduce the number of font-size breakpoints.

## Try it yourself
Add a small eyebrow label using clamp.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
