# System Dark Mode

## Task
Use prefers-color-scheme to respond to the user's theme.

## Main concept
prefers-color-scheme

## Expected result
The page switches to a dark palette when the system uses dark mode.

## Explanation
This media feature can provide an automatic theme. Keep contrast readable in both modes.

## Try it yourself
Add dark-mode link and border colours.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
