# Reduced Motion Preference

## Task
Disable non-essential movement for users who prefer reduced motion.

## Main concept
prefers-reduced-motion

## Expected result
The hover movement is removed when reduced motion is requested.

## Explanation
Respect system motion preferences for animation and transitions.

## Try it yourself
Add a reduced-motion rule to one of your earlier cards.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
