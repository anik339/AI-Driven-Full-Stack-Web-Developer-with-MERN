# Responsive Table Cards

## Task
Transform a compact data table into stacked rows on mobile.

## Main concept
data-label and mobile table pattern

## Expected result
On mobile, each row becomes a labelled block.

## Explanation
For complex tables, horizontal scrolling is often clearer. This card pattern is useful only for simple data and must preserve accessible headers.

## Try it yourself
Test with a screen reader or inspect the table semantics after styling.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
