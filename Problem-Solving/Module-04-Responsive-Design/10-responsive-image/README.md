# Responsive Image

## Task
Make an image shrink with its parent without distortion.

## Main concept
max-width, width and auto height

## Expected result
The image never exceeds its container and keeps its natural ratio.

## Explanation
Set width: 100% and height: auto for a simple responsive image.

## Try it yourself
Give the image a max-width of 700px and center it.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
