# Tablet Navigation Breakpoint

## Task
Increase spacing and font size on wider navigation.

## Main concept
tablet-specific spacing

## Expected result
Navigation has compact spacing on mobile and more breathing room on tablet.

## Explanation
Responsive design can adjust spacing and typography, not only columns.

## Try it yourself
Add a desktop breakpoint that aligns the nav to the right.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
