# Responsive Hero Section

## Task
Create a hero that scales its title and spacing.

## Main concept
fluid type and responsive hero grid

## Expected result
The hero stacks on mobile and becomes a two-column composition on desktop.

## Explanation
Use clamp for fluid type and Grid for the layout shift.

## Try it yourself
Add a background colour and adjust padding at large sizes.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
