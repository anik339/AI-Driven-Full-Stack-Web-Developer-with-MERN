# Accessible CSS-Only Disclosure

## Task
Use details/summary instead of hiding content behind hover.

## Main concept
native disclosure and responsive content

## Expected result
The FAQ opens and closes using built-in browser interaction.

## Explanation
Native details/summary works with keyboard and touch without requiring hover-only interactions.

## Try it yourself
Add a second FAQ and keep spacing consistent.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
