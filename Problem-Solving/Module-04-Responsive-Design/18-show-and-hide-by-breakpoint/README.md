# Show and Hide by Breakpoint

## Task
Display a compact note on mobile and a full note on desktop.

## Main concept
display and breakpoint visibility

## Expected result
The mobile note appears on small screens; the longer note appears on wide screens.

## Explanation
Use responsive visibility carefully. Do not hide important information from users just because the layout is narrow.

## Try it yourself
Make the desktop note visible at 600px and compare.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
