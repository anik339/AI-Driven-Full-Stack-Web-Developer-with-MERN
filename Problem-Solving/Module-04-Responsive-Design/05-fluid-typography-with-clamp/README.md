# Fluid Typography with clamp

## Task
Scale a heading smoothly between minimum and maximum sizes.

## Main concept
clamp() and viewport units

## Expected result
The heading scales smoothly as the viewport changes.

## Explanation
clamp(min, preferred, max) creates fluid typography without needing many breakpoints.

## Try it yourself
Use clamp() for the paragraph with smaller values.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
