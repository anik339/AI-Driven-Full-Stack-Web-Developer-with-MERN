# Responsive Portfolio Grid

## Task
Build a portfolio grid with one, two and three columns.

## Main concept
progressive grid breakpoints

## Expected result
Portfolio cards show one, two or three columns depending on width.

## Explanation
Choose breakpoints based on the card's minimum comfortable width.

## Try it yourself
Add a featured card that spans two columns on desktop.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
