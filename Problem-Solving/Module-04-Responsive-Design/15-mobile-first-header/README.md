# Mobile-First Header

## Task
Stack brand and actions on mobile, align them on desktop.

## Main concept
mobile-first flex direction

## Expected result
The header stacks on mobile and becomes a horizontal bar on larger screens.

## Explanation
Changing flex-direction at a breakpoint is a simple way to adapt a header.

## Try it yourself
Add a second action link and test at 320px.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
