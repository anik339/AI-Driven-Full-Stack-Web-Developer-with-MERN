# Responsive Form Width

## Task
Make form controls fill the available mobile width.

## Main concept
fluid form width and max-width

## Expected result
The form fills the mobile width and remains centered on larger screens.

## Explanation
Set controls to width:100% and constrain the form with max-width.

## Try it yourself
Add a two-column name/email row only at wide desktop sizes.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
