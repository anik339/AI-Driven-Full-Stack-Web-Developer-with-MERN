# Two-Column Content Layout

## Task
Switch a text and image section from stacked to two columns.

## Main concept
responsive two-column grid

## Expected result
The section stacks on mobile and splits into two columns on desktop.

## Explanation
Use one column as the base, then add columns when both pieces have enough space.

## Try it yourself
Reverse the image and text order on mobile using grid areas.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
