# Picture Art Direction

## Task
Use picture sources to choose different crops at different widths.

## Main concept
picture and media source selection

## Expected result
The browser can select a portrait crop on narrow screens and a wide image on larger screens.

## Explanation
Use picture for art direction when the best crop differs by viewport. Use srcset/sizes for resolution selection.

## Try it yourself
Add a medium-width source for tablet screens.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
