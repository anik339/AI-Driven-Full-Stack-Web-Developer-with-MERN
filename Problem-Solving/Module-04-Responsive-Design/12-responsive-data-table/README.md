# Responsive Data Table

## Task
Allow a wide table to scroll inside a wrapper on small screens.

## Main concept
overflow-x and min-width

## Expected result
The table remains readable and can scroll horizontally on a narrow screen.

## Explanation
Do not squeeze every data column until it becomes unreadable. A scroll wrapper is often appropriate for complex tables.

## Try it yourself
Add a caption and test keyboard scrolling.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
