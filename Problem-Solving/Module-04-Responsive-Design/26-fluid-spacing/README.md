# Fluid Spacing

## Task
Use clamp to create spacing that grows with the viewport.

## Main concept
clamp() for fluid spacing

## Expected result
Padding grows from 16px to 56px with viewport width.

## Explanation
Fluid spacing can reduce the number of breakpoints needed for simple layouts.

## Try it yourself
Use clamp for the gap between two cards.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
