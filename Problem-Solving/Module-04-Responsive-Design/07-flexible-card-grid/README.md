# Flexible Card Grid

## Task
Use auto-fit and minmax to create a flexible grid.

## Main concept
auto-fit and minmax

## Expected result
Cards automatically form as many columns as fit.

## Explanation
auto-fit and minmax create a responsive grid without manually writing multiple breakpoints.

## Try it yourself
Change 220px to 260px and compare.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
