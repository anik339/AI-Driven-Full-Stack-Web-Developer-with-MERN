# Responsive Blog Layout

## Task
Create a blog article and related sidebar that adapts to mobile.

## Main concept
responsive article and sidebar

## Expected result
The sidebar moves below the article on mobile and to the side on desktop.

## Explanation
Maintain a logical reading order in the HTML. CSS should not create a confusing visual order.

## Try it yourself
Add a sticky sidebar only on wide screens.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
