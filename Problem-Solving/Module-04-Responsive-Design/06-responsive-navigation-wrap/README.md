# Responsive Navigation Wrap

## Task
Allow navigation links to wrap instead of overflow.

## Main concept
flex-wrap and responsive navigation

## Expected result
Links wrap onto a new line when the viewport is narrow.

## Explanation
Wrapping is a simple way to avoid overflow in small navigation bars. A collapsed menu requires an accessible interaction pattern.

## Try it yourself
Add a menu button visually for a later JavaScript exercise.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
