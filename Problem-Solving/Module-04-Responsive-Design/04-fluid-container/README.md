# Fluid Container

## Task
Use percentage width and max-width for a flexible page container.

## Main concept
width, max-width and auto margins

## Expected result
The container stays centered and does not grow beyond 960px.

## Explanation
A fluid container adapts to the viewport while max-width keeps line lengths manageable.

## Try it yourself
Change the max width to 720px.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
