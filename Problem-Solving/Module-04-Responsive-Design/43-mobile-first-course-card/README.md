# Mobile-First Course Card

## Task
Create a course card that expands horizontally at a breakpoint.

## Main concept
mobile-first card layout

## Expected result
The image stacks above the text on mobile and sits beside it on wider screens.

## Explanation
Build the small layout first; only add columns when the content has room.

## Try it yourself
Add a status badge and make it wrap naturally.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
