# Responsive Landing Page

## Task
Combine hero, feature cards and footer into a small responsive landing page.

## Main concept
responsive page composition

## Expected result
Header, hero, feature grid and footer components adapt to mobile and desktop.

## Explanation
A complete responsive page combines fluid containers, flexible media, grid/flex and readable type.

## Try it yourself
Test at 320px, 768px and 1280px and fix any horizontal overflow.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
