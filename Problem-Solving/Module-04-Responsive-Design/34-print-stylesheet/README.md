# Print Stylesheet

## Task
Hide navigation and preserve readable article content when printing.

## Main concept
@media print

## Expected result
Navigation is hidden and the article uses a clean print layout.

## Explanation
Print styles can remove navigation, backgrounds and other non-essential elements.

## Try it yourself
Add page-break rules for a long report.

## How to run
1. Open `index.html` with VS Code Live Server.
2. Resize the browser to mobile, tablet and desktop widths.
3. Read `style.css` from top to bottom.
4. Change one breakpoint or layout rule and test again.
5. Use browser DevTools responsive mode to inspect the layout.
