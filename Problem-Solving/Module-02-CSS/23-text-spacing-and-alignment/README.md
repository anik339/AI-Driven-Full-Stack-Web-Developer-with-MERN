# Text Spacing and Alignment

## Task
Control line height, letter spacing and text alignment.

## Main concept
text-align, letter-spacing, line-height and text-transform

## Expected result
The heading is uppercase and the paragraph is centered with generous line height.

## Explanation
Text spacing can improve readability. Avoid excessive letter spacing or all-caps body text.

## Try it yourself
Align the paragraph left while keeping the heading centered.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
