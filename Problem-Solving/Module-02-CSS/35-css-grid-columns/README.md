# CSS Grid Columns

## Task
Build a three-column card layout using Grid.

## Main concept
display:grid and repeat()

## Expected result
Three equal columns appear on a wide viewport.

## Explanation
Grid is useful for two-dimensional layouts with rows and columns.

## Try it yourself
Change the grid to two columns.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
