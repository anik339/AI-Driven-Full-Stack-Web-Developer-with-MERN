# Container Query Card

## Task
Adapt a card based on its container width.

## Main concept
container-type and @container

## Expected result
The card becomes horizontal when its container is wide enough.

## Explanation
Container queries respond to a component's container rather than the viewport.

## Try it yourself
Place two cards inside containers with different widths and compare.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
