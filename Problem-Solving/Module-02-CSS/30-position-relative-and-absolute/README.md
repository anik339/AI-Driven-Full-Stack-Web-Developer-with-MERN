# Position Relative and Absolute

## Task
Place a badge inside a card using positioned ancestors.

## Main concept
position relative and absolute

## Expected result
The New badge appears in the top-right corner of the card.

## Explanation
An absolutely positioned element is positioned relative to its nearest positioned ancestor.

## Try it yourself
Move the badge to the bottom-left corner.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
