# Accessible Focus and Colour

## Task
Create visible focus and readable contrast for a notice.

## Main concept
contrast and focus visibility

## Expected result
The link has a clear keyboard focus ring and the notice uses dark text on a pale background.

## Explanation
Do not communicate status using colour alone; keep clear text and focus indicators.

## Try it yourself
Use a contrast checker to verify your chosen text and background colours.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
