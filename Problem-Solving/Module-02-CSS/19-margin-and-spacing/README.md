# Margin and Spacing

## Task
Create consistent vertical spacing between cards.

## Main concept
margin and spacing

## Expected result
Cards have equal vertical gaps without an extra gap after the last card.

## Explanation
Margin creates space outside an element. Use a consistent spacing scale.

## Try it yourself
Replace margins with flex gap and compare the CSS.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
