# Transition on Interaction

## Task
Animate a card's shadow and movement smoothly.

## Main concept
transition and hover

## Expected result
The card lifts slightly when hovered.

## Explanation
Transition specifies which properties animate and how long the change takes.

## Try it yourself
Add a border-color transition.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
