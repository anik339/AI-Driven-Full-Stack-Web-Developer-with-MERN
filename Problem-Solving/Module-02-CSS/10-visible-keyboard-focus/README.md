# Visible Keyboard Focus

## Task
Make keyboard focus visible on links and buttons.

## Main concept
focus-visible and outline

## Expected result
Press Tab to see a clear focus outline.

## Explanation
:focus-visible helps keyboard users see which control is active without adding an outline for every pointer click.

## Try it yourself
Use :focus-visible on an input and select.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
