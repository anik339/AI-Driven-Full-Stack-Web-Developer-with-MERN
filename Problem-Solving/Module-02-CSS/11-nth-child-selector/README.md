# Nth-child Selector

## Task
Highlight every second row in a list.

## Main concept
nth-child() pseudo-class

## Expected result
Even-numbered list items receive a light background.

## Explanation
:nth-child() selects elements based on their position among siblings.

## Try it yourself
Highlight the third item only.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
