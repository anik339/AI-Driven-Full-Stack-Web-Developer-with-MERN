# Pseudo-element Before

## Task
Add a decorative marker before each checklist item.

## Main concept
::before and generated content

## Expected result
Each list item has a checkmark before its text.

## Explanation
Pseudo-elements create decorative content without adding extra HTML nodes. Do not use them for essential information.

## Try it yourself
Use ::after to add a small label after a heading.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
