# Element Selector

## Task
Style every paragraph using an element selector.

## Main concept
type selector

## Expected result
Both paragraphs share the same text colour and spacing.

## Explanation
An element selector targets every element of that type in the document.

## Try it yourself
Style all h2 elements with a different colour.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
