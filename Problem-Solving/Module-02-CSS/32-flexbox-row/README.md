# Flexbox Row

## Task
Align navigation links in one row with Flexbox.

## Main concept
display:flex, align-items and gap

## Expected result
The links appear in a row with even gaps.

## Explanation
Flexbox is useful for one-dimensional layouts such as navigation bars and toolbars.

## Try it yourself
Add justify-content: space-between and compare.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
