# CSS Architecture with Components

## Task
Use component classes and avoid styling by tag alone.

## Main concept
component naming and BEM-style classes

## Expected result
The card styles are scoped to one component.

## Explanation
Meaningful component classes are easier to maintain than broad selectors that unexpectedly affect unrelated pages.

## Try it yourself
Create a second card component using the same class names.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
