# Border-box Reset

## Task
Use border-box so declared widths include padding and borders.

## Main concept
box-sizing: border-box

## Expected result
The box's outer width remains 280px.

## Explanation
border-box makes sizing easier because width includes padding and border.

## Try it yourself
Apply a universal border-box reset to the whole page.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
