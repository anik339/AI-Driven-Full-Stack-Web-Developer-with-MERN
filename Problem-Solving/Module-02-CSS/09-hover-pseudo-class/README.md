# Hover Pseudo-class

## Task
Change a button's appearance when the pointer hovers over it.

## Main concept
hover and transition

## Expected result
The button darkens when hovered.

## Explanation
:hover matches an element while a pointing device is over it. Keep hover effects subtle.

## Try it yourself
Add a hover state to a card.
