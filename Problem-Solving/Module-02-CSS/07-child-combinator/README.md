# Child Combinator

## Task
Style only direct list children, not nested items.

## Main concept
child combinator >

## Expected result
Top-level list items are blue and bold; nested items are muted.

## Explanation
The > combinator matches only direct children.

## Try it yourself
Add another nested list and compare the result.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
