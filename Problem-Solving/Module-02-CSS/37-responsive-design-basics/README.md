# Responsive Design Basics

## Task
Use a media query to reduce card columns on small screens.

## Main concept
media queries and breakpoints

## Expected result
The cards display in one column on a narrow screen.

## Explanation
A media query applies CSS only when the viewport matches its condition.

## Try it yourself
Add a two-column layout between 651px and 900px.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
