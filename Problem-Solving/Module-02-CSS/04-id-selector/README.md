# ID Selector

## Task
Target one unique element with an ID selector.

## Main concept
ID selector

## Expected result
Only the announcement receives the highlighted background.

## Explanation
An ID should be unique on a page. Use classes for styles that need to be reused.

## Try it yourself
Add a unique id to a heading and style it.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
