# CSS Functions calc()

## Task
Calculate a content width using calc().

## Main concept
calc()

## Expected result
The main area fills the remaining width after the sidebar and gap.

## Explanation
calc() can combine compatible CSS units to calculate a value.

## Try it yourself
Use calc(100% - 240px) and adjust the sidebar width.
