# Overflow Handling

## Task
Prevent long content from breaking a card layout.

## Main concept
overflow and overflow-wrap

## Expected result
The long URL wraps inside the card.

## Explanation
overflow controls content outside a box. overflow-wrap helps break long unspaced strings.

## Try it yourself
Try overflow: auto on a fixed-height code preview.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
