# Typography and Font Size

## Task
Create a clear title and body text hierarchy.

## Main concept
font-size, font-weight, letter-spacing and line-height

## Expected result
The heading is prominent and the paragraph is comfortable to read.

## Explanation
Typography uses size, weight, spacing and line height to create hierarchy.

## Try it yourself
Make the paragraph slightly larger on wide screens.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
