# Flexbox Alignment

## Task
Center a login panel both horizontally and vertically.

## Main concept
justify-content and align-items

## Expected result
The login panel is centered inside the stage.

## Explanation
justify-content aligns items on the main axis; align-items aligns them on the cross axis.

## Try it yourself
Try align-items: flex-start and compare.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
