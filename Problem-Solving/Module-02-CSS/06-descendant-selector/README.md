# Descendant Selector

## Task
Style links only when they appear inside the navigation.

## Main concept
descendant combinator

## Expected result
Navigation links are blue and bold; the paragraph link remains unchanged.

## Explanation
A space between selectors means the second selector can be anywhere inside the first.

## Try it yourself
Style only strong elements inside an article.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
