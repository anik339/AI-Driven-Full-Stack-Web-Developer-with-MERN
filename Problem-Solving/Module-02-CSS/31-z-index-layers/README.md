# Z-index Layers

## Task
Place a notification above a decorative panel.

## Main concept
z-index and stacking context

## Expected result
The notification sits above the background panel.

## Explanation
z-index affects stacking order within a stacking context. Positioning and transforms can create new stacking contexts.

## Try it yourself
Give the back layer z-index: 3 and observe what changes.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
