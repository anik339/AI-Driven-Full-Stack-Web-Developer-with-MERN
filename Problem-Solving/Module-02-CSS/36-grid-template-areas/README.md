# Grid Template Areas

## Task
Create a simple header, sidebar and content layout.

## Main concept
grid-template-areas and grid-area

## Expected result
The dashboard places header and footer across both columns.

## Explanation
Named grid areas make complex page regions easier to understand.

## Try it yourself

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
