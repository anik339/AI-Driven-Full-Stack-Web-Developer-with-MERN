# Reduced Motion Preference

## Task
Respect users who prefer reduced motion.

## Main concept
prefers-reduced-motion

## Expected result
The hover animation is reduced when the operating system requests reduced motion.

## Explanation
Some users experience discomfort from motion. Respect the prefers-reduced-motion media feature.

## Try it yourself
Test by enabling Reduce Motion in your operating system.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
