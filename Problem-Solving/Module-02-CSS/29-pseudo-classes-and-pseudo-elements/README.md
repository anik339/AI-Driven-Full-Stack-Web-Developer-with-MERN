# Pseudo-classes and Pseudo-elements

## Task
Style first-child, checked and placeholder states.

## Main concept
pseudo-classes and pseudo-elements

## Expected result
The first list item is highlighted, checkbox uses an accent colour and placeholder is muted.

## Explanation
Pseudo-classes represent a state or relationship; pseudo-elements target a part of an element.

## Try it yourself
Add :disabled styling to a disabled input.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
