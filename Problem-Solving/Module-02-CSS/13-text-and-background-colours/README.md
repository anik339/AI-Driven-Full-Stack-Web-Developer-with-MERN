# Text and Background Colours

## Task
Use foreground and background colours with sufficient contrast.

## Main concept
color and background-color

## Expected result
The notice has dark text on a pale blue background.

## Explanation
Choose readable contrast between text and background, especially for small text.

## Try it yourself
Create a warning notice using an accessible colour combination.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
