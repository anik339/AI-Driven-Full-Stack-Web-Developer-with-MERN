# Transform an Element

## Task
Rotate and scale a decorative badge.

## Main concept
transform rotate and scale

## Expected result
The badge is slightly rotated and enlarged.

## Explanation
Transforms visually change an element without changing the normal document flow.

## Try it yourself
Try translateX(10px) instead of rotation.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
