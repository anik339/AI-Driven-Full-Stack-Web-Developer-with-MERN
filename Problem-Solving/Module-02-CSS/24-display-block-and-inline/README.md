# Display Block and Inline

## Task
Compare block, inline and inline-block behaviour.

## Main concept
display: block, inline and inline-block

## Expected result
Inline items share a line; the paragraph begins on a new line.

## Explanation
display controls how an element participates in layout. inline-block allows dimensions and padding while staying inline.

## Try it yourself
Change the spans to inline-block and give them a width.
