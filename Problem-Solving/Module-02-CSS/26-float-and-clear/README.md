# Float and Clear

## Task
Wrap text around an image using float and clear.

## Main concept
float and clear

## Expected result
The first paragraph wraps around the image; the second starts below it.

## Explanation
Float was designed for text wrapping. Use Flexbox or Grid for most interface layouts.

## Try it yourself
Create a right-floated image and observe the text wrapping.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
