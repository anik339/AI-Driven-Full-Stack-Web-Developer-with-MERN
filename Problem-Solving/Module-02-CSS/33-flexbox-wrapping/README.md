# Flexbox Wrapping

## Task
Allow cards to wrap onto another row.

## Main concept
flex-wrap and flex shorthand

## Expected result
Cards wrap when the available space is too small.

## Explanation
flex: 1 1 150px lets items grow, shrink and start from a 150px basis.

## Try it yourself
Change the basis to 220px and test a narrow viewport.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
