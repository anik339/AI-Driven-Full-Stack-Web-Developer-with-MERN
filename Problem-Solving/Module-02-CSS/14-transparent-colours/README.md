# Transparent Colours

## Task
Use rgba() to create a translucent overlay.

## Main concept
alpha channel and rgba()

## Expected result
The heading has a semi-transparent dark background.

## Explanation
The alpha channel controls transparency. rgba() uses a value from 0 to 1 for opacity.

## Try it yourself
Make the overlay more transparent by changing .45 to .25.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
