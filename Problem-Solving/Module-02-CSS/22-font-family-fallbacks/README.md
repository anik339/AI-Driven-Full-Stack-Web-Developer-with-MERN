# Font Family Fallbacks

## Task
Choose a font stack with sensible fallbacks.

## Main concept
font-family and fallback stack

## Expected result
Text uses the first available font in the stack.

## Explanation
A fallback stack prevents text from depending on one font being installed.

## Try it yourself
Use Georgia, Times New Roman and serif for an editorial heading.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
