# Borders and Radius

## Task
Use border styles and rounded corners to define a card.

## Main concept
border, border-style, border-radius

## Expected result
The profile card has a visible border and rounded corners.

## Explanation
Border shorthand combines width, style and colour. border-radius controls corner rounding.

## Try it yourself
Make the card have a pill-shaped label.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
