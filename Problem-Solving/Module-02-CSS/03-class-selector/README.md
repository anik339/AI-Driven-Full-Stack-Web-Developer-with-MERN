# Class Selector

## Task
Apply a reusable card style using a class.

## Main concept
class selector and reusable styling

## Expected result
Both cards receive the same border, padding and rounded corners.

## Explanation
A class can be reused on multiple elements. Prefix the class selector with a dot.

## Try it yourself
Create a .featured class and apply it to one card.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
