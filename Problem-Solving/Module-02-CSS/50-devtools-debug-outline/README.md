# DevTools Debug Outline

## Task
Use temporary outlines to debug layout boxes.

## Main concept
DevTools inspection and outline

## Expected result
A dashed outline makes the child box easier to inspect.

## Explanation
Use browser DevTools to inspect computed styles, box model and layout. Remove temporary debug styles before committing.

## Try it yourself
Inspect the element's computed margin, padding and width in DevTools.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
