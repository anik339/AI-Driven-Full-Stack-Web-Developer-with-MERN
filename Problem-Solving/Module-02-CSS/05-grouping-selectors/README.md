# Grouping Selectors

## Task
Apply the same font to multiple heading levels.

## Main concept
grouping selector

## Expected result
Both headings use the same font family and colour.

## Explanation
Separate selectors with commas when the same declarations apply to each.

## Try it yourself
Group h1 and h4 under one rule.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
