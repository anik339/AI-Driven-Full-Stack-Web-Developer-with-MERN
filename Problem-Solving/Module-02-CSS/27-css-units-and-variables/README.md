# CSS Units and Variables

## Task
Use rem units and a reusable custom property.

## Main concept
px, rem, %, custom properties and var()

## Expected result
The card uses a shared colour and spacing token.

## Explanation
Custom properties can be declared on :root and reused with var(). rem units scale with the root font size.

## Try it yourself
Add --surface and use it for the card background.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
