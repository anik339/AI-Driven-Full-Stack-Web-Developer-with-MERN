# Cascade and Specificity

## Task
Observe which selector wins when rules conflict.

## Main concept
cascade and specificity

## Expected result
The text is blue because the ID selector has higher specificity.

## Explanation
The cascade considers origin, importance, layers, specificity and source order. Avoid solving every conflict with !important.

## Try it yourself
Remove the ID rule and predict the winning colour.
