# List Markers

## Task
Customize list markers without changing the content.

## Main concept
list-style and ::marker

## Expected result
The list uses square blue markers.

## Explanation
Use list-style-type for marker shapes and ::marker for supported marker styling.

## Try it yourself
Create an ordered list with lower-roman numbering.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
