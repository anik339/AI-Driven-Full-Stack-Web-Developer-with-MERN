# CSS Rule Syntax

## Task
Style a heading and paragraph using a selector, property and value.

## Main concept
selector, declaration, property and value

## Expected result
The heading is blue and larger; the paragraph has a readable line height.

## Explanation
A CSS rule has a selector and a declaration block. Each declaration is a property-value pair.

## Try it yourself
Add a background-color to .note.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
