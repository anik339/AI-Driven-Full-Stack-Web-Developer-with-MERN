# Box Model Dimensions

## Task
Understand content, padding, border and margin.

## Main concept
CSS box model

## Expected result
The visible box is wider than its content width because padding and border are added.

## Explanation
With content-box, declared width applies only to the content. Padding and border increase the outer size.

## Try it yourself
Inspect the element in DevTools and calculate its total width.
