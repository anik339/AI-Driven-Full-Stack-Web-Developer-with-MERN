# Image Object Fit

## Task
Crop an image to a fixed frame without stretching it.

## Main concept
object-fit and object-position

## Expected result
The image fills the frame while keeping its proportions.

## Explanation
object-fit: cover fills the frame and crops overflow. contain shows the entire image with possible empty space.

## Try it yourself
Change cover to contain and compare.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
