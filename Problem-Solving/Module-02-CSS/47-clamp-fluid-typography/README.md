# Clamp Fluid Typography

## Task
Use clamp() for a heading that scales with the viewport.

## Main concept
clamp(minimum, preferred, maximum)

## Expected result
The heading grows as the viewport gets wider but remains within the limits.

## Explanation
clamp() sets a minimum, fluid preferred value and maximum.

## Try it yourself
Use clamp() for paragraph text with smaller limits.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
