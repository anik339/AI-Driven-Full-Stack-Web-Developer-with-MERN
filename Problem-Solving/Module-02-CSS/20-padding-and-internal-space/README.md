# Padding and Internal Space

## Task
Give a message panel breathing room inside its border.

## Main concept
padding

## Expected result
The message has space between its text and border.

## Explanation
Padding adds internal space. It is especially useful for cards, buttons and form controls.

## Try it yourself
Try padding: 8px 16px and compare.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
