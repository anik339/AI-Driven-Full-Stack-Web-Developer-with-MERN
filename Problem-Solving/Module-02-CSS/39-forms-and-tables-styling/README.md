# Forms and Tables Styling

## Task
Style inputs and table rows for readability.

## Main concept
form control and table styling

## Expected result
The input and table have consistent borders and spacing.

## Explanation
Form controls need visible boundaries and focus styles. Data tables benefit from clear headers and row separation.

## Try it yourself
Add a focus-visible style to the email input.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
