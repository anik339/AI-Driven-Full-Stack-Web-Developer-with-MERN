# Attribute Selector

## Task
Style required form controls using an attribute selector.

## Main concept
attribute selectors

## Expected result
The required input receives a green border.

## Explanation
Attribute selectors target elements based on the presence or value of an attribute.

## Try it yourself
Style all links that have target=_blank.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
