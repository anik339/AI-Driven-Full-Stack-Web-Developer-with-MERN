# Module 02 — CSS Foundations — 50 Problems

50 CSS problems covering selectors, cascade, specificity, colours, backgrounds, box model, typography, units, variables, display, overflow, positioning, Flexbox, Grid, responsive CSS, transitions, accessibility, container queries and DevTools.

## How to practise

Open each `index.html` with Live Server. Edit `style.css` and refresh the page to see the result.

## Recommended routine
1. Read the problem statement before opening the solution.
2. Predict what the page or code will do.
3. Run the provided solution and compare the result.
4. Read the code comments and explain the important lines in your own words.
5. Complete the challenge without copying the solution.
6. Commit your completed work to GitHub with a clear message.
