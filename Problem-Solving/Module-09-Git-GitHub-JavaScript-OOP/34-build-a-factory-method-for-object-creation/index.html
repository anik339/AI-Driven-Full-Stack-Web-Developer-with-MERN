Build a Factory Method for Object Creation

Centralize object creation and provide safe defaults.

Problem statement

Create a User class with static createGuest and createRegistered factory methods. Keep construction details in one place.

Expected behavior

Focus: factory method · static factory · named creation

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  class User {
    constructor({ id, name, role }) {
      this.id = id;
      this.name = name;
      this.role = role;
    }

    // Factory methods describe intent more clearly than raw constructor calls.
    static createGuest() {
      return new User({ id: null, name: "Guest", role: "visitor" });
    }

    static createRegistered(id, name) {
      if (!name.trim()) throw new Error("A registered user needs a name.");
      return new User({ id, name: name.trim(), role: "member" });
    }
  }

  console.log(User.createGuest());
  console.log(User.createRegistered(7, "Maya"));
}

Output / practice checklist

One guest user and one registered member are created with different defaults.
