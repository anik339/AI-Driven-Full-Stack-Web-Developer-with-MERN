Problem statement

Create a Person base class and a Developer child class. Reuse the parent constructor with super and add a language property.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add a Designer class that also extends Person and overrides describe().

Expected behavior

Anik develops with JavaScript. The instanceof check is true.

Focus: extends · super · inheritance

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  class Person {
    constructor(name) {
      this.name = name;
    }

    describe() {
      return `${this.name} is a person.`;
    }
  }

  class Developer extends Person {
    constructor(name, language) {
      // super must run before using `this` in a derived constructor.
      super(name);
      this.language = language;
    }

    describe() {
      return `${this.name} develops with ${this.language}.`;
    }
  }

  const developer = new Developer("Anik", "JavaScript");
  console.log(developer.describe());
  console.log(developer instanceof Person);
}

Output / practice checklist

Anik develops with JavaScript. The instanceof check is true.
