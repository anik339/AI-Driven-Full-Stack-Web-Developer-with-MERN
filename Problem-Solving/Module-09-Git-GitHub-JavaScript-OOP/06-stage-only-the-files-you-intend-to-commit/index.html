Stage Only the Files You Intend to Commit

Problem statement

Create README.md and app.js. Stage only README.md, verify app.js remains untracked, then stage app.js separately.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Practise staging a single hunk with `git add -p` in Git Bash or a compatible terminal.

Expected behavior

The first staged-file list contains only README.md. After the second git add, both files appear.

Focus: git add · pathspec · staged diff

PowerShell / Git command reference

These are Git commands for a terminal. The browser cannot execute them.

# Create two files for the exercise.
"Project setup notes" | Set-Content README.md
New-Item -ItemType Directory -Force src | Out-Null
"console.log('Hello');" | Set-Content src/app.js
# Stage only the documentation file.
git add README.md
# Review exactly what is staged.
git status --short
git diff --cached --name-only
# Stage the source file after reviewing it.
git add src/app.js
git diff --cached --name-only

Output / practice checklist

Git commands are shown for manual execution in PowerShell. They are not executed by this webpage.
