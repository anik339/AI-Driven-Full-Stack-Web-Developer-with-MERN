Problem statement

Create a ReportExporter class whose public export method validates data, formats it, and returns a CSV-like string. Keep formatting private.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add CSV escaping for commas and quotation marks in names.

Expected behavior

A two-line CSV-style report is returned.

Focus: abstraction · private methods · public API

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  class ReportExporter {
    // Private method keeps the formatting detail out of the public API.
    #formatRows(rows) {
      return rows.map(row => `${row.name},${row.score}`).join("\n");
    }

    export(rows) {
      if (!Array.isArray(rows)) throw new TypeError("Rows must be an array.");
      // Callers only need to know about export(), not each internal step.
      return this.#formatRows(rows);
    }
  }

  const exporter = new ReportExporter();
  console.log(exporter.export([{ name: "Anik", score: 90 }, { name: "Maya", score: 95 }]));
}

Output / practice checklist

A two-line CSV-style report is returned.
