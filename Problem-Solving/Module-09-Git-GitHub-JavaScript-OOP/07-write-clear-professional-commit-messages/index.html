Task 07 · Git fundamentals

Write Clear, Professional Commit Messages

Create small commits with messages that communicate intent.

Problem 7 of 50git commit · conventional commit prefixes · atomic changes
Read full task guide ↗Module 09 guide ↗

Problem statement

Stage one documentation change and one source-code change separately. Commit each with a concise message describing the change.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Write a `fix:` commit for a bug and a `refactor:` commit for an internal cleanup. Explain the difference.

Expected behavior

Two separate commits appear in history. Each commit describes one logical change.

Focus: git commit · conventional commit prefixes · atomic changes

PowerShell / Git command reference

These are Git commands for a terminal. The browser cannot execute them.

# Stage and commit one focused documentation change.
git add README.md
git commit -m "docs: describe local setup"
# Stage and commit one focused code change.
git add src/app.js
git commit -m "feat: add application entry point"
# Review the resulting commit sequence.
git log --oneline -5

Output / practice checklist
