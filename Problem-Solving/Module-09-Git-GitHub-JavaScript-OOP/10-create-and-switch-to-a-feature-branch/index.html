Task 10 · Git branching

Create and Switch to a Feature Branch

Isolate a new feature from the main branch using a descriptive branch name.

Problem 10 of 50git switch · feature branch · branch list
Read full task guide ↗Module 09 guide ↗

Problem statement

Create a feature branch, add a small file, commit it, and verify that main has not received the change yet.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Create a second branch named fix/mobile-navigation and explain why each branch should have a focused purpose.

Expected behavior

The current branch is feature/profile-card. The feature commit belongs to that branch until merged.

Focus: git switch · feature branch · branch list

PowerShell / Git command reference

These are Git commands for a terminal. The browser cannot execute them.

# Start from the main branch and create a named feature branch.
git switch main
git switch -c feature/profile-card
# Add and commit a feature-specific file.
New-Item -ItemType Directory -Force src | Out-Null
"export const profileTitle = 'Developer Profile';" | Set-Content src/profile.js
git add src/profile.js
git commit -m "feat: add profile card data"
# Confirm the active branch and available branches.
git branch --show-current
git branch --list

Output / practice checklist

Git commands are shown for manual execution in PowerShell. They are not executed by this webpage.
