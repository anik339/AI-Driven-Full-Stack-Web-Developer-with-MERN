Problem statement

Create a product object with name and price. Add a method that returns a formatted product label using this.name and this.price.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Expected behavior

Mechanical Keyboard — $79.99

Focus: methods · this · method call

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  // A method is a function stored as an object property.
  const product = {
    name: "Mechanical Keyboard",
    price: 79.99,
    // `this` refers to the object before the dot at the call site.
    getLabel() {
      return `${this.name} — $${this.price.toFixed(2)}`;
    }
  };

  // Calling product.getLabel() sets `this` to product.
  console.log(product.getLabel());
}
