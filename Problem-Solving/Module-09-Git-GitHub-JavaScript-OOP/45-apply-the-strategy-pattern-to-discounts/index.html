Apply the Strategy Pattern to Discounts

Swap pricing rules without adding conditional branches throughout a checkout class.

Problem 45 of 50strategy pattern · composition · interchangeable behavior

Problem statement

Create percentage and fixed-amount discount strategies. Inject the selected strategy into a Checkout class.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Expected behavior

Percentage: 90 · Fixed: 85

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  const percentageDiscount = {
    apply(total) { return total * 0.9; } // 10% off
  };
  const fixedDiscount = {
    apply(total) { return Math.max(0, total - 15); } // $15 off, never below zero
  };

  class Checkout {
    constructor(discountStrategy) { this.discountStrategy = discountStrategy; }
    totalAfterDiscount(subtotal) {
      // Checkout delegates the pricing rule to the injected strategy.
      return this.discountStrategy.apply(subtotal);
    }
  }

  console.log("Percentage:", new Checkout(percentageDiscount).totalAfterDiscount(100));
  console.log("Fixed:", new Checkout(fixedDiscount).totalAfterDiscount(100));
}
