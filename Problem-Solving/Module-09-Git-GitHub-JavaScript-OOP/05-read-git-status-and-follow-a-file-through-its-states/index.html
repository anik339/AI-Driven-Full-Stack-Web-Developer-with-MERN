Task 05 · Git fundamentals

Read Git Status and Follow a File Through Its States

Observe untracked, modified, and staged states using one practice file.

Problem 5 of 50git status · git diff · git diff --cached
Read full task guide ↗Module 09 guide ↗

Problem statement

Create notes.txt, inspect it, stage it, modify it again, and compare the staged and unstaged differences.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Stage the second version and compare `git diff --cached` before committing.

Expected behavior

The staged snapshot contains Version 1 while the working tree contains Version 2. Git status shows both staged and unstaged changes.

Focus: git status · git diff · git diff --cached

PowerShell / Git command reference

These are Git commands for a terminal. The browser cannot execute them.

# Create a file and inspect its untracked state.
"Version 1" | Set-Content notes.txt
git status --short
# Stage the first version.
git add notes.txt
# Inspect what is staged for the next commit.
git diff --cached
# Modify the file after staging.
"Version 2" | Set-Content notes.txt
# This shows unstaged changes; the staged snapshot remains separate.
git diff
# Inspect both states together.
git status

Output / practice checklist

Git commands are shown for manual execution in PowerShell. They are not executed by this webpage.
