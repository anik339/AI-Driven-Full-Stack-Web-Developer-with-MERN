Problem statement

Create a vehicle prototype with a start method. Create a car object that inherits from it and distinguish own from inherited properties.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add a second vehicle object and compare its prototype with the first car.

Expected behavior

start is inherited, while brand and model are own properties of car.

Focus: Object.create · prototype chain · hasOwn

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  // The prototype provides behavior shared by related objects.
  const vehicle = {
    start() {
      return `${this.brand} engine started.`;
    }
  };

  // car inherits from vehicle but owns its brand and model properties.
  const car = Object.create(vehicle);
  car.brand = "Toyota";
  car.model = "Corolla";

  console.log(car.start());
  console.log("Own keys:", Object.keys(car).join(", "));
  console.log("Has own start:", Object.hasOwn(car, "start"));
  console.log("Prototype is vehicle:", Object.getPrototypeOf(car) === vehicle);
}

Output / practice checklist

start is inherited, while brand and model are own properties of car.
