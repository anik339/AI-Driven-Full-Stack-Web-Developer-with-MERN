Problem statement

Create a BankAccount class with a private balance. Allow deposits and withdrawals only when amounts are valid.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add withdraw(amount) and prevent the balance from becoming negative.

Expected behavior

Balance: 150. Private balance is not exposed as a public property.

Focus: private fields · encapsulation · invariants

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  class BankAccount {
    // The # prefix makes balance private to the class body.
    #balance = 0;

    constructor(owner, openingBalance = 0) {
      this.owner = owner;
      if (openingBalance < 0) throw new Error("Opening balance cannot be negative.");
      this.#balance = openingBalance;
    }

    deposit(amount) {
      if (!Number.isFinite(amount) || amount <= 0) throw new Error("Deposit must be positive.");
      this.#balance += amount;
      return this.#balance;
    }

    getBalance() {
      // Public method exposes a safe read-only view.
      return this.#balance;
    }
  }

  const account = new BankAccount("Anik", 100);
  account.deposit(50);
  console.log("Balance:", account.getBalance());
  console.log("Private field accessible:", "#balance" in account);
}

Output / practice checklist

Balance: 150. Private balance is not exposed as a public property.
