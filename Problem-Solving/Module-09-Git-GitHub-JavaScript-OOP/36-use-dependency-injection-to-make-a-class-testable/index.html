Use Dependency Injection to Make a Class Testable

Pass dependencies into a class instead of creating them internally.

Problem statement

Create a GreetingService that receives a user repository. Test it with a fake repository that does not use a database.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Inject a logger too, and verify the service can run with a no-op logger.

Expected behavior

The service greets user 1 and returns User not found for an unknown id.

Focus: dependency injection · constructor parameters · test doubles

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  // The service knows the repository contract, not how data is stored.
  class GreetingService {
    constructor(userRepository) {
      this.userRepository = userRepository;
    }

    greetUser(id) {
      const user = this.userRepository.findById(id);
      if (!user) return "User not found";
      return `Welcome back, ${user.name}!`;
    }
  }

  // This in-memory fake is a test double for a future database repository.
  const fakeRepository = {
    findById(id) {
      return id === 1 ? { id: 1, name: "Anik" } : null;
    }
  };

  const service = new GreetingService(fakeRepository);
  console.log(service.greetUser(1));
  console.log(service.greetUser(99));
}

Output / practice checklist

The service greets user 1 and returns User not found for an unknown id.
