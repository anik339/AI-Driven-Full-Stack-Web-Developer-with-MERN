Task 02 · Git fundamentals

Verify Git Installation and Inspect Configuration

Check that Git is installed and understand which configuration values are active.

Problem statement

Verify Git is available in PowerShell. Inspect configured identity and explain the difference between system, global, and local configuration.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Find which config file supplies user.name and explain why local config overrides global config.

Expected behavior

PowerShell prints a Git version and the active configuration values. Missing identity values can be configured locally in a practice repository.

Focus: git --version · git config · configuration scope

PowerShell / Git command reference

These are Git commands for a terminal. The browser cannot execute them.

# Confirm that the Git executable is available.
git --version
# Show configuration values and where each value came from.
git config --list --show-origin
# Read the configured author name and email (if present).
git config user.name
git config user.email
# PowerShell alternative for locating the executable.
Get-Command git

Output / practice checklist

Git commands are shown for manual execution in PowerShell. They are not executed by this webpage.
