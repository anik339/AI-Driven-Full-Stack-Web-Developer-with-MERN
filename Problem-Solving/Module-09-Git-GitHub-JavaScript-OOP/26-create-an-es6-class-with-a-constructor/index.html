Problem statement

Create a Course class with title, duration, and an instance method that returns a course summary.

Stretch challenge

Add a method that estimates study hours from durationWeeks and a weekly-hours value.

Expected behavior

Two course summaries and true for the instanceof check.

Focus: class · constructor · instance methods

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  // A class describes the data and behavior shared by its instances.
  class Course {
    constructor(title, durationWeeks) {
      this.title = title;
      this.durationWeeks = durationWeeks;
    }

    // Instance methods are shared through Course.prototype.
    getSummary() {
      return `${this.title} — ${this.durationWeeks} weeks`;
    }
  }

  const javascript = new Course("JavaScript and OOP", 4);
  const git = new Course("Git and GitHub", 2);
  console.log(javascript.getSummary());
  console.log(git.getSummary());
  console.log(javascript instanceof Course);
}

Output / practice checklist

Two course summaries and true for the instanceof check.
