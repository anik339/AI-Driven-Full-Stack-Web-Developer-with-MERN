# Task 48 — Write Small Unit Tests for a Class

**Track:** Testing fundamentals  
**Focus:** unit testing · assertions · arrange act assert

## Problem

Write a tiny assert helper and test a Cart class for adding items, calculating totals, and rejecting invalid quantities.

## Requirements

1. Read the problem and write down your own plan before opening the solution.
2. Complete the requested behavior and test at least one normal case.
3. Test one edge case or invalid input where relevant.
4. Explain why the solution works in your own words.

## Run and review

- Open `index.html` with VS Code Live Server.
- Click **Run example** to see the reference output, then inspect `script.js` line by line.
- Read the comments before copying or adapting the reference solution.

## Reference result

Both assertions print PASS. A failing assertion throws an error with a useful message.

## Stretch challenge

Add tests for empty carts, invalid quantity, and a second product with a different price.
