Problem statement

Write a tiny assert helper and test a Cart class for adding items, calculating totals, and rejecting invalid quantities.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add tests for empty carts, invalid quantity, and a second product with a different price.

Expected behavior

Both assertions print PASS. A failing assertion throws an error with a useful message.

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  // A tiny assertion helper keeps this browser example dependency-free.
  function assertEqual(actual, expected, label) {
    if (actual !== expected) throw new Error(`${label}: expected ${expected}, received ${actual}`);
    console.log(`PASS: ${label}`);
  }

  class Cart {
    #items = [];
    add(price, quantity) {
      if (price < 0 || quantity <= 0) throw new Error("Invalid cart item");
      this.#items.push({ price, quantity });
    }
    total() { return this.#items.reduce((sum, item) => sum + item.price * item.quantity, 0); }
    get count() { return this.#items.reduce((sum, item) => sum + item.quantity, 0); }
  }

  // Arrange: create a clean cart for this test.
  const cart = new Cart();
  // Act: add one item.
  cart.add(10, 2);
  // Assert: verify the public behavior.
  assertEqual(cart.total(), 20, "cart total");
  assertEqual(cart.count, 2, "cart item count");
}

Output / practice checklist

Both assertions print PASS. A failing assertion throws an error with a useful message.
