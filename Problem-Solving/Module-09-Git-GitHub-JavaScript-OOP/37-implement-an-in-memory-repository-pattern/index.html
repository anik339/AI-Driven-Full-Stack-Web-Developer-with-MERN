Problem statement

Build a ProductRepository with create, findById, update, and delete methods backed by an array.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Prevent duplicate IDs and add a findAll method that returns copies of every product.

Expected behavior

The product is created, updated to price 45, retrieved, and deleted successfully.

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  class ProductRepository {
    #products = [];
    create(product) {
      // Store a copy so callers cannot mutate repository data by reference.
      const saved = { ...product };
      this.#products.push(saved);
      return { ...saved };
    }
    findById(id) {
      const found = this.#products.find(product => product.id === id);
      return found ? { ...found } : null;
    }
    update(id, changes) {
      const index = this.#products.findIndex(product => product.id === id);
      if (index === -1) return null;
      this.#products[index] = { ...this.#products[index], ...changes };
      return { ...this.#products[index] };
    }
    delete(id) {
      const before = this.#products.length;
      this.#products = this.#products.filter(product => product.id !== id);
      return this.#products.length < before;
    }
  }

  const repository = new ProductRepository();
  repository.create({ id: 1, name: "Keyboard", price: 50 });
  console.log(repository.update(1, { price: 45 }));
  console.log(repository.findById(1));
  console.log("Deleted:", repository.delete(1));
}

Output / practice checklist

The product is created, updated to price 45, retrieved, and deleted successfully.
