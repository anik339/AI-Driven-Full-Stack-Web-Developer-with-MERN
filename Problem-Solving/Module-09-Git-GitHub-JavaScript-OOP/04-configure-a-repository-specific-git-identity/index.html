Task 04 · Git fundamentals

Configure a Repository-Specific Git Identity

Set an author identity only for a disposable learning repository.

Problem 4 of 50git config · local identity · commit metadata

Problem statement

Inside a disposable repository, configure a local name and placeholder email. Verify that the values are stored in the repository config, not your global config.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Compare `git config --local --list` with `git config --global --list` and explain the scope difference.

Expected behavior

The name and placeholder email are shown with local configuration scope. Replace the placeholders with your preferred commit identity when practising.

Focus: git config · local identity · commit metadata

PowerShell / Git command reference

These are Git commands for a terminal. The browser cannot execute them.

# First move into your disposable practice repository.
# These values apply only to this repository.
git config user.name "Your Name"
git config user.email "you@example.com"
# Verify the local values.
git config --local --get user.name
git config --local --get user.email
# Show the file that stores local repository configuration.
git config --local --list --show-origin

Output / practice checklist

Git commands are shown for manual execution in PowerShell. They are not executed by this webpage.
