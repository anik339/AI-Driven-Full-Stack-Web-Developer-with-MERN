Task 19 · GitHub collaboration

Add a Basic GitHub Actions Quality Check

Run a repeatable automated check when code is pushed or a pull request is opened.

Problem 19 of 50GitHub Actions · workflow YAML · CI
Read full task guide ↗Module 09 guide ↗

Problem statement

Create a workflow that checks JavaScript syntax on every push and pull request. Keep the workflow small and explain each step.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add a second job that runs unit tests only after a package.json test script exists.

Expected behavior

The workflow starts on push and pull_request events. The syntax step fails if a checked JavaScript file has a parse error.

Focus: GitHub Actions · workflow YAML · CI

PowerShell / Git command reference

These are Git commands for a terminal. The browser cannot execute them.

# Create this file: .github/workflows/javascript-check.yml
# GitHub Actions runs this workflow for pushes and pull requests.
name: JavaScript syntax check
on: [push, pull_request]
jobs:
  syntax:
    runs-on: ubuntu-latest
    steps:
      - name: Check out repository
        uses: actions/checkout@v4
      - name: Set up Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
      - name: Check JavaScript files
        run: |
          find frontend -name '*.js' -not -path '*/node_modules/*' -print0 | while IFS= read -r -d '' file; do
            node --check "$file"
          done
# Commit the workflow and inspect the Actions tab after pushing.

Output / practice checklist

Git commands are shown for manual execution in PowerShell. They are not executed by this webpage.
