Create Static Methods for Class-Level Utilities

Use static methods when behavior belongs to the class rather than an instance.

Problem statement

Create a Price class with a static format method and a static tax calculation method.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add a static method that rejects unsupported currency codes gracefully.

Expected behavior

$125.50 and 115.

Focus: static methods · utility methods · class API

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  class Price {
    // Static methods are called on the class itself.
    static format(amount, currency = "USD") {
      return new Intl.NumberFormat("en-US", { style: "currency", currency }).format(amount);
    }

    static addTax(amount, rate) {
      if (amount < 0 || rate < 0) throw new RangeError("Amount and rate must be non-negative.");
      return amount * (1 + rate);
    }
  }

  console.log(Price.format(125.5));
  console.log(Price.addTax(100, 0.15));
}

Output / practice checklist

$125.50 and 115.
