Implement an Observer Pattern for App State

Notify subscribers when a small state store changes.

Problem statement

Create a Store class with getState, setState, and subscribe. Notify all listeners whenever state changes.

What to practise

Stretch challenge

Expected behavior

The subscriber receives the first state update only; it receives nothing after unsubscribe.

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  class Store {
    #state;
    #listeners = new Set();
    constructor(initialState) { this.#state = initialState; }
    getState() { return { ...this.#state }; }
    subscribe(listener) {
      this.#listeners.add(listener);
      return () => this.#listeners.delete(listener);
    }
    setState(patch) {
      // Replace state instead of mutating the existing object.
      this.#state = { ...this.#state, ...patch };
      this.#listeners.forEach(listener => listener(this.getState()));
    }
  }

  const store = new Store({ theme: "light", count: 0 });
  const unsubscribe = store.subscribe(state => console.log("State changed:", state));
  store.setState({ count: 1 });
  unsubscribe();
  store.setState({ theme: "dark" });
}

Output / practice checklist

The subscriber receives the first state update only; it receives nothing after unsubscribe.
