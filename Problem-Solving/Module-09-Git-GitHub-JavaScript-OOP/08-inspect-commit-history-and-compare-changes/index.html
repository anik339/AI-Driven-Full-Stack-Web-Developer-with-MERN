Task 08 · Git fundamentals

Inspect Commit History and Compare Changes

Use history and diff commands to understand what changed and when.

Problem 8 of 50git log · git show · git diff

Problem statement

Inspect the latest commits, view one commit in detail, and compare the latest two commits.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Use `git log -- README.md` to inspect only the history that touched one file.

Expected behavior

You can identify commit hashes, authors, messages, changed files, and line-level differences.

Focus: git log · git show · git diff

PowerShell / Git command reference

These are Git commands for a terminal. The browser cannot execute them.

# Compact history with branch decorations.
git log --oneline --graph --decorate -10
# Show the latest commit and its changed files.
git show --stat HEAD
# Show the complete latest commit patch.
git show HEAD
# Compare the latest commit with its parent (requires at least two commits).
git diff HEAD~1 HEAD

Output / practice checklist

Git commands are shown for manual execution in PowerShell. They are not executed by this webpage.
