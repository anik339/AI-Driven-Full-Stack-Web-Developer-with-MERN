Send Notifications Through Multiple Channels

Use polymorphism to send a message through different notification adapters.

Problem 44 of 50polymorphism · interface contract · adapter
Read full task guide ↗Module 09 guide ↗

Problem statement

Create EmailChannel, SMSChannel, and ConsoleChannel classes with a send method. Use one NotificationService to deliver through any channel.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add a channel that stores messages in memory and test it without changing NotificationService.

Expected behavior

Three channels deliver the same message using their own implementation.

Focus: polymorphism · interface contract · adapter

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  class EmailChannel {
    send(message) { return `Email sent: ${message}`; }
  }
  class SMSChannel {
    send(message) { return `SMS sent: ${message}`; }
  }
  class ConsoleChannel {
    send(message) { return `Console notice: ${message}`; }
  }
  class NotificationService {
    constructor(channel) { this.channel = channel; }
    notify(message) {
      // The service relies on the send() contract, not a concrete channel.
      return this.channel.send(message);
    }
  }

  [new EmailChannel(), new SMSChannel(), new ConsoleChannel()].forEach(channel => {
    console.log(new NotificationService(channel).notify("Build completed"));
  });
}

Output / practice checklist

Three channels deliver the same message using their own implementation.
