Problem statement

Create an InsufficientFundsError and use it in a BankAccount withdrawal method. Catch the error and display its name and message.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add InvalidAmountError for zero, negative, or non-numeric withdrawal amounts.

Expected behavior

The catch block identifies InsufficientFundsError and prints the requested and available amounts.

Focus: extends Error · custom errors · try/catch

Commented JavaScript solution (study after attempting)

function runSolution() {
  // Custom errors make expected business failures easy to identify.
  class InsufficientFundsError extends Error {
    constructor(requested, available) {
      super(`Requested ${requested}, but only ${available} is available.`);
      this.name = "InsufficientFundsError";
    }
  }

  class BankAccount {
    constructor(balance) { this.balance = balance; }
    withdraw(amount) {
      if (amount > this.balance) {
        throw new InsufficientFundsError(amount, this.balance);
      }
      this.balance -= amount;
      return this.balance;
    }
  }

  try {
    new BankAccount(50).withdraw(80);
  } catch (error) {
    // Check the error type before choosing a recovery action.
    if (error instanceof InsufficientFundsError) {
      console.log(`${error.name}: ${error.message}`);
    } else {
      throw error; // Do not hide unexpected programming errors.
    }
  }
}

Output / practice checklist
