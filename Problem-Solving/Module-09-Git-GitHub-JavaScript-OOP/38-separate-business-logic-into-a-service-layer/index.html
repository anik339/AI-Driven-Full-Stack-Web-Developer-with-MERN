Problem statement

Create a RegistrationService that validates user input and delegates persistence to a repository.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add a duplicate-email check and keep that rule inside the service layer.

Expected behavior

A normalized user object is stored with a lowercase email.

Focus: service layer · single responsibility · validation

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  const repository = {
    users: [],
    save(user) { this.users.push(user); return user; }
  };

  class RegistrationService {
    constructor(userRepository) { this.repository = userRepository; }

    register(input) {
      // Business rules belong in the service, not in the storage adapter.
      const name = String(input.name ?? "").trim();
      const email = String(input.email ?? "").trim().toLowerCase();
      if (name.length < 2) throw new Error("Name must contain at least 2 characters.");
      if (!/^[^@\s]+@[^@\s]+\.[^@\s]+$/.test(email)) throw new Error("Enter a valid email.");
      return this.repository.save({ id: this.repository.users.length + 1, name, email });
    }
  }

  const service = new RegistrationService(repository);
  console.log(service.register({ name: "Anik", email: "ANIK@example.com" }));
}

Output / practice checklist

A normalized user object is stored with a lowercase email.
