Problem statement

Write a createProduct function that validates name, price, and stock before returning a normalized product object.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Return all validation errors together instead of stopping at the first invalid field.

Expected behavior

A normalized product object is returned; invalid data is rejected with a clear message.

Focus: guard clauses · Number.isFinite · validation

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  function createProduct(input) {
    // Guard clauses keep invalid data from entering the application.
    const name = String(input.name ?? "").trim();
    const price = Number(input.price);
    const stock = Number(input.stock);

    if (name.length < 2) throw new TypeError("Product name is too short.");
    if (!Number.isFinite(price) || price < 0) throw new TypeError("Price must be a non-negative number.");
    if (!Number.isInteger(stock) || stock < 0) throw new TypeError("Stock must be a non-negative integer.");

    return { name, price, stock };
  }

  console.log(createProduct({ name: "Keyboard", price: "49.99", stock: "12" }));
  try {
    createProduct({ name: "X", price: -1, stock: 2 });
  } catch (error) {
    console.log("Validation:", error.message);
  }
}
