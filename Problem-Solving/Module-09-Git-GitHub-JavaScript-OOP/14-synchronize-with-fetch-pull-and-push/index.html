Task 14 · GitHub collaboration

Synchronize with Fetch, Pull, and Push

Move commits safely between your local branch and GitHub.

Problem 14 of 50git fetch · git pull · git push · upstream
Read full task guide ↗Module 09 guide ↗

Problem statement

Fetch remote updates, inspect the branch state, pull with fast-forward-only behavior, and push your own branch with upstream tracking.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Use `git log --oneline --left-right HEAD...origin/main` to inspect commits on each side before integrating.

Expected behavior

Fetch updates remote-tracking references; pull integrates remote commits; push publishes local commits.

Focus: git fetch · git pull · git push · upstream

PowerShell / Git command reference

These are Git commands for a terminal. The browser cannot execute them.

# Download remote references without merging them into your branch.
git fetch origin
# Compare your local branch with its upstream.
git status -sb
# Integrate remote changes only when a fast-forward is possible.
git pull --ff-only
# Publish your current branch and set its upstream on first push.
git push -u origin main
# On later pushes, the upstream can be used automatically.
git push

Output / practice checklist

Git commands are shown for manual execution in PowerShell. They are not executed by this webpage.
