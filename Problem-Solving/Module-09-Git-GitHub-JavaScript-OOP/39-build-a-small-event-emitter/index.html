Build a Small Event Emitter

Problem statement

Implement an EventEmitter with on, emit, and off methods. Register two listeners, emit an event, and remove one listener.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add a once(eventName, callback) method that automatically unsubscribes after the first event.

Expected behavior

Both listeners run for order 101; only the toast listener runs for order 102.

Focus: observer pattern · publish/subscribe · unsubscribe

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  class EventEmitter {
    #listeners = new Map();

    on(eventName, callback) {
      // Each event stores a set so the same callback is not registered twice.
      if (!this.#listeners.has(eventName)) this.#listeners.set(eventName, new Set());
      this.#listeners.get(eventName).add(callback);
      return () => this.off(eventName, callback); // Return an unsubscribe function.
    }

    emit(eventName, payload) {
      this.#listeners.get(eventName)?.forEach(callback => callback(payload));
    }

    off(eventName, callback) {
      this.#listeners.get(eventName)?.delete(callback);
    }
  }

  const bus = new EventEmitter();
  const logOrder = order => console.log(`Order received: ${order.id}`);
  const showToast = order => console.log(`Toast: ${order.status}`);
  const unsubscribe = bus.on("order:created", logOrder);
  bus.on("order:created", showToast);
  bus.emit("order:created", { id: 101, status: "created" });
  unsubscribe();
  bus.emit("order:created", { id: 102, status: "created" });
}

Output / practice checklist

Both listeners run for order 101; only the toast listener runs for order 102.
