Demonstrate Polymorphism with Method Overriding

Call one shared method on different objects and allow each type to respond.

Problem statement

Create EmailNotification and SMSNotification classes with a send method. Process both through one function.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add a PushNotification class without changing the deliver function.

Expected behavior

Both notification types handle the same message through their own send implementation.

Focus: polymorphism · overriding · common interface

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  class EmailNotification {
    constructor(address) { this.address = address; }
    send(message) {
      return `Email to ${this.address}: ${message}`;
    }
  }

  class SMSNotification {
    constructor(phone) { this.phone = phone; }
    send(message) {
      return `SMS to ${this.phone}: ${message}`;
    }
  }

  // The caller depends on the send() contract, not a concrete class.
  function deliver(notification, message) {
    console.log(notification.send(message));
  }

  deliver(new EmailNotification("user@example.com"), "Your order shipped.");
  deliver(new SMSNotification("+8801000000000"), "Your order shipped.");
}

Output / practice checklist

Both notification types handle the same message through their own send implementation.
