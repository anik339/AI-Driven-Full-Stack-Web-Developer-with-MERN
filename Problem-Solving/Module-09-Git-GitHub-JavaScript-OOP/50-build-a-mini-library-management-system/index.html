Problem statement

Build Book, LibraryMember, and Library classes. Support adding books, registering members, borrowing available books, and returning books.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Add a maximum of three borrowed books per member, a search method, and a small test suite.

Expected behavior

Anik borrows Clean Code and then returns it. Invalid borrow/return operations are rejected.

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  class Book {
    constructor(id, title) { this.id = id; this.title = title; this.isBorrowed = false; }
  }
  class LibraryMember {
    constructor(id, name) { this.id = id; this.name = name; this.borrowedBookIds = new Set(); }
  }
  class Library {
    #books = new Map();
    #members = new Map();
    addBook(book) { this.#books.set(book.id, book); }
    register(member) { this.#members.set(member.id, member); }
    borrow(bookId, memberId) {
      const book = this.#books.get(bookId);
      const member = this.#members.get(memberId);
      if (!book || !member) throw new Error("Book or member not found");
      if (book.isBorrowed) throw new Error("Book is already borrowed");
      book.isBorrowed = true;
      member.borrowedBookIds.add(bookId);
      return `${member.name} borrowed ${book.title}`;
    }
    returnBook(bookId, memberId) {
      const book = this.#books.get(bookId);
      const member = this.#members.get(memberId);
      if (!book || !member || !member.borrowedBookIds.has(bookId)) throw new Error("Invalid return");
      book.isBorrowed = false;
      member.borrowedBookIds.delete(bookId);
      return `${member.name} returned ${book.title}`;
    }
  }

  const library = new Library();
  library.addBook(new Book(1, "Clean Code"));
  library.register(new LibraryMember(7, "Anik"));
  console.log(library.borrow(1, 7));
  console.log(library.returnBook(1, 7));
}

Output / practice checklist

Anik borrows Clean Code and then returns it. Invalid borrow/return operations are rejected.
