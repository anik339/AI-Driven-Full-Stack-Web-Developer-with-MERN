Problem statement

Create one introduce function and call it with two different profile objects. Use call, apply, and bind.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Detach a method from an object and observe the difference between a regular function and a bound function.

Expected behavior

The same function produces different introductions because each call supplies a different this value.

Focus: call · apply · bind · function context

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  // This function can be reused by any object with name and role properties.
  function introduce(city, greeting) {
    return `${greeting}, I am ${this.name}, a ${this.role} in ${city}.`;
  }

  const firstProfile = { name: "Anik", role: "Developer" };
  const secondProfile = { name: "Maya", role: "Designer" };

  // call passes arguments one by one.
  console.log(introduce.call(firstProfile, "Dhaka", "Hello"));
  // apply passes arguments as an array.
  console.log(introduce.apply(secondProfile, ["Chattogram", "Hi"]));
  // bind returns a new function with a permanently selected context.
  const introduceAnik = introduce.bind(firstProfile, "Dhaka");
  console.log(introduceAnik("Welcome"));
}

Output / practice checklist

The same function produces different introductions because each call supplies a different this value.
