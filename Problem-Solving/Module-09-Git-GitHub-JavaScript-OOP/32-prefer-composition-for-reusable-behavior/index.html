Problem statement

Create a UserService by composing a userRepository and logger. The service should save a user and log the action.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Replace the logger with a silent test logger without changing UserService.

Expected behavior

The logger prints the registration message and the repository contains one user.

Focus: composition · dependency collaboration · separation of concerns

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  // A repository owns data access behavior.
  const userRepository = {
    users: [],
    save(user) { this.users.push(user); return user; }
  };

  // A logger is another small collaborator.
  const logger = {
    info(message) { console.log(`[INFO] ${message}`); }
  };

  // UserService composes both dependencies rather than inheriting from them.
  class UserService {
    constructor(repository, log) {
      this.repository = repository;
      this.log = log;
    }

    register(user) {
      const saved = this.repository.save(user);
      this.log.info(`Registered ${saved.name}`);
      return saved;
    }
  }

  const service = new UserService(userRepository, logger);
  service.register({ id: 1, name: "Anik" });
  console.log("Saved users:", userRepository.users.length);
}

Output / practice checklist

The logger prints the registration message and the repository contains one user.
