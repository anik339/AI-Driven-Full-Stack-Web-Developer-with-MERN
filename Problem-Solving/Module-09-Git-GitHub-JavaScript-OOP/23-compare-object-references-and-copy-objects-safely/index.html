Compare Object References and Copy Objects Safely

Understand shallow copies and when nested data remains shared.

Problem 23 of 50reference · spread syntax · structuredClone

Problem statement

Create an object with nested settings. Make a shallow copy and a deep copy, update nested values, and compare the results.

What to practise

  • Understand the concept before writing code.
  • Use clear names and small, focused steps.
  • Test normal behavior and at least one edge case.
  • Explain the solution without relying on comments alone.

Stretch challenge

Try cloning an object containing a function and explain why structuredClone rejects non-cloneable values.

Expected behavior

The shallow update also changes original.settings.theme; the deep-copy update does not.

Focus: reference · spread syntax · structuredClone

Commented JavaScript solution (study after attempting)

Try the problem yourself before opening this reference solution.

function runSolution() {
  const original = {
    name: "Project Alpha",
    settings: { theme: "dark", notifications: true }
  };

  // Spread creates a shallow copy: nested objects are still shared.
  const shallowCopy = { ...original };
  shallowCopy.settings.theme = "light";
  console.log("Original after shallow update:", original.settings.theme);

  // structuredClone creates an independent deep copy for cloneable data.
  const deepCopy = structuredClone(original);
  deepCopy.settings.theme = "contrast";
  console.log("Original after deep update:", original.settings.theme);
  console.log("Deep copy:", deepCopy.settings.theme);
}

Output / practice checklist

The shallow update also changes original.settings.theme; the deep-copy update does not.
