## What each task contains

- Modules 01–04 and 06–08 primarily provide runnable HTML/CSS/JavaScript examples with a README.
- Module 05 is a workflow-practice set: task instructions, AI prompts, acceptance checklists, Git notes and sample project files where provided. It is designed to practise repository inspection, planning, implementation review, testing and GitHub habits rather than to present 50 standalone web apps.
- Some browser examples need VS Code Live Server. Tailwind CDN and Fetch/API tasks need an internet connection.

## Run and study

1. Open the repository root in VS Code.
2. Open `Problem-Solving/index.html` and choose a module.
3. Read the task's `README.md` first.
4. For runnable examples, right-click `index.html` and choose **Open with Live Server**.
5. For Module 05, read `TASK.md`, inspect `PROMPT.md`, work carefully, and complete `ACCEPTANCE_CHECKLIST.md`.
6. Use browser DevTools → Console to inspect errors and output.

The examples are reference material. Try the task independently and explain your solution before marking it complete.
