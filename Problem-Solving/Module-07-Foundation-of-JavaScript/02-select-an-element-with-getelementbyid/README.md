# Problem 02: Select an Element with getElementById()

## Task
Select an element by its unique id and change its text.

## Main concept
getElementById(), id

## Expected output
The heading changes to Welcome to JavaScript DOM!

## Explanation
getElementById() returns the element with the matching id. An id should be unique on a page.

## Practice challenge
Create a paragraph with id my-message and update it.
