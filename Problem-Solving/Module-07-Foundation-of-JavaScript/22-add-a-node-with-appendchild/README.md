# Problem 22: Add a Node with appendChild()

## Task
Create and append one list item using appendChild().

## Main concept
appendChild()

## Expected output
The list item is added; returnedNode === item is true.

## Explanation
appendChild() adds one node and returns it. If the node already exists elsewhere, it is moved rather than copied.

## Practice challenge
Append a paragraph to a section and inspect section.children.length.
