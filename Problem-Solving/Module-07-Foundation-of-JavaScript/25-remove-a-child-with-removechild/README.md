# Problem 25: Remove a Child with removeChild()

## Task
Remove the second item from a list.

## Main concept
removeChild()

## Expected output
Remaining: HTML, JavaScript; Removed: CSS.

## Explanation
parent.removeChild(child) removes and returns the child node. The child must belong to that parent.

## Practice challenge
Remove the first item from a list.
