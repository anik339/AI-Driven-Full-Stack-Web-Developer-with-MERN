# Problem 35: Handle Keyboard Events

## Task
Display the key name when a user presses a key in an input.

## Main concept
keydown, event.key, event.code

## Expected output
Pressing a key displays its key and physical code.

## Explanation
keydown fires when a key is pressed. event.key gives the key name; event.code identifies the physical key.

## Practice challenge
Detect Enter and show a message.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
