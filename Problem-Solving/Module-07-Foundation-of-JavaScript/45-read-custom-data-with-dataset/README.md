# Problem 45: Read Custom Data with dataset

## Task
Read product id and name from data-* attributes.

## Main concept
data attributes, dataset

## Expected output
Clicking the button displays P-104 and Wireless Mouse.

## Explanation
data-product-id becomes dataset.productId. Dataset values are strings.

## Practice challenge
Add data-price to a product button and display it when clicked.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.

## Files
- `index.html` — lesson, output and code viewer.
- `styles.css` — page styling.
- `script.js` — complete JavaScript solution with comments.
