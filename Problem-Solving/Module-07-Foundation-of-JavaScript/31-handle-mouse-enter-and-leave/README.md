# Problem 31: Handle Mouse Enter and Leave

## Task
Change a panel's message when the pointer enters or leaves.

## Main concept
mouseenter, mouseleave

## Expected output
Moving the pointer in and out updates the message.

## Explanation
mouseenter fires when the pointer enters an element; mouseleave fires when it leaves.

## Practice challenge
Change a button's background on mouseenter and restore it on mouseleave.
