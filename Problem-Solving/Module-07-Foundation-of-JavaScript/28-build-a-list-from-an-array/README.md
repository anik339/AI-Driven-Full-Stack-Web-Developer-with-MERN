# Problem 28: Build a List from an Array

## Task
Render four skills from a JavaScript array.

## Main concept
Array iteration, createElement(), append()

## Expected output
A four-item skill list is displayed.

## Explanation
forEach() visits each array value. createElement() creates each li and append() places it in the list.

## Practice challenge
Render an array of five student names.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
