# Problem 08: Read and Change Text with innerText

## Task
Change the visible text of a paragraph.

## Main concept
innerText

## Expected output
The visible paragraph shows the updated sentence.

## Explanation
innerText represents rendered text and considers visual visibility. textContent reads text from the DOM regardless of visual rendering.

## Practice challenge
Compare innerText and textContent after adding a hidden span.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
