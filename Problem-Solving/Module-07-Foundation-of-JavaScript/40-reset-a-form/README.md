# Problem 40: Reset a Form

## Task
Restore a form control to its initial value.

## Main concept
form.reset(), reset event

## Expected output
The input returns to Anik after clicking Reset form.

## Explanation
form.reset() or a type=reset button restores controls to their default values.

## Practice challenge
Create a form with name and email fields and reset both.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
