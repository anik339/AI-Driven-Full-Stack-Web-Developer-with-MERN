# Problem 26: Replace an Element

## Task
Replace an old heading with a new heading.

## Main concept
replaceWith()

## Expected output
The old title is replaced by New title.

## Explanation
replaceWith() replaces an element in its parent with a node or text.

## Practice challenge
Replace a paragraph with a button.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
