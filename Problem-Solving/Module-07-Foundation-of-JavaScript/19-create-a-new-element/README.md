# Problem 19: Create a New Element

## Task
Create a heading and paragraph using JavaScript.

## Main concept
document.createElement()

## Expected output
A heading and paragraph are displayed.

## Explanation
createElement() creates a node in memory. It becomes visible when added to the document.

## Practice challenge
Create a button and set its textContent.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
