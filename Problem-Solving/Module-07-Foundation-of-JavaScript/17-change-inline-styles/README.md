# Problem 17: Change Inline Styles

## Task
Change a card's background, padding and border radius.

## Main concept
element.style

## Expected output
A light-blue card appears with padding and rounded corners.

## Explanation
JavaScript style property names use camelCase. Reusable visual styles are usually better placed in CSS classes.

## Practice challenge
Set fontSize and color on a heading.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.

## Files
- `index.html` — lesson, output and code viewer.
- `styles.css` — page styling.
- `script.js` — complete JavaScript solution with comments.
