# Problem 23: Insert Before Another Element

## Task
Insert a new node before a specific list item.

## Main concept
insertBefore()

## Expected output
The order becomes One → Two → Three.

## Explanation
insertBefore(newNode, referenceNode) inserts the new node immediately before the reference node.

## Practice challenge
Insert a paragraph before the last paragraph in a section.
