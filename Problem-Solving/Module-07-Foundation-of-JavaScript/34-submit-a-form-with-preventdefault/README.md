# Problem 34: Submit a Form with preventDefault()

## Task
Show a welcome message after a form is submitted without reloading.

## Main concept
submit event, preventDefault()

## Expected output
Submitting a name displays Welcome, [name]!

## Explanation
The submit event belongs to the form. preventDefault() stops the browser's normal navigation so JavaScript can handle the data.

## Practice challenge
Create an email form and display the entered email.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
