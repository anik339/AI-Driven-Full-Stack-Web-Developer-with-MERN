# Problem 30: Handle a Double-Click Event

## Task
Change a card after it is double-clicked.

## Main concept
dblclick event

## Expected output
Double-clicking the card displays Double-click detected!

## Explanation
dblclick fires after a rapid double-click. A normal click is usually better for primary actions.

## Practice challenge
Show a hidden note after double-clicking a heading.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
