# Problem 13: Add a CSS Class

## Task
Add a class without overwriting existing classes.

## Main concept
classList.add()

## Expected output
The element has demo-card and highlighted classes.

## Explanation
classList.add() adds a class while preserving existing classes. CSS defines how the class looks.

## Practice challenge
Add two classes to one element.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.

## Files
- `index.html` — lesson, output and code viewer.
- `styles.css` — page styling.
