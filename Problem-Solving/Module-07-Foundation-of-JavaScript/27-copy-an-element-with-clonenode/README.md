# Problem 27: Copy an Element with cloneNode()

## Task
Clone a card including its child elements.

## Main concept
cloneNode(), deep clone

## Expected output
Two cards appear: Original card and Cloned card.

## Explanation
cloneNode(true) makes a deep clone. Event listeners attached with addEventListener are not copied.

## Practice challenge
Clone a list item and change the copy's text.
