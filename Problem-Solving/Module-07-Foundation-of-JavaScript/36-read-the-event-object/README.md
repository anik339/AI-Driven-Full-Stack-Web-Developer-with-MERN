# Problem 36: Read the Event Object

## Task
Display event type, target and timestamp when a button is clicked.

## Main concept
event, event.type, event.target, timeStamp

## Expected output
The output shows click, BUTTON and a timestamp.

## Explanation
The browser passes an Event object to the callback. It contains details about the event.

## Practice challenge
Display event.type and event.target for a keyboard event.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
