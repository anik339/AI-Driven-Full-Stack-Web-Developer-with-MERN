# Problem 04: Select Multiple Elements with querySelectorAll()

## Task
Select every list item and add its position number.

## Main concept
querySelectorAll(), NodeList, forEach()

## Expected output
Three list items are numbered 1, 2 and 3.

## Explanation
querySelectorAll() returns a NodeList. It can be looped through with forEach().
