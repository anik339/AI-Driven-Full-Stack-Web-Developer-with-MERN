# Problem 07: Change Text with textContent

## Task
Replace an element's plain text.

## Main concept
textContent

## Expected output
The paragraph displays the new sentence.

## Explanation
textContent changes plain text and does not parse a string as HTML. It is a safe default for text.

## Practice challenge
Create a heading and change its text using textContent.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
