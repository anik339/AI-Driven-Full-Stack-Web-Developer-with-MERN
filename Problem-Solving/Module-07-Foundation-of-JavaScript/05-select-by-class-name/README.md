# Problem 05: Select by Class Name

## Task
Find every element with the class fruit.

## Main concept
getElementsByClassName(), HTMLCollection

## Expected output
Found 3: Apple, Mango, Banana.

## Explanation
getElementsByClassName() takes a class name without a dot and returns a live HTMLCollection.

## Practice challenge
Select all elements with class student and count them.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
