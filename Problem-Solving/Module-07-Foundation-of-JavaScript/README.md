# Module 7 — DOM Manipulation and Events — 50 JavaScript Problems

50 practical problems covering the DOM tree, selecting elements, text and attributes, classes and styles, creating and removing elements, mouse and keyboard events, forms, event objects, event delegation and small interactive interfaces.

## Study method
1. Read the task and predict the output.
2. Run `index.html` with VS Code Live Server.
3. Click **Run Solution**.
4. Read `script.js` carefully; comments explain the important lines.
5. Read the expected output and explanation.
6. Try the extra challenge without copying the solution.
