# Problem 42: Check Document Ready State

## Task
Read the browser's current document loading state.

## Main concept
document.readyState, defer

## Expected output
Usually the readyState is interactive or complete.

## Explanation
loading means parsing is in progress; interactive means parsing is complete; complete means dependent resources have loaded.

## Practice challenge
Add a DOMContentLoaded listener to a separate page.
