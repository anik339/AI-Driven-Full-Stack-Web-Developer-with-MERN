# Problem 37: Understand target and currentTarget

## Task
Compare the element that started an event with the element whose listener is running.

## Main concept
event.target, event.currentTarget

## Expected output
Clicking the inner button shows target BUTTON and currentTarget DIV.

## Explanation
target is where the event originated. currentTarget is the element whose listener is currently executing.

## Practice challenge
Add a span inside the button and compare the values.
