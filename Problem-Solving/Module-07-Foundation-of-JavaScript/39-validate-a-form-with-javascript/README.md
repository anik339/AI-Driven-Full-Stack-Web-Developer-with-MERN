# Problem 39: Validate a Form with JavaScript

## Task
Require a name and a valid email before showing success.

## Main concept
required, trim(), checkValidity()

## Expected output
An empty name or invalid email is rejected; valid values show a welcome message.

## Explanation
Use built-in browser validation and add JavaScript checks for your own rules.

## Practice challenge
Require a password of at least eight characters.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.

## Files
- `index.html` — lesson, output and code viewer.
- `styles.css` — page styling.
- `script.js` — complete JavaScript solution with comments.
- Supporting files: None
