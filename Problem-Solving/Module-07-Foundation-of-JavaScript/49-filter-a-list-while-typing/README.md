# Problem 49: Filter a List While Typing

## Task
Show only skills that match the search field.

## Main concept
input event, includes(), toLowerCase()

## Expected output
Typing 'js' displays JavaScript; clearing the field displays all skills.

## Explanation
Convert both the search query and each item to lowercase for a case-insensitive search.

## Practice challenge
Add a category dropdown and combine it with the text filter.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
