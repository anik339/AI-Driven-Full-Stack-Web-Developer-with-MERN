# Problem 41: Handle Focus and Blur

## Task
Show a message when an input receives or loses focus.

## Main concept
focus, blur

## Expected output
Focusing the input and then clicking elsewhere updates the output.

## Explanation
focus fires when an element receives focus; blur fires when it loses focus.

## Practice challenge
Show a hint when a password field receives focus.

## How to run
