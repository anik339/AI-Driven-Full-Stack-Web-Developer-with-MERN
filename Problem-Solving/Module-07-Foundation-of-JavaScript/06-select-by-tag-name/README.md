# Problem 06: Select by Tag Name

## Task
Count all paragraph elements in a container.

## Main concept
getElementsByTagName()

## Expected output
Paragraph count: 2, followed by both paragraph texts.

## Explanation
getElementsByTagName() accepts a tag name such as p, h1, li or button.

## Practice challenge
Count all h2 elements on a page.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
