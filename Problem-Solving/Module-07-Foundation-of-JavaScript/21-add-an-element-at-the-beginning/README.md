# Problem 21: Add an Element at the Beginning

## Task
Insert a new item before existing children.

## Main concept
prepend()

## Expected output
The order becomes First → Second → Third.

## Explanation
prepend() inserts nodes or text at the beginning of a parent element.

## Practice challenge
Prepend a new notification to a notification list.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
