# Problem 29: Handle a Click Event

## Task
Change a message when a button is clicked.

## Main concept
addEventListener(), click

## Expected output
Clicking the demo button changes its text and the output.

## Explanation
addEventListener('click', callback) attaches a handler that runs when the user clicks the element.

## Practice challenge
Create a button that increases a number every time it is clicked.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
