# Problem 12: Check and Remove an Attribute

## Task
Check whether a button is disabled, then remove that attribute.

## Main concept
hasAttribute(), removeAttribute()

## Expected output
Disabled before: true; Disabled after: false.

## Explanation
hasAttribute() returns a Boolean. removeAttribute() removes the named attribute.

## Practice challenge
Create a link with a title attribute, check it, then remove it.

## How to run
