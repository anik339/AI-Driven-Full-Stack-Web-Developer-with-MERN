# Problem 43: Respond to Window Resize

## Task
Display the browser window dimensions and update them when resized.

## Main concept
resize, innerWidth, innerHeight

## Expected output
Window dimensions appear and update when the browser is resized.

## Explanation
resize is a window event. Use it for calculations only when CSS alone is not enough.

## Practice challenge
Show a message when the viewport becomes narrower than 600 pixels.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
