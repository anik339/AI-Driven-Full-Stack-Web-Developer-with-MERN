# Problem 47: Build an Interactive Counter

## Task
Use plus and minus buttons to update a number on the page.

## Main concept
click event, textContent, state variable

## Expected output
Plus and minus buttons change the counter.

## Explanation
The count is stored in a variable. Each click changes the variable and render() updates the page.

## Practice challenge
Add a Reset button and prevent the counter from going below zero.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.

## Files
- `index.html` — lesson, output and code viewer.
- `styles.css` — page styling.
- `script.js` — complete JavaScript solution with comments.
- Supporting files: None
