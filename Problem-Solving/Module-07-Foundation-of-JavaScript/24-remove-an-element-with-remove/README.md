# Problem 24: Remove an Element with remove()

## Task
Remove an element directly from the DOM.

## Main concept
element.remove()

## Expected output
Paragraph still connected? false.

## Explanation
remove() detaches the element from its parent. A JavaScript variable can still refer to the detached element.

## Practice challenge
Create a button and remove it after it is clicked.
