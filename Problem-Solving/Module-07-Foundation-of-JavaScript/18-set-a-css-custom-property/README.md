# Problem 18: Set a CSS Custom Property

## Task
Set a CSS variable and use it as a card's background.

## Main concept
style.setProperty(), CSS custom properties

## Expected output
A pale green card appears.

## Explanation
setProperty() accepts a CSS property name. It is useful for custom properties that begin with --.

## Practice challenge
Change --theme-color on document.documentElement.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
