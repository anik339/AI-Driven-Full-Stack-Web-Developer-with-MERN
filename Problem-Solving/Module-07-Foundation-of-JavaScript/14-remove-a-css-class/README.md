# Problem 14: Remove a CSS Class

## Task
Remove only the temporary class from an element.

## Main concept
classList.remove()

## Expected output
The temporary class is removed; demo-card and active remain.

## Explanation
classList.remove() removes only the class names supplied to it.

## Practice challenge
Remove the class inactive from a button.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
