# Problem 03: Select the First Match with querySelector()

## Task
Select the first element with the class notice.

## Main concept
querySelector(), CSS selectors

## Expected output
Only the first notice changes.

## Explanation
querySelector() accepts CSS selector syntax and returns the first matching element.

## Practice challenge
Select the first button inside a section and change its text.
