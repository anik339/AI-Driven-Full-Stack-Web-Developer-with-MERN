# Problem 33: Handle a Select Change Event

## Task
Display the course selected in a dropdown.

## Main concept
change event, select.value

## Expected output
Selecting JavaScript displays Selected course: javascript.

## Explanation
The change event fires when a select value changes. Read it using select.value.

## Practice challenge
Create a country dropdown and display the selected country.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
