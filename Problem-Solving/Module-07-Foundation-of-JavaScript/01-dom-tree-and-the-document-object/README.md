# Problem 01: DOM Tree and the document Object

## Task
Read the page title and inspect the main document elements.

## Main concept
document, documentElement, body

## Expected output
The page title, HTML and BODY are displayed.

## Explanation
document represents the loaded page. documentElement is the HTML root; body is the page body.

## Practice challenge
Inspect document.head and document.body.children.
