# Problem 38: Use Event Delegation

## Task
Handle clicks on all list items using one listener on their parent.

## Main concept
event bubbling, closest(), delegation

## Expected output
Clicking any item displays the selected skill.

## Explanation
Event delegation uses bubbling. One parent listener can handle child elements added later.

## Practice challenge
Build a list with five buttons and handle all clicks from one parent.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
