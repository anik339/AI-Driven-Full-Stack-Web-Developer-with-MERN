# Problem 10: Read an Attribute with getAttribute()

## Task
Read the alt attribute of a sample image.

## Main concept
getAttribute()

## Expected output
Alt attribute: A sample landscape image.

## Explanation
getAttribute() returns an attribute value as a string, or null if it does not exist.

## Practice challenge
Read the href attribute from a link.
