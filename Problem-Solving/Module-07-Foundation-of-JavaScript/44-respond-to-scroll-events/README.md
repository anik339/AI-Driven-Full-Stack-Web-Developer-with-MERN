# Problem 44: Respond to Scroll Events

## Task
Display the scroll position inside a scrollable box.

## Main concept
scroll event, scrollTop

## Expected output
Scrolling inside the box updates the scrollTop value.

## Explanation
scrollTop tells how far an element has been scrolled vertically. The scroll event can fire frequently.

## Practice challenge
Show a scroll progress percentage using scrollTop and scrollHeight.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
