# Problem 48: Build a Simple To-Do List

## Task
Add tasks and delete them using event delegation.

## Main concept
createElement(), append(), click, event delegation

## Expected output
Tasks can be added and deleted without refreshing the page.

## Explanation
Each task is built with createElement. One delegated listener handles delete buttons added later.

## Practice challenge
Add a Complete button that toggles a completed class.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.

## Files
- `index.html` — lesson, output and code viewer.
- `styles.css` — page styling.
- `script.js` — complete JavaScript solution with comments.
- Supporting files: None
