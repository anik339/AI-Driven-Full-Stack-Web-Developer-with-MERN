# Problem 15: Toggle a CSS Class

## Task
Switch a class on and off with one method.

## Main concept
classList.toggle()

## Expected output
The first toggle returns true; the second returns false.

## Explanation
toggle() adds a missing class and removes an existing class. It returns whether the class is present after the operation.

## Practice challenge
Use toggle() to show and hide a message panel.
