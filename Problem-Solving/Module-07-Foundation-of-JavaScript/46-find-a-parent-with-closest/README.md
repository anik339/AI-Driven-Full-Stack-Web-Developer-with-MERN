# Problem 46: Find a Parent with closest()

## Task
Find the nearest product card that contains a clicked button.

## Main concept
closest()

## Expected output
Clicking the button finds the Keyboard card.

## Explanation
closest() checks the element itself and then its ancestors until a matching selector is found.

## Practice challenge
Use closest('.todo-item') to find the list item containing a delete button.
