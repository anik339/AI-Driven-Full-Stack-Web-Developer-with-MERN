# Problem 16: Check a Class with contains()

## Task
Check whether a card has a particular class.

## Main concept
classList.contains()

## Expected output
featured? true; hidden? false.

## Explanation
contains() checks class membership and returns true or false.

## Practice challenge
Check whether a navigation link has the class current.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.
