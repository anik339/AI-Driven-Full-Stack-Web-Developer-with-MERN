# Problem 11: Change an Attribute with setAttribute()

## Task
Set a link's href, target and rel attributes.

## Main concept
setAttribute()

## Expected output
The link opens example.com in a new tab.

## Explanation
setAttribute(name, value) creates or updates an attribute. rel='noopener noreferrer' is a useful safety setting for new tabs.

## Practice challenge
Set the title attribute of a button.
