# Problem 32: Handle Live Input

## Task
Display a character count as the user types.

## Main concept
input event, value

## Expected output
Character count updates on every keystroke.

## Explanation
The input event fires whenever the value changes due to user input. It is useful for live search and counters.

## Practice challenge
Show remaining characters for a 100-character message limit.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.

- `index.html` — lesson, output and code viewer.
