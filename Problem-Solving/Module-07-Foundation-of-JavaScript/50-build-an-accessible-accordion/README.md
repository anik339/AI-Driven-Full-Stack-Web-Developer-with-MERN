# Problem 50: Build an Accessible Accordion

## Task
Show or hide an answer when its question button is clicked.

## Main concept
click, hidden, aria-expanded

## Expected output
Clicking the question opens and closes its answer.

## Explanation
The hidden property controls visibility. aria-expanded communicates the current state to assistive technology.

## Practice challenge
Create a three-question accordion and allow only one answer open at a time.

## How to run
1. Open this problem folder in VS Code.
2. Start `index.html` with the **Live Server** extension.
3. Click **Run Solution** in the browser.
4. Open `script.js` in VS Code and read the comments.
5. Try the challenge without copying the solution.

## Files
- `index.html` — lesson, output and code viewer.
- `styles.css` — page styling.
