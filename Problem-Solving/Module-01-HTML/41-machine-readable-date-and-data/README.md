# Machine-Readable Date and Data

## Task
Use time and data for values with machine-readable meaning.

## Main concept
time datetime and data value

## Expected result
The visible date and product name are linked to machine-readable values.

## Explanation
time provides a machine-readable date/time; data pairs visible text with a machine-readable value.

## Try it yourself
Add a data element for a product price in a known currency.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
