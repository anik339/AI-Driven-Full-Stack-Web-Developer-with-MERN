# Valid HTML5 Document

## Task
Create a complete HTML5 page with language, character encoding, viewport and title.

## Main concept
doctype, html, head, body, lang, charset and viewport

## Expected result
A browser page displays the heading and paragraph without needing CSS.

## Explanation
Every HTML page should have a doctype, an html root, a head for metadata and a body for visible content.

## Try it yourself
Change the language to bn and write a short Bengali paragraph.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
