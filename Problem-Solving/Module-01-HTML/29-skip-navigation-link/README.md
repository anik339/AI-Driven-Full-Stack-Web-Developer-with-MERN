# Skip Navigation Link

## Task
Add a skip link that moves keyboard users to main content.

## Main concept
Fragment links and accessible navigation

## Expected result
A skip link appears before the navigation and targets main content.

## Explanation
A skip link helps keyboard users bypass repeated navigation and reach the main content quickly.

## Try it yourself
Add a footer landmark and test the page using the Tab key.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
