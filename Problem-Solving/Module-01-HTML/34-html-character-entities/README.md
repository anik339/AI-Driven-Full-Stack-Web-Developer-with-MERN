# HTML Character Entities

## Task
Display reserved characters and common symbols.

## Main concept
Named and numeric character references

## Expected result
Reserved characters and symbols display as text.

## Explanation
Character references allow reserved characters to be shown without being parsed as markup.

## Try it yourself
Add the non-breaking space entity and explain where it is useful.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
