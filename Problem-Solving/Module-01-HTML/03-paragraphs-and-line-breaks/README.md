# Paragraphs and Line Breaks

## Task
Use paragraphs for separate ideas and br only for meaningful line breaks.

## Main concept
p, br and address

## Expected result
Two paragraphs and a two-line address appear.

## Explanation
A paragraph represents a block of related text. br is for a meaningful line break, not page spacing.

## Try it yourself
Write a three-paragraph introduction and use br only in a postal address.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
