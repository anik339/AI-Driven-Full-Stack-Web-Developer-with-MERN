# Email and Telephone Links

## Task
Create mailto and tel links with readable labels.

## Main concept
mailto: and tel: URL schemes

## Expected result
The email link opens a mail application; the phone link may open a dialler on supported devices.

## Explanation
These links ask the device to handle an email or telephone action. Use a sample contact value for practice.

## Try it yourself
Add a mailto link with a subject query parameter.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
