# Canvas Fallback Content

## Task
Create a canvas element with meaningful fallback text.

## Main concept
canvas and fallback content

## Expected result
The fallback text is available when canvas cannot be displayed.

## Explanation
Canvas is a drawing surface. HTML alone does not draw on it; JavaScript is required for drawing operations.

## Try it yourself
Write a text description of the chart that would be drawn on canvas.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
