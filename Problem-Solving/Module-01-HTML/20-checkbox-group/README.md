# Checkbox Group

## Task
Allow multiple technologies to be selected.

## Main concept
checkbox and shared name

## Expected result
Multiple technologies can be checked at the same time.

## Explanation
Checkboxes represent independent choices. Unlike radio buttons, multiple values may be selected.

## Try it yourself
Add TypeScript and Git to the options.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
