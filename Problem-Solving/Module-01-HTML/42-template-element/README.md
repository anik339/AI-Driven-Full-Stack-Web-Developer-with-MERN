# Template Element

## Task
Place inert reusable markup inside a template element.

## Main concept
template content

## Expected result
The paragraph appears; the template's article is not rendered as normal page content.

## Explanation
Template content is inert until code clones and inserts it into the document.

## Try it yourself
Add a button idea to clone the template later in the JavaScript module.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
