# External Link

## Task
Create a descriptive external link that opens safely in a new tab.

## Main concept
a, href, target and rel

## Expected result
The MDN link opens in a new tab.

## Explanation
Use meaningful link text. When target=_blank is used, rel=noopener noreferrer is a safe default.

## Try it yourself
Add a second link to the official Git documentation.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
