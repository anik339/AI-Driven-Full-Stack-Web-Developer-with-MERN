# Inline SVG Graphic

## Task
Create a small scalable graphic with inline SVG markup.

## Main concept
svg, viewBox, circle, path, title and desc

## Expected result
A small landscape illustration appears.

## Explanation
SVG is vector-based and scales without losing sharpness. Provide an accessible name or description when the graphic conveys meaning.

## Try it yourself
Change the circle position and hill path to create a different graphic.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
