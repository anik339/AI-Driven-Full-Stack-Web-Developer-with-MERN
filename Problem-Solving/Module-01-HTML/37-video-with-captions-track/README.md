# Video with Captions Track

## Task
Embed a video and explain the purpose of captions.

## Main concept
video, source, poster, track

## Expected result
A video player appears when the source is available.

## Explanation
Video controls let users operate playback. Captions provide access to spoken content and important sounds.

## Try it yourself
Add a track element with kind=captions and a local captions.vtt file.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
