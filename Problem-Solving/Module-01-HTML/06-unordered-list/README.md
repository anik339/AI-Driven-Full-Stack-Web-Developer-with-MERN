# Unordered List

## Task
Show a collection of tools where order does not matter.

## Main concept
ul and li

## Expected result
A bullet list of four tools appears.

## Explanation
Use ul for a group where changing the order does not change the meaning.

## Try it yourself
Add Live Server and Node.js to the list.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
