# Native Form Validation

## Task
Use built-in HTML validation attributes.

## Main concept
required, minlength, maxlength, pattern and title

## Expected result
The browser prevents submission when a required field is invalid.

## Explanation
HTML validation is useful for basic checks, but server-side validation is still required for real applications.

## Try it yourself
Add a password field with minlength=8.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
