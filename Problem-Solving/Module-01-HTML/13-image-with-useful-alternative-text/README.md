# Image with Useful Alternative Text

## Task
Add a local image with alt text and dimensions.

## Main concept
img, src, alt, width, height, figure and figcaption

## Expected result
An image with a caption appears.

## Explanation
Alt text communicates the image's purpose to people who cannot see it. Width and height reserve layout space.

## Try it yourself
Replace the sample image with a local image and write accurate alt text.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
