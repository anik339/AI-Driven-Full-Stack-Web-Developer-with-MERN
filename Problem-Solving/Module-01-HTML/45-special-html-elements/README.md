# Special HTML Elements

## Task
Use dfn, var, samp, wbr, ruby and noscript in context.

## Main concept
dfn, var, samp, wbr, ruby and noscript

## Expected result
Specialized elements identify definitions, variables, sample output, break opportunities and annotations.

## Explanation
Use specialized elements when their meaning fits the content. noscript provides fallback content when scripts are disabled or unsupported.
