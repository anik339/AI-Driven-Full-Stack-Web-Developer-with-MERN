# Simple Data Table

## Task
Create a timetable with caption and scoped headers.

## Main concept
table, caption, thead, tbody, tr, th, td and scope

## Expected result
A three-column study table appears.

## Explanation
Tables are for tabular data. Use caption and scoped headers to make relationships clear.

## Try it yourself
Add Thursday and Friday rows.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
