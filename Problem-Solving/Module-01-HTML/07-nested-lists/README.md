# Nested Lists

## Task
Organize frontend and backend technologies into nested lists.

## Main concept
Nested ul and li

## Expected result
Frontend and Backend each contain their own sub-list.

## Explanation
Place a nested list inside the parent li that owns it.

## Try it yourself
Add React under Frontend and PostgreSQL under Backend.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
