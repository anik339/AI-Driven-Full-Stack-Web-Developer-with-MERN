# HTML Project File Structure

## Task
Create links to files inside a small multi-page project.

## Main concept
Relative paths and folder organization

## Expected result
A file tree and sample navigation links appear.

## Explanation
Relative paths depend on the current HTML file. Use ./ for the current folder and ../ to move to a parent folder.

## Try it yourself
Move this page into pages/ and update its links to the correct relative paths.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
