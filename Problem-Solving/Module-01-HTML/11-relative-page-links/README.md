# Relative Page Links

## Task
Connect two pages in the same project using relative paths.

## Main concept
Relative URLs and file paths

## Expected result
The links point to sibling HTML files.

## Explanation
A relative URL is resolved from the current file's location. Check spelling and folder names carefully.

## Try it yourself
Move contact.html into a pages folder and update the link to ./pages/contact.html.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
