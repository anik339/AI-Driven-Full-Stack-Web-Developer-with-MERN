# Code and Keyboard Instructions

## Task
Show source code, keyboard input and preformatted text.

## Main concept
code, kbd, pre

## Expected result
Code is shown in a preformatted block and keyboard keys are marked.

## Explanation
code represents computer code, kbd represents user input, and pre preserves whitespace.

## Try it yourself
Add a command-line example using samp for sample output.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
