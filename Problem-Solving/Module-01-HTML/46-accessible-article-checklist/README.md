# Accessible Article Checklist

## Task
Build an article with landmarks, headings, links and an image alternative.

## Main concept
Semantic article, image alt text, heading order and descriptive links

## Expected result
A complete article has a byline, date, meaningful image text and a section link.

## Explanation
Accessibility starts with meaningful structure, labels, alternatives and predictable navigation.

## Try it yourself
Use a keyboard to navigate the page and write down any issue you find.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
