# HTML Final Quality Review

## Task
Review a small page for semantics, links, images and forms.

## Main concept
Semantic review and validation

## Expected result
A six-point HTML quality checklist appears.

## Explanation
A good review checks meaning, accessibility, valid structure and local file references—not only whether the page looks correct.

## Try it yourself
Run the W3C HTML validator on one of your own pages and fix the reported errors.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
