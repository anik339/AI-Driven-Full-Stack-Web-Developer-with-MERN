# Metadata for Search and Sharing

## Task
Add a meaningful title, description, language and viewport metadata.

## Main concept
title, meta description, charset, viewport and lang

## Expected result
The page source contains useful metadata and a visible checklist.

## Explanation
Metadata belongs in head. It is not usually displayed as visible body content.

## Try it yourself
Write a unique title and description for a product page.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
