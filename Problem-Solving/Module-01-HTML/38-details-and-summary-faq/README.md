# Details and Summary FAQ

## Task
Build a no-JavaScript FAQ using details and summary.

## Main concept
details and summary

## Expected result
Two questions can be opened and closed without JavaScript.

## Explanation
details creates a disclosure widget; summary provides its visible label.

## Try it yourself
Add a third FAQ and set one details element to open by default.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
