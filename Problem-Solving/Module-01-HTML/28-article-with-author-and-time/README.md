# Article with Author and Time

## Task
Mark an article's publication date with time datetime.

## Main concept
article, header, footer and time datetime

## Expected result
An article displays its title, author, date and content.

## Explanation
The datetime attribute stores a machine-readable date while the element text is human-readable.

## Try it yourself
Add a second time element for the estimated reading duration using an appropriate format.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
