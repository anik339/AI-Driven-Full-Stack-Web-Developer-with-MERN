# Abbreviation and Quotations

## Task
Mark abbreviations, short quotations and long quotations.

## Main concept
abbr, q and blockquote

## Expected result
The abbreviation has an expanded title and quotations use semantic elements.

## Explanation
abbr can provide an expansion. q is for short inline quotations; blockquote is for longer quoted material.

## Try it yourself
Add a citation link after the blockquote.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
