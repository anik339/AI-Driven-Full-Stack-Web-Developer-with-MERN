# Semantic Page Landmarks

## Task
Create a page using semantic layout elements.

## Main concept
header, nav, main, article, aside and footer

## Expected result
The page has clear structural landmarks.

## Explanation
Semantic elements communicate the role of each region to browsers, search engines and assistive technologies.
