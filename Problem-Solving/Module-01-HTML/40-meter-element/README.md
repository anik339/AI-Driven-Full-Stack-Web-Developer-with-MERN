# Meter Element

## Task
Represent a measurement within a known range.

## Main concept
meter min, max, low, high, optimum and value

## Expected result
A meter shows a value inside a defined range.

## Explanation
meter is for a scalar measurement such as capacity or rating; progress is for task completion.

## Try it yourself
Create a meter for a test score out of 100.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
