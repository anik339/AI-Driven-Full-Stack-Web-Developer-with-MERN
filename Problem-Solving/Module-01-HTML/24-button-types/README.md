# Button Types

## Task
Demonstrate submit, reset and plain buttons.

## Main concept
button type submit, reset and button

## Expected result
The buttons show different browser states and default form behaviour.

## Explanation
A button inside a form defaults to submit if no type is given. Choose the type explicitly.

## Try it yourself
Create a form with one submit button and one reset button.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
