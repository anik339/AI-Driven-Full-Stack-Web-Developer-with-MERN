# Select and Optgroup

## Task
Organize course options into categories.

## Main concept
select, option and optgroup

## Expected result
A dropdown displays grouped course choices.

## Explanation
optgroup helps users scan long lists by grouping related options.

## Try it yourself
Add React under Frontend and Express under Backend.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
