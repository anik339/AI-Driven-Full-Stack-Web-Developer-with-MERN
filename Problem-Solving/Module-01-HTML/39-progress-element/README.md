# Progress Element

## Task
Show the progress of a course using progress.

## Main concept
progress value and max

## Expected result
A progress indicator shows 36 out of 50.

## Explanation
progress represents completion of a task. Keep its label and numeric context available to users.

## Try it yourself
Change the value to 42 and explain the percentage.
