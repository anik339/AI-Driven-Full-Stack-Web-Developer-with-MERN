# Correct Heading Hierarchy

## Task
Build a page with one main heading and correctly nested section headings.

## Main concept
h1–h6 and document outline

## Expected result
One h1 is followed by meaningful h2 and h3 headings.

## Explanation
Choose headings by document structure, not by the visual size you want.

## Try it yourself
Add a JavaScript h3 under Frontend Development.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
