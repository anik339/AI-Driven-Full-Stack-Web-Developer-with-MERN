# Module 01 — HTML — 50 Problems

50 HTML-only problems covering document structure, headings, text, links, images, lists, tables, forms, semantic elements, accessibility, media, responsive images and modern HTML elements.

## How to practise

Open each `index.html` in a browser or with Live Server. This module intentionally uses HTML only; CSS and JavaScript are covered later.

## Recommended routine
1. Read the problem statement before opening the solution.
2. Predict what the page or code will do.
3. Run the provided solution and compare the result.
4. Read the code comments and explain the important lines in your own words.
5. Complete the challenge without copying the solution.
6. Commit your completed work to GitHub with a clear message.
