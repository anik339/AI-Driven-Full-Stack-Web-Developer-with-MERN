# Radio Button Group

## Task
Let a user select exactly one study schedule.

## Main concept
fieldset, legend and radio group names

## Expected result
Three radio options appear; only one can be selected.

## Explanation
Radio buttons with the same name form one mutually exclusive group.

## Try it yourself
Add an option for night study.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
