# Accessible Contact Form

## Task
Build a form with labels, names and appropriate input types.

## Main concept
form, label, for, id, name, input and textarea

## Expected result
A labelled form with name, email and message fields appears.

## Explanation
A label should be associated with a control. A name is used when form data is submitted.

## Try it yourself
Add a subject field and a reset button.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
