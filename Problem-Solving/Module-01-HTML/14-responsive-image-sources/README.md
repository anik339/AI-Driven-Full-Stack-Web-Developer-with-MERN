# Responsive Image Sources

## Task
Use picture and source to offer image alternatives.

## Main concept
picture, source, media and img fallback

## Expected result
The browser selects a source based on the media condition.

## Explanation
picture lets the browser choose among alternative image sources. Always keep an img fallback.

## Try it yourself
Add a source for a high-density display using srcset.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
