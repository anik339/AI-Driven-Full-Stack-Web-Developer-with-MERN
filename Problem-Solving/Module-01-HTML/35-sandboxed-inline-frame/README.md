# Sandboxed Inline Frame

## Task
Embed a small document using iframe srcdoc and a restrictive sandbox.

## Main concept
iframe, title, sandbox and srcdoc

## Expected result
A small embedded document appears inside the page.

## Explanation
An iframe needs a descriptive title. Sandbox restricts capabilities; grant only the permissions a real use case needs.

## Try it yourself
Add a second iframe and compare the titles and dimensions.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
