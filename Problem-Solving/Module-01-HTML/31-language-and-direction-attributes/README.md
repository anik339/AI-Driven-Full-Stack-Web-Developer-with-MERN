# Language and Direction Attributes

## Task
Mark a language change and isolate bidirectional text.

## Main concept
lang, bdi and bdo

## Expected result
English and Bengali text are identified with language attributes; bdo changes text direction.

## Explanation
lang identifies the language of content. bdi isolates text with unknown direction; bdo overrides direction.

## Try it yourself
Add an Arabic sample phrase with lang=ar and dir=rtl.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
