# Fieldset and Legend

## Task
Group related personal information fields.

## Main concept
fieldset and legend

## Expected result
The browser groups two related controls under one legend.

## Explanation
fieldset groups related controls and legend provides the group's accessible name.

## Try it yourself
Create a second fieldset for notification preferences.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
