# Datalist Suggestions

## Task
Offer suggested values while allowing custom input.

## Main concept
input list and datalist

## Expected result
The input can show suggested editor names.

## Explanation
datalist offers suggestions but does not restrict the user to only those options.

## Try it yourself
Add Chrome and Firefox as browser suggestions.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
