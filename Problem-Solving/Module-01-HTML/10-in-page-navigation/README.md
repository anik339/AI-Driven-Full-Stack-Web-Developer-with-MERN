# In-Page Navigation

## Task
Link navigation items to sections using fragment identifiers.

## Main concept
href fragments and unique id values

## Expected result
Each navigation link moves to the matching section.

## Explanation
The fragment after # must match an element id exactly. IDs should be unique in a document.

## Try it yourself
Add a Projects link and a section with id projects.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
