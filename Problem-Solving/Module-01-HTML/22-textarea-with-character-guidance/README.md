# Textarea with Character Guidance

## Task
Create a labelled message field with a length limit.

## Main concept
textarea, minlength, maxlength and required

## Expected result
A text area accepts a message and the browser checks its length on submission.

## Explanation
Textarea is for multi-line text. Native constraints help prevent empty or excessively long input.

## Try it yourself
Add a second textarea for optional suggestions.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
