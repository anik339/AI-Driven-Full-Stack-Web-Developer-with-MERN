# Table with Colspan

## Task
Merge a header across two columns.

## Main concept
colspan and table headers

## Expected result
The Fee breakdown header spans two columns.

## Explanation
colspan merges adjacent cells horizontally. Do not use tables to lay out an entire page.

## Try it yourself
Add a total column and explain how the headers should relate.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
