# Emphasis and Importance

## Task
Use strong and em to express meaning, not just appearance.

## Main concept
strong, em, b and i

## Expected result
Important text and emphasized words are identified semantically.

## Explanation
strong means strong importance; em adds stress emphasis. b and i have more limited presentational or alternate-voice uses.

## Try it yourself
Write a safety note using strong and an emphasized word using em.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
