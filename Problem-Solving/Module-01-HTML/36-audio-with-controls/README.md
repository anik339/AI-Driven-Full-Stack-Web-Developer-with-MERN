# Audio with Controls

## Task
Embed an audio sample with controls and fallback text.

## Main concept
audio, source, controls and fallback

## Expected result
An audio player appears when a supported media source is available.

## Explanation
Use controls so users can play, pause and adjust media. Provide meaningful alternatives when audio conveys information.

## Try it yourself
Add a transcript below the audio player.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
