# Ordered List

## Task
Create a numbered list showing the steps to start a project.

## Main concept
ol and li

## Expected result
A four-step numbered list appears.

## Explanation
Use ol when order matters, such as instructions or a sequence.

## Try it yourself
Add a fifth step about testing the page.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
