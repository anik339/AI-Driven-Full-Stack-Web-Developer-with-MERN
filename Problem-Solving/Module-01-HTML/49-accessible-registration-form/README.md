# Accessible Registration Form

## Task
Combine labels, fieldsets, validation and helpful instructions.

## Main concept
Labels, autocomplete, required, minlength, fieldset and legend

## Expected result
A registration form displays associated labels and native validation.

## Explanation
Use labels for every form control. Do not request real credentials in practice examples.

## Try it yourself
Add a confirm-password field and explain that matching values need JavaScript or server-side validation.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
