# HTML Form Submission Attributes

## Task
Demonstrate action, method and enctype with safe sample values.

## Main concept
action, method, name and multipart/form-data

## Expected result
The browser displays a form with a file picker and submit button.

## Explanation
action identifies the destination; method defines GET or POST; multipart/form-data is used for file uploads. This demo does not send data to a working server.

## Try it yourself
Create a GET search form with a q field and explain the URL query string.

## How to run
1. Open this problem folder in VS Code.
2. Open `index.html` with Live Server.
3. Read the source file and comments before changing anything.
4. Make your own version of the challenge and test it in the browser.
