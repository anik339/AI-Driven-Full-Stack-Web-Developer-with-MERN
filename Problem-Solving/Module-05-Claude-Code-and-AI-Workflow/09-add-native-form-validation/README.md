# Add Native Form Validation

## Task
A registration form accepts empty and invalid email fields.

## Main concept
Forms

## Expected result
The browser blocks empty and malformed values and all controls have labels.

## Explanation
Ask Claude Code to add required, type=email, minlength and appropriate labels, then explain what still requires server-side validation.

## Try it yourself
Add a password length rule and test it manually.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
