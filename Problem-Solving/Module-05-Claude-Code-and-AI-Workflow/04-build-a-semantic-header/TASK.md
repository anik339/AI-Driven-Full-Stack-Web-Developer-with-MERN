# Problem 04: Build a Semantic Header

## Scenario
A page has a header built with generic div elements and unclear navigation.

## Goal
Ask Claude Code to replace the header with semantic header and nav elements, descriptive links and a clear heading structure.

## Expected result
The header uses semantic landmarks and links have meaningful text.

## Challenge
Use keyboard navigation to test every link.

## Files
- `sample-project/index.html` — safe sample page.
- `sample-project/style.css` — sample stylesheet.
- `PROMPT.md` — copy-ready Claude Code prompt.
- `ACCEPTANCE_CHECKLIST.md` — checks to perform before accepting changes.
