# Build a Semantic Header

## Task
A page has a header built with generic div elements and unclear navigation.

## Main concept
HTML implementation

## Expected result
The header uses semantic landmarks and links have meaningful text.

## Explanation
Ask Claude Code to replace the header with semantic header and nav elements, descriptive links and a clear heading structure.

## Try it yourself
Use keyboard navigation to test every link.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
