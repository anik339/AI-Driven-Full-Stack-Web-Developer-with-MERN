# Claude Code Prompt — Build a Semantic Header

**Context:** A page has a header built with generic div elements and unclear navigation.

**Request:** Preserve the existing content and visual design. Do not add JavaScript or a framework.

**Working rules:**
- Inspect the relevant files before proposing changes.
- Explain the plan and identify files that may change.
- Do not edit unrelated files or add dependencies without approval.
- Do not invent test results, URLs, screenshots or project facts.
- Explain the important code changes in beginner-friendly language.

**Acceptance criteria:** The header uses semantic landmarks and links have meaningful text.
