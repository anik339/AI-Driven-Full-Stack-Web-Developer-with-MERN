# Claude Code Prompt — Final Quality Gate Before Push

**Context:** Your changes are complete and you are about to push to GitHub.

**Request:** Read-only review. Do not push, commit, reset or change remote settings.

**Working rules:**
- Inspect the relevant files before proposing changes.
- Explain the plan and identify files that may change.
- Do not edit unrelated files or add dependencies without approval.
- Do not invent test results, URLs, screenshots or project facts.
- Explain the important code changes in beginner-friendly language.

**Acceptance criteria:** The report has pass/fail/needs-manual-check status and lists remaining blockers.
