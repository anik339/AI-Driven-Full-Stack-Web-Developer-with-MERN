# Final Quality Gate Before Push

## Task
Your changes are complete and you are about to push to GitHub.

## Main concept
Release quality

## Expected result
The report has pass/fail/needs-manual-check status and lists remaining blockers.

## Explanation
Ask Claude Code to review status, diff, tests, build, secrets, documentation and responsive behaviour.

## Try it yourself
Run each check yourself and update the report with actual results.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
