# Problem 10: Run an Accessibility Review

## Scenario
A landing page needs a basic accessibility review before publishing.

## Goal
Ask Claude Code to inspect headings, landmarks, links, images, forms, contrast clues and keyboard focus.

## Expected result
The report lists issue, location, impact, proposed fix and verification step.

## Challenge
Fix the highest-impact issue after reviewing the report.

## Files
- `sample-project/index.html` — safe sample page.
- `sample-project/style.css` — sample stylesheet.
- `PROMPT.md` — copy-ready Claude Code prompt.
- `ACCEPTANCE_CHECKLIST.md` — checks to perform before accepting changes.
