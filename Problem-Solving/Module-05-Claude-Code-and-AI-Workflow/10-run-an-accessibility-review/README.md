# Run an Accessibility Review

## Task
A landing page needs a basic accessibility review before publishing.

## Main concept
Accessibility review

## Expected result
The report lists issue, location, impact, proposed fix and verification step.

## Explanation
Ask Claude Code to inspect headings, landmarks, links, images, forms, contrast clues and keyboard focus.

## Try it yourself
Fix the highest-impact issue after reviewing the report.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
