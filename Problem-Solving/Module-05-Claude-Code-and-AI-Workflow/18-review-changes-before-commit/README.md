# Review Changes Before Commit

## Task
You have modified several files and want to understand the impact.

## Main concept
Git review

## Expected result
The review references actual changed files and lines and identifies untested behaviour.

## Explanation
Ask Claude Code to review the Git diff and summarize changed behaviour, risks and missing tests.

## Try it yourself
Ask it to classify findings by severity.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
