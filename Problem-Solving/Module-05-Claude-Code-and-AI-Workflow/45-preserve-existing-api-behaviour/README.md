## Task
A refactor should improve readability without changing function inputs or outputs.

## Main concept
Refactoring

## Expected result

## Explanation
Ask Claude Code to refactor the function while preserving its public signature and output behaviour.

3. Open `sample-project/index.html` with Live Server to see the sample page.
