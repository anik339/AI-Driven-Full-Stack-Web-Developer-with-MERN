# Inspect a Repository Before Editing

## Task
You have opened an unfamiliar web project. Understand its structure before changing any files.

## Main concept
Repository inspection

## Expected result
The report names the main folders, entry files, available scripts and a safe next step.

## Explanation
Ask Claude Code to inspect the project and report its entry points, technologies, scripts and important folders without editing files.

## Try it yourself
Ask for a short architecture map of a second repository.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
