# Create a Manual Test Plan

## Task
A feature is implemented but has no test cases.

## Main concept
Testing

## Expected result
Each test has setup, action and expected result.

## Explanation
Ask Claude Code to create a manual test plan with normal, boundary, invalid and keyboard-only cases.

## Try it yourself
Execute the test plan and record actual outcomes.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
