# Resolve a Merge Conflict

## Task
Two branches changed the same lines in a README file.

## Main concept
Conflict resolution

## Expected result
Conflict markers are removed and the final content preserves the intended information.

## Explanation
Ask Claude Code to explain the conflict markers and help preserve both intended changes.

## Try it yourself
Create a small practice conflict in a disposable repository.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
