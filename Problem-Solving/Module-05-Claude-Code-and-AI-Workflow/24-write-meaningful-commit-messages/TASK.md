# Problem 24: Write Meaningful Commit Messages

## Scenario
Your commit history contains vague messages such as update and fix.

## Goal
Ask Claude Code to suggest clear commit messages based on the actual diff.

## Expected result
Each message accurately summarizes one logical change.

## Challenge
Practise a conventional commit format such as feat:, fix: or docs:.

## Files
- `sample-project/index.html` — safe sample page.
- `sample-project/style.css` — sample stylesheet.
- `PROMPT.md` — copy-ready Claude Code prompt.
- `ACCEPTANCE_CHECKLIST.md` — checks to perform before accepting changes.
