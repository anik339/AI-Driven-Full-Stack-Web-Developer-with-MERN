# Write Meaningful Commit Messages

## Task
Your commit history contains vague messages such as update and fix.

## Main concept
Git hygiene

## Expected result
Each message accurately summarizes one logical change.

## Explanation
Ask Claude Code to suggest clear commit messages based on the actual diff.

## Try it yourself
Practise a conventional commit format such as feat:, fix: or docs:.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
