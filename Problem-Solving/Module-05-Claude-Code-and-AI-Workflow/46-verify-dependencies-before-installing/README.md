# Verify Dependencies Before Installing

## Task
A tutorial suggests installing a package, but the project may already have it.

## Main concept
Dependencies

## Expected result
The recommendation is based on the existing dependency list.

## Explanation
Ask Claude Code to inspect package.json and the lockfile before recommending any installation.

## Try it yourself
Check whether a native browser API can solve the task without a package.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
