# Problem 07: Make a Card Grid Responsive

## Scenario
A three-column card grid overflows on a phone.

## Goal
Ask Claude Code to create a mobile-first grid that stacks on narrow screens and adds columns when space allows.

## Expected result
No horizontal overflow at 320px, 768px or 1280px.

## Challenge
Use auto-fit and minmax as an alternative implementation.

## Files
- `sample-project/index.html` — safe sample page.
- `sample-project/style.css` — sample stylesheet.
- `PROMPT.md` — copy-ready Claude Code prompt.
- `ACCEPTANCE_CHECKLIST.md` — checks to perform before accepting changes.
