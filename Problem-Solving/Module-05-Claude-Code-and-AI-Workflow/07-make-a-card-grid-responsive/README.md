# Make a Card Grid Responsive

## Task
A three-column card grid overflows on a phone.

## Main concept
Responsive implementation

## Expected result
No horizontal overflow at 320px, 768px or 1280px.

## Explanation
Ask Claude Code to create a mobile-first grid that stacks on narrow screens and adds columns when space allows.

## Try it yourself
Use auto-fit and minmax as an alternative implementation.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
