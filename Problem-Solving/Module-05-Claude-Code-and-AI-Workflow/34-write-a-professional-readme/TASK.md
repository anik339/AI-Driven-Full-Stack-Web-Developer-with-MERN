# Problem 34: Write a Professional README

## Scenario
A repository README does not explain how to run the project.

## Goal
Ask Claude Code to create a README with project overview, features, setup, scripts, folder structure, screenshots and learning notes.

## Expected result
A new developer can understand and run the project from the README.

## Challenge
Ask a friend to follow the README without extra help.

- `sample-project/index.html` — safe sample page.
- `sample-project/style.css` — sample stylesheet.
- `PROMPT.md` — copy-ready Claude Code prompt.
- `ACCEPTANCE_CHECKLIST.md` — checks to perform before accepting changes.
