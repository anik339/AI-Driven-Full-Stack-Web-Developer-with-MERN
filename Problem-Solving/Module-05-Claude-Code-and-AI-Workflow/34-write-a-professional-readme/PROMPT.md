# Claude Code Prompt — Write a Professional README

**Context:** A repository README does not explain how to run the project.

**Request:** Use only commands and features that exist in the project. Do not invent deployment URLs.

**Working rules:**
- Inspect the relevant files before proposing changes.
- Explain the plan and identify files that may change.
- Do not edit unrelated files or add dependencies without approval.
- Do not invent test results, URLs, screenshots or project facts.
- Explain the important code changes in beginner-friendly language.

**Acceptance criteria:** A new developer can understand and run the project from the README.
