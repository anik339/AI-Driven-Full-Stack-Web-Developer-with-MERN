# Use Plan-Then-Implement Workflow

## Task
You want Claude Code to plan a change before touching the code.

## Main concept
Claude Code workflow

## Expected result
The plan names exact files, risks and tests.

## Explanation
Ask Claude Code to inspect relevant files, propose a short plan and wait for approval before editing.

## Try it yourself
Use the workflow for a small navigation change.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
