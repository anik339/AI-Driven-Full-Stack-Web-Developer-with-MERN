# Problem 17: Write a Regression Test

## Scenario
A bug has been fixed once, but the same problem could return later.

## Goal
Ask Claude Code to identify the expected behaviour and add a focused regression test using the test framework already present.

## Expected result
The test fails before the fix or reproduces the bug, then passes after the fix.

## Challenge
Change the test input to cover a boundary case.
