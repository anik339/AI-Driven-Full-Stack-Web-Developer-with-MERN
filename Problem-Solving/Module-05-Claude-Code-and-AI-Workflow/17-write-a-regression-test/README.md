# Write a Regression Test

## Task
A bug has been fixed once, but the same problem could return later.

## Main concept
Testing

## Expected result
The test fails before the fix or reproduces the bug, then passes after the fix.

## Explanation
Ask Claude Code to identify the expected behaviour and add a focused regression test using the test framework already present.

## Try it yourself
Change the test input to cover a boundary case.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
