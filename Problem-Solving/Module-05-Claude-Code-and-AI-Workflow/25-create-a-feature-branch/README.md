# Create a Feature Branch

## Task
You need to implement a feature without working directly on main.

## Main concept
Branch workflow

## Expected result
The new branch has a descriptive name and the original branch remains unchanged.

## Explanation
Practise creating a branch from the latest main branch and switching to it.

## Try it yourself
Use feature/responsive-header as a practice branch name.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
