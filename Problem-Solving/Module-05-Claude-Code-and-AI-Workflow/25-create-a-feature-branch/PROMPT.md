# Claude Code Prompt — Create a Feature Branch

**Context:** You need to implement a feature without working directly on main.

**Request:** Check the current branch and working tree first. Do not discard local changes.

**Working rules:**
- Inspect the relevant files before proposing changes.
- Explain the plan and identify files that may change.
- Do not edit unrelated files or add dependencies without approval.
- Do not invent test results, URLs, screenshots or project facts.
- Explain the important code changes in beginner-friendly language.

**Acceptance criteria:** The new branch has a descriptive name and the original branch remains unchanged.
