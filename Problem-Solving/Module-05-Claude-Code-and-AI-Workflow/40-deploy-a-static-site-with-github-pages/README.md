# Deploy a Static Site with GitHub Pages

## Task
A static HTML/CSS project is ready for a public preview.

## Main concept
Deployment

## Expected result
The checklist identifies the correct branch/folder and post-deployment tests.

## Explanation
Ask Claude Code to check whether the project is suitable for GitHub Pages and write a deployment checklist.

## Try it yourself
Deploy a disposable static project and verify its assets load.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
