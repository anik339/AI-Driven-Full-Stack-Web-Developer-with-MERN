# Claude Code Prompt — Deploy a Static Site with GitHub Pages

**Context:** A static HTML/CSS project is ready for a public preview.

**Request:** Do not invent a live URL or change repository settings. Check relative paths and build requirements.

**Working rules:**
- Inspect the relevant files before proposing changes.
- Explain the plan and identify files that may change.
- Do not edit unrelated files or add dependencies without approval.
- Do not invent test results, URLs, screenshots or project facts.
- Explain the important code changes in beginner-friendly language.

**Acceptance criteria:** The checklist identifies the correct branch/folder and post-deployment tests.
