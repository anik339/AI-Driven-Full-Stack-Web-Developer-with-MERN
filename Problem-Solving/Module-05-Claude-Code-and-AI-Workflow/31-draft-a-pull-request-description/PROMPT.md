# Claude Code Prompt — Draft a Pull Request Description

**Context:** A feature branch is ready for review.

**Request:** Include summary, motivation, changes, test evidence, screenshots if available and known limitations. Do not claim tests passed unless run.

**Working rules:**
- Inspect the relevant files before proposing changes.
- Explain the plan and identify files that may change.
- Do not edit unrelated files or add dependencies without approval.
- Do not invent test results, URLs, screenshots or project facts.
- Explain the important code changes in beginner-friendly language.

**Acceptance criteria:** The PR description is accurate, concise and reviewable.
