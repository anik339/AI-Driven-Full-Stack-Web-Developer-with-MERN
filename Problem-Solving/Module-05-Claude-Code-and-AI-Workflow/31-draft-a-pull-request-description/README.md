# Draft a Pull Request Description

## Task
A feature branch is ready for review.

## Main concept
Pull requests

## Expected result
The PR description is accurate, concise and reviewable.

## Explanation
Ask Claude Code to draft a pull request description from the actual diff.

## Try it yourself
Add a checklist for responsive and accessibility checks.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
