# Initialize a Local Git Repository

## Task
A new project folder is not yet tracked by Git.

## Main concept
Git basics

## Expected result
The project has a local repository and a clean working tree after commit.

## Explanation
Practise initializing Git and making the first local commit.

## Try it yourself
Create a second commit after changing the README.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
