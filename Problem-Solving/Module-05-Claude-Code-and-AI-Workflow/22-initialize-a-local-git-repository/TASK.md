# Problem 22: Initialize a Local Git Repository

## Scenario
A new project folder is not yet tracked by Git.

## Goal
Practise initializing Git and making the first local commit.

## Expected result
The project has a local repository and a clean working tree after commit.

## Challenge
Create a second commit after changing the README.
