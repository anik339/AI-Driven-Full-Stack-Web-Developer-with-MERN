# Capstone AI-Assisted Feature Workflow

## Task
Implement a small responsive course card feature using an AI-assisted workflow.

## Main concept
Capstone

## Expected result
The feature works, tests are documented, diff is focused and PR description is accurate.

## Explanation
Use Claude Code to inspect the repository, plan the feature, implement in small steps, test, review the diff and prepare a pull request description.

## Try it yourself
Repeat the workflow for a search/filter feature.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
