# Claude Code Prompt — Capstone AI-Assisted Feature Workflow

**Context:** Implement a small responsive course card feature using an AI-assisted workflow.

**Request:** Ask for approval before edits. Preserve existing project conventions. Never commit or push automatically.

**Working rules:**
- Inspect the relevant files before proposing changes.
- Explain the plan and identify files that may change.
- Do not edit unrelated files or add dependencies without approval.
- Do not invent test results, URLs, screenshots or project facts.
- Explain the important code changes in beginner-friendly language.

**Acceptance criteria:** The feature works, tests are documented, diff is focused and PR description is accurate.
