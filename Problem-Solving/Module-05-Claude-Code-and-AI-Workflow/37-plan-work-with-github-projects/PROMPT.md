# Claude Code Prompt — Plan Work with GitHub Projects

**Context:** A learning project has many tasks and needs a simple tracking board.

**Request:** Do not claim to create the board. Keep the workflow simple for one learner.

**Working rules:**
- Inspect the relevant files before proposing changes.
- Explain the plan and identify files that may change.
- Do not edit unrelated files or add dependencies without approval.
- Do not invent test results, URLs, screenshots or project facts.
- Explain the important code changes in beginner-friendly language.

**Acceptance criteria:** Tasks have clear outcomes and can move through a small workflow.
