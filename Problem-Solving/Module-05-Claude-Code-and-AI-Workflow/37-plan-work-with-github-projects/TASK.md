# Problem 37: Plan Work with GitHub Projects

## Scenario
A learning project has many tasks and needs a simple tracking board.

## Goal
Ask Claude Code to propose columns, labels and task cards for a small GitHub Projects board.

## Expected result
Tasks have clear outcomes and can move through a small workflow.

## Challenge
Create five real cards for the next project milestone.
