# Plan Work with GitHub Projects

## Task
A learning project has many tasks and needs a simple tracking board.

## Main concept
Project management

## Expected result
Tasks have clear outcomes and can move through a small workflow.

## Explanation
Ask Claude Code to propose columns, labels and task cards for a small GitHub Projects board.

## Try it yourself
Create five real cards for the next project milestone.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
