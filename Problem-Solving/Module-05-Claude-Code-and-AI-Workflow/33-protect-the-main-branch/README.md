# Protect the Main Branch

## Task
You want to reduce accidental direct pushes to the main branch.

## Main concept
GitHub settings

## Expected result
The checklist includes pull requests, status checks and restrictions appropriate for a solo learner.

## Explanation
Ask Claude Code to explain recommended GitHub branch protection settings for a small learning repository.

## Try it yourself
Enable a pull-request requirement if your GitHub plan and repo settings allow it.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
