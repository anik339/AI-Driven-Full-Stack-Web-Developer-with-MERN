# Claude Code Prompt — Protect the Main Branch

**Context:** You want to reduce accidental direct pushes to the main branch.

**Request:** Do not claim to change GitHub settings. Provide UI steps and explain trade-offs.

**Working rules:**
- Inspect the relevant files before proposing changes.
- Explain the plan and identify files that may change.
- Do not edit unrelated files or add dependencies without approval.
- Do not invent test results, URLs, screenshots or project facts.
- Explain the important code changes in beginner-friendly language.

**Acceptance criteria:** The checklist includes pull requests, status checks and restrictions appropriate for a solo learner.
