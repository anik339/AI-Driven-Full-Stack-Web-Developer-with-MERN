# Introduce CSS Design Tokens

## Task
A stylesheet repeats the same colours, spacing and border radii in many places.

## Main concept
CSS refactoring

## Expected result
Repeated values use named custom properties and the page still renders the same.

## Explanation
Ask Claude Code to create a small :root token system and replace repeated values without changing the design.

## Try it yourself
Add a token for the focus colour.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
