# Break a Feature into Small Tasks

## Task
A feature request is too broad to implement safely in one change.

## Main concept
Task planning

## Expected result
The plan is small, testable and ordered by dependency.

## Explanation
Ask Claude Code to convert the feature brief into small ordered tasks, files likely to change and acceptance criteria.

## Try it yourself
Choose one task and ask for its smallest implementation step.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
