# Problem 20: Audit Image Assets

## Scenario
A project has many image files with unclear dimensions and alt text.

## Goal
Ask Claude Code to inventory images, identify oversized assets and review alt text in context.

## Expected result
The report maps image path, usage, dimensions if known and suggested action.

## Challenge
Optimize one image and verify visual quality.
