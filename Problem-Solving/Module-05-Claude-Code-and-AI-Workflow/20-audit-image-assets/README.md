# Audit Image Assets

## Task
A project has many image files with unclear dimensions and alt text.

## Main concept
Asset management

## Expected result
The report maps image path, usage, dimensions if known and suggested action.

## Explanation
Ask Claude Code to inventory images, identify oversized assets and review alt text in context.

## Try it yourself
Optimize one image and verify visual quality.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
