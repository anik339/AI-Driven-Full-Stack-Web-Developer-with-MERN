# Problem 39: Create a Version Tag

## Scenario
A stable project milestone is ready to mark with a version tag.

## Goal
Ask Claude Code to explain annotated Git tags and suggest a version number based on the release scope.

## Expected result
The learner understands MAJOR, MINOR and PATCH version increments.

## Challenge
Create a local practice tag v1.0.0 on a test repository.
