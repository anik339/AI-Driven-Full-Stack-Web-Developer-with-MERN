# Create a Version Tag

## Task
A stable project milestone is ready to mark with a version tag.

## Main concept
Releases

## Expected result
The learner understands MAJOR, MINOR and PATCH version increments.

## Explanation
Ask Claude Code to explain annotated Git tags and suggest a version number based on the release scope.

## Try it yourself
Create a local practice tag v1.0.0 on a test repository.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
