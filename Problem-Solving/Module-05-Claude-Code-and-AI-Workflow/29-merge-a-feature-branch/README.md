# Merge a Feature Branch

## Task
A completed feature branch needs to be merged into main locally.

## Main concept
Branch workflow

## Expected result
The merge completes or the conflict state is clearly explained.

## Explanation
Ask Claude Code to guide a safe local merge and explain how to verify the result.

## Try it yourself
Inspect git log --oneline --graph after merging.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
