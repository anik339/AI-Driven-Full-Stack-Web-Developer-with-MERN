# Problem 29: Merge a Feature Branch

## Scenario
A completed feature branch needs to be merged into main locally.

## Goal
Ask Claude Code to guide a safe local merge and explain how to verify the result.

## Expected result
The merge completes or the conflict state is clearly explained.

## Challenge
Inspect git log --oneline --graph after merging.
