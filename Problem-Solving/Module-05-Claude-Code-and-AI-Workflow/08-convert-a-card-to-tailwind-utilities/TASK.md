# Problem 08: Convert a Card to Tailwind Utilities

## Scenario
A small card uses a long custom stylesheet and should be rebuilt with Tailwind utilities.

## Goal
Ask Claude Code to convert the card to Tailwind v4 utilities while preserving semantic HTML and responsive behaviour.

## Expected result
The card works with the configured Tailwind version and has visible focus states for links or buttons.

## Challenge
Ask Claude Code to explain each utility group.

## Files
- `sample-project/index.html` — safe sample page.
- `sample-project/style.css` — sample stylesheet.
- `PROMPT.md` — copy-ready Claude Code prompt.
- `ACCEPTANCE_CHECKLIST.md` — checks to perform before accepting changes.
