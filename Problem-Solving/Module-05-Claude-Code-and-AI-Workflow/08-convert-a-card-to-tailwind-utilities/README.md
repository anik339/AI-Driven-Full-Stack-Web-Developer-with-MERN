# Convert a Card to Tailwind Utilities

## Task
A small card uses a long custom stylesheet and should be rebuilt with Tailwind utilities.

## Main concept
Tailwind workflow

## Expected result
The card works with the configured Tailwind version and has visible focus states for links or buttons.

## Explanation
Ask Claude Code to convert the card to Tailwind v4 utilities while preserving semantic HTML and responsive behaviour.

## Try it yourself
Ask Claude Code to explain each utility group.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
