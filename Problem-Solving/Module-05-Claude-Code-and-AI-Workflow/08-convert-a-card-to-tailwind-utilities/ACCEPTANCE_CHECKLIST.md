# Acceptance checklist

- [ ] The change matches the task and existing project conventions.
- [ ] Only relevant files were changed.
- [ ] No secrets, credentials or private data were added.
- [ ] The page or workflow was checked using the stated steps.
- [ ] Keyboard access and responsive behaviour were considered where relevant.
- [ ] Actual test results are recorded honestly.
- [ ] Specific success criterion: The card works with the configured Tailwind version and has visible focus states for links or buttons.
