# Problem 43: Ask for an Explanation Before Editing

## Scenario
You are unsure why a component is structured in a particular way.

## Goal
Ask Claude Code to explain the component's data flow, props, state and dependencies without editing it.

## Expected result
The explanation follows the actual source code.

## Challenge
Ask it to draw a simple data-flow diagram in Markdown.
