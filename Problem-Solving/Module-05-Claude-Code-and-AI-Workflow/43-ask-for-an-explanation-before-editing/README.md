# Ask for an Explanation Before Editing

## Task
You are unsure why a component is structured in a particular way.

## Main concept
Code understanding

## Expected result
The explanation follows the actual source code.

## Explanation
Ask Claude Code to explain the component's data flow, props, state and dependencies without editing it.

## Try it yourself
Ask it to draw a simple data-flow diagram in Markdown.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
