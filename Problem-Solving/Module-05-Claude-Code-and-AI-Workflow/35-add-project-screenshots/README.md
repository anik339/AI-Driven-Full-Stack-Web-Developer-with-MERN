# Add Project Screenshots

## Task
A project needs visual evidence for its GitHub README.

## Main concept
Documentation

## Expected result
The README references existing image files with descriptive alt text.

## Explanation
Ask Claude Code to identify where screenshots should be stored and how to reference them in Markdown.

## Try it yourself
Capture desktop and mobile screenshots yourself.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
