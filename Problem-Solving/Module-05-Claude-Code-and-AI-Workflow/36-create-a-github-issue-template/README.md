# Create a GitHub Issue Template

## Task
You want bug reports to contain reproducible information.

## Main concept
GitHub collaboration

## Expected result
The template helps another developer reproduce a bug.

## Explanation
Ask Claude Code to create a bug report template with steps, expected result, actual result and environment.

## Try it yourself

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
