# Check Responsive Breakpoints

## Task
A page looks correct on desktop but breaks at tablet width.

## Main concept
Responsive QA

## Expected result
The layout has no horizontal overflow and controls remain usable.

## Explanation
Ask Claude Code to inspect layout CSS and propose breakpoint changes based on content needs.

## Try it yourself
Use DevTools responsive mode and capture screenshots.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
