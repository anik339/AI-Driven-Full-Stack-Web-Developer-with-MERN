# Module 05 — Claude Code and AI Workflow: 50 Practice Tasks

This module practises safe AI-assisted development, prompt writing, code reading, debugging, refactoring, testing, accessibility review, Git/GitHub collaboration and release preparation.

Every problem includes a task brief, a copy-ready prompt, an acceptance checklist and a small browser-runnable sample page. Git-related tasks include additional safety notes.

Important: Claude Code prompts do not replace your judgement. Inspect changes, run tests yourself and never let an assistant commit, push or discard work without your explicit approval.
