# Use Conventional Commits

## Task
You want a consistent commit history across the repository.

## Main concept
Git hygiene

## Expected result
The type and scope match the real change.

## Explanation
Ask Claude Code to classify actual changes and suggest conventional commit messages.

## Try it yourself
Write a breaking-change message and explain when it is appropriate.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
