# Fix Unlabelled Form Controls

## Task
A contact form has inputs that rely only on placeholder text.

## Main concept
Accessibility

## Expected result
Every input has an accessible name and the form remains usable.

## Explanation
Ask Claude Code to associate every form control with a visible label and add suitable input types and autocomplete values.

## Try it yourself
Ask for a manual keyboard and screen-reader review checklist.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
