# Review a Pull Request

## Task
A teammate has submitted a pull request with a UI change.

## Main concept
Pull requests

## Expected result
Findings are actionable and distinguish blockers from suggestions.

## Explanation
Ask Claude Code to review the diff for correctness, accessibility, responsiveness and maintainability.

## Try it yourself
Write one review comment with a suggested fix.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
