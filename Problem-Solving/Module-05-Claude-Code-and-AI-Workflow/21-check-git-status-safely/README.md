# Check Git Status Safely

## Task
Before starting work, you need to understand the current repository state.

## Main concept
Git basics

## Expected result
Every file is classified correctly and no work is discarded.

## Explanation
Ask Claude Code to explain the output of git status and identify modified, staged and untracked files.

## Try it yourself
Run git status --short and explain each status symbol.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
