# Problem 21: Check Git Status Safely

## Scenario
Before starting work, you need to understand the current repository state.

## Goal
Ask Claude Code to explain the output of git status and identify modified, staged and untracked files.

## Expected result
Every file is classified correctly and no work is discarded.

## Challenge
Run git status --short and explain each status symbol.
