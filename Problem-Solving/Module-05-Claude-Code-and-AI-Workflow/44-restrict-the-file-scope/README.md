# Restrict the File Scope

## Task
You want to change one component without touching the rest of the repository.

## Main concept
Safe editing

## Expected result
The diff contains only approved files.

## Explanation
Ask Claude Code to modify only the named component and its directly required stylesheet.

## Try it yourself
Review git status and diff after the change.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
