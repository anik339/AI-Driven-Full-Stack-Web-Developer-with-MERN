# Claude Code Prompt — Create a Reusable UI Component

**Context:** Several pages repeat the same button or card markup.

**Request:** Do not introduce a framework if the project is plain HTML/CSS. Preserve accessible names and states.

**Working rules:**
- Inspect the relevant files before proposing changes.
- Explain the plan and identify files that may change.
- Do not edit unrelated files or add dependencies without approval.
- Do not invent test results, URLs, screenshots or project facts.
- Explain the important code changes in beginner-friendly language.

**Acceptance criteria:** The component removes duplication without making simple markup harder to understand.
