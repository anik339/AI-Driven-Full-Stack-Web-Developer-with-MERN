# Create a Reusable UI Component

## Task
Several pages repeat the same button or card markup.

## Main concept
Component design

## Expected result
The component removes duplication without making simple markup harder to understand.

## Explanation
Ask Claude Code to identify repeated markup and propose a reusable component or pattern suited to the existing stack.

## Try it yourself
Add a second use of the reusable component.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
