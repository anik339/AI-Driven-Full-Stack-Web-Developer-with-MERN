# Problem 48: Create a Reusable UI Component

## Scenario
Several pages repeat the same button or card markup.

## Goal
Ask Claude Code to identify repeated markup and propose a reusable component or pattern suited to the existing stack.

## Expected result
The component removes duplication without making simple markup harder to understand.

## Challenge
Add a second use of the reusable component.

## Files
- `sample-project/index.html` — safe sample page.
- `sample-project/style.css` — sample stylesheet.
- `PROMPT.md` — copy-ready Claude Code prompt.
- `ACCEPTANCE_CHECKLIST.md` — checks to perform before accepting changes.
