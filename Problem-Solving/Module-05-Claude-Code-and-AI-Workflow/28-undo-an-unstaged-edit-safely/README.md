# Undo an Unstaged Edit Safely

## Task
You accidentally changed one line in a practice file and want to understand safe recovery.

## Main concept
Git recovery

## Expected result
The explanation distinguishes restore, checkout and reset and warns about data loss.

## Explanation
Ask Claude Code to explain safe options for discarding a single unstaged file change.

## Try it yourself
Practise only on a disposable copy of a file.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
