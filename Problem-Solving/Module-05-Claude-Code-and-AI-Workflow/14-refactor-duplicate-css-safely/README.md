# Refactor Duplicate CSS Safely

## Task
Several selectors repeat identical declarations.

## Main concept
CSS refactoring

## Expected result
Duplicate declarations are reduced and the page remains visually consistent.

## Explanation
Ask Claude Code to identify safe shared rules and refactor them into reusable classes or custom properties.

## Try it yourself
Compare before and after screenshots at the same viewport width.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
