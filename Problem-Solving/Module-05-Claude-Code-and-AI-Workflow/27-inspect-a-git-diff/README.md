# Inspect a Git Diff

## Task
You want to verify what changed before committing.

## Main concept
Git review

## Expected result
The review accurately describes additions, deletions and modifications.

## Explanation
Ask Claude Code to explain the diff and point out unrelated formatting or accidental edits.

## Try it yourself
Use git diff --check to find whitespace problems.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
