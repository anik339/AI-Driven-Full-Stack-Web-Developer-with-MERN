# Debug a Console Error

## Task
The browser console shows an error after a recent code change.

## Main concept
Debugging

## Expected result
The error is reproduced, fixed and verified with a clear test.

## Explanation
Ask Claude Code to trace the error from the message and relevant source code, then propose the smallest fix.

## Try it yourself
Introduce a small intentional error in a copy and practise tracing it.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
