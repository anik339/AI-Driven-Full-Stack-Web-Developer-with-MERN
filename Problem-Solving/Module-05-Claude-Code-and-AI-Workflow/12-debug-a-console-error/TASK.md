# Problem 12: Debug a Console Error

## Scenario
The browser console shows an error after a recent code change.

## Goal
Ask Claude Code to trace the error from the message and relevant source code, then propose the smallest fix.

## Expected result
The error is reproduced, fixed and verified with a clear test.

## Challenge
Introduce a small intentional error in a copy and practise tracing it.

- `sample-project/index.html` — safe sample page.
- `sample-project/style.css` — sample stylesheet.
- `PROMPT.md` — copy-ready Claude Code prompt.
