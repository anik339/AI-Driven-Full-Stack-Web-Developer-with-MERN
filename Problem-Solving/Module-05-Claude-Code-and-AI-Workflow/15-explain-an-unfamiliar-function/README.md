# Explain an Unfamiliar Function

## Task
You need to understand a function before editing it.

## Main concept
Code reading

## Expected result
The explanation includes a plain-language summary and a small example.

## Explanation
Ask Claude Code to explain the function line by line, including inputs, outputs, side effects and edge cases.

## Try it yourself
Explain the same function in your own words without looking at the answer.

## How to run
1. Open this problem folder in VS Code.
2. Read `TASK.md` and `PROMPT.md` first.
3. Open `sample-project/index.html` with Live Server to see the sample page.
4. Copy the prompt into Claude Code only after reviewing the working rules.
5. Check the proposed diff and complete `ACCEPTANCE_CHECKLIST.md` yourself.
