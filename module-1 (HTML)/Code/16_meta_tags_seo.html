HTML Metadata and SEO

Essential head metadata without unnecessary redirects or fake canonical URLs.

Metadata used in this actual page

  • meta charset UTF-8 = show international text correctly.
  • meta viewport = use mobile screen width.
  • meta description = short summary for search engines.
  • title = the browser tab title.

Use a meaningful h1 and real content. Metadata alone does not guarantee search ranking.

<meta name="description" content="Write a useful summary">
    <meta name="robots" content="index, follow">
    <link rel="canonical" href="https://your-real-domain.example/page">

Replace the example canonical address with the correct public URL only when you publish.

HTML-only learning example. No CSS, Tailwind, JavaScript or backend is included.
