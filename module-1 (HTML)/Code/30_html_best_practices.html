HTML Best Practices Checklist

A final HTML-only review of semantic structure, accessibility and security.

Before calling your HTML finished

  1. Set DOCTYPE, language, charset and viewport.
  2. Use a descriptive title and meta description.
  3. Use one clear top-level h1 and meaningful heading order.
  4. Use nav, main, article and section when appropriate.
  5. Use alt text for informative images and labels for inputs.
  6. Use table elements only for actual tabular data.
  7. Use rel="noopener noreferrer" on new-tab external links.
  8. Do not assume HTML-only forms are backed by a server.
