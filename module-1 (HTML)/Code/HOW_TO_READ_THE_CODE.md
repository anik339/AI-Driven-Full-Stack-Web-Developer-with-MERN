# Module 1: Code-reading checklist

HTML: Read tags from outside to inside. `head` is metadata, `body` is visible content, semantic tags describe purpose. For every input check `type`, `name`, `id`, and matching `label for`.

## Four questions for any code block
1. What does this element / selector / utility do?
2. Why is it used here instead of a simpler option?
3. What breaks if I remove it?
4. How can I change one small part and test the result?

## Practice routine
- Read a comment immediately above the section.
- Hide that comment and explain the logic yourself.
- Change one value and save.
- Refresh and compare desktop/mobile output.
- Undo the change and repeat with a different value.

This is learning material. Mark a topic complete only after you can reproduce or explain it.
