# JavaScript Foundation — Module 06

এই Folder-টি তোমার দেওয়া Course Screenshot-এর ২৮টি JavaScript Lesson Topic অনুসারে সাজানো হয়েছে।

## Folder structure
- `index.html` — সব ২৮টি Topic-এর Dashboard
- `assets/css/style.css` — সব Lesson-এর shared design
- `assets/js/helpers.js` — Browser output দেখানোর helper functions
- `01-...` থেকে `28-...` — প্রতিটি Topic-এর আলাদা Folder; প্রতিটিতে `index.html` এবং `script.js` আছে।

## VS Code-এ চালানোর নিয়ম
1. ZIP Extract করো।
2. VS Code থেকে Extract করা `module-6` Folder-টি Open Folder দিয়ে খোলো।
3. Root-এর `index.html` Open করো।
4. Live Server extension থাকলে `Go Live` চাপো।
5. Browser-এ Dashboard খুলবে; যে Topic শিখতে চাও সেটিতে Click করো।
6. Console দেখতে `Ctrl + Shift + J` চাপো। কাজ না করলে `Ctrl + Shift + I` চাপো, তারপর Console tab নির্বাচন করো।

## ১০টি JavaScript Project
- `Projects/index.html` — ১০টি beginner-friendly runnable project-এর dashboard।
- প্রতিটি project-এর আলাদা `index.html`, `script.js`, `styles.css` এবং `README.md` আছে।
- Project শেষ করার আগে code বুঝে নিজের মতো পরিবর্তন করে পরীক্ষা করো।

## কীভাবে শিখবে
1. প্রথমে Topic-এর `script.js` খুলে Comments পড়ো।
2. প্রতিটি Code কী করছে বোঝার চেষ্টা করো।
3. Browser এবং Console-এর Output মিলিয়ে দেখো।
4. নিজের মতো করে variable, number, text বা condition পরিবর্তন করো।
5. অন্তত একটি Example না দেখে নিজে লিখে Practice করো।
6. Error হলে Console-এর লাল Error Message পড়ো।

## Important notes
- কোনো npm package বা build tool দরকার নেই।
- প্রতিটি Lesson আলাদাভাবে চালানো যায়। Problem-Solving/Module-06-JavaScript ফোল্ডারে আরও ৫০টি runnable JavaScript practice problem আছে।
- `document.write()` পুরোনো output technique হিসেবে দেখানো হয়েছে; বাস্তব Project-এ `textContent` বা উপযুক্ত DOM method ব্যবহার করো।
- সাধারণত `===` ব্যবহার করো এবং `==`-এর পার্থক্য বুঝে রাখো।
- Array-এর values পড়তে `for...of` বা array methods সাধারণত `for...in`-এর চেয়ে উপযুক্ত।
- `structuredClone()` আধুনিক browser-এ সমর্থিত; পুরোনো browser-এ না চললে compatibility যাচাই করো।
- Comments শেখার সুবিধার জন্য লেখা। নিজের ভাষায় ব্যাখ্যা করতে পারাই আসল লক্ষ্য।
