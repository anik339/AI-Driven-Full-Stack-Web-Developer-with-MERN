# Project 03 — JavaScript Quiz App

## What you will build
Build a multiple-choice quiz that tracks answers, gives explanations, and calculates a final score.

## Features
- Eight JavaScript questions
- Immediate answer feedback
- Progress bar and score
- Final percentage and restart option

## JavaScript concepts practiced
arrays of objects, state variables, forEach(), event delegation, conditionals, template strings, DOM updates.

## Run in VS Code
1. Open this project folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Keep `index.html`, `styles.css`, and `script.js` in the same folder.

No API or storage is required. The question bank is defined near the top of `script.js`.

## Important files
- `index.html` — page structure and accessible controls.
- `styles.css` — responsive layout and visual design.
- `script.js` — application logic. Read the comments from top to bottom.

## Practice after it works
1. Add a countdown timer for each question.
1. Randomize the question order.
1. Save the best score in localStorage.

## Learning note
First run the project, then read one function at a time. Change a small part, refresh the browser, and observe the result. Do not only copy the code.
