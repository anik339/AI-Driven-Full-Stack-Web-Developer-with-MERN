# Project 02 — Expense Tracker

## What you will build
Build an income and expense tracker that calculates totals and stores transaction history locally.

## Features
- Add income and expense transactions
- Choose a category and date
- Calculate balance, total income, and total expenses
- Filter transaction history
- Delete an incorrect transaction

## JavaScript concepts practiced
form handling, Number() and numeric validation, Date inputs, filter() and reduce(), Intl.NumberFormat, DOM rendering, localStorage.

## Run in VS Code
1. Open this project folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Keep `index.html`, `styles.css`, and `script.js` in the same folder.

All transactions are demo data stored in your browser. The app does not connect to a bank or payment service.

## Important files
- `index.html` — page structure and accessible controls.
- `styles.css` — responsive layout and visual design.
- `script.js` — application logic. Read the comments from top to bottom.

## Practice after it works
1. Add monthly summaries.
1. Add a category breakdown.
1. Add an edit transaction feature.

## Learning note
First run the project, then read one function at a time. Change a small part, refresh the browser, and observe the result. Do not only copy the code.
