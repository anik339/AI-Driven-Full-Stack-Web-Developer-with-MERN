# Project 05 — Product Catalog and Shopping Cart

## What you will build
Build a small e-commerce front-end with product search, category filters, sorting, and a persistent cart.

## Features
- Search product names and descriptions
- Filter by category
- Sort products by price
- Add products and change cart quantities
- Calculate the cart total
- Persist cart data after refresh

## JavaScript concepts practiced
arrays of objects, filter() and sort(), reduce(), event delegation, object properties, localStorage, Intl.NumberFormat.

## Run in VS Code
1. Open this project folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Keep `index.html`, `styles.css`, and `script.js` in the same folder.

Products are sample data. This is a front-end learning project only: it has no checkout, payment processing, inventory, or backend.

## Important files
- `index.html` — page structure and accessible controls.
- `styles.css` — responsive layout and visual design.
- `script.js` — application logic. Read the comments from top to bottom.

## Practice after it works
1. Add a product details view.
1. Add a remove-all confirmation.
1. Move the product array into a separate `products.js` file.

## Learning note
First run the project, then read one function at a time. Change a small part, refresh the browser, and observe the result. Do not only copy the code.
