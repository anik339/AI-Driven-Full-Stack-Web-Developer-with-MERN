# Project 08 — Smart Form Validation

## What you will build
Build a sign-up form that validates user input and gives clear, accessible feedback.

## Features
- Validate name and email
- Check password length and show a strength indicator
- Confirm both password fields match
- Require the demo terms checkbox
- Show field-level error messages and a success message

## JavaScript concepts practiced
functions, regular expressions, input, blur, change, and submit events, boolean logic, arrays and every(), DOM attributes, accessibility feedback.

## Run in VS Code
1. Open this project folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Keep `index.html`, `styles.css`, and `script.js` in the same folder.

This is client-side validation practice only. Real applications must validate again on a secure server and must never rely on browser validation alone.

## Important files
- `index.html` — page structure and accessible controls.
- `styles.css` — responsive layout and visual design.
- `script.js` — application logic. Read the comments from top to bottom.

## Practice after it works
1. Add a phone number field.
1. Add show/hide password controls.
1. Move validation rules into a separate reusable validation module.

## Learning note
First run the project, then read one function at a time. Change a small part, refresh the browser, and observe the result. Do not only copy the code.
