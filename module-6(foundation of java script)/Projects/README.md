# Module 6 — JavaScript Projects

This folder contains **10 standalone JavaScript projects** designed to reinforce the lessons in Module 6.

## Start here

Open `index.html` in this folder to browse the 10 projects. The projects are already stored inside the Module 06 learning folder, separately from the 28 lesson topics and course resources.

## Projects in learning order

| # | Project | Main skills |
|---|---|---|
| 01 | Task Manager | DOM, events, arrays, localStorage |
| 02 | Expense Tracker | Forms, numbers, dates, reduce(), localStorage |
| 03 | Quiz App | State, arrays of objects, conditionals, event delegation |
| 04 | Weather Dashboard | fetch(), async/await, APIs, error handling |
| 05 | Product Catalog & Cart | Search, filter, sort, cart state, localStorage |
| 06 | Notes Manager | CRUD, edit, delete, search, pin, localStorage |
| 07 | GitHub Profile Finder | REST API, Promise.all(), async/await |
| 08 | Smart Form Validation | Validation, regular expressions, accessibility |
| 09 | Recipe Finder | API requests, dynamic cards, dialog, arrays |
| 10 | Job Application Tracker | CRUD, filters, URL validation, dashboard metrics |

## How to run a project in VS Code

1. Open one project folder in VS Code.
2. Open `index.html`.
3. Right-click the file and select **Open with Live Server**.
4. Read that project's `README.md` before changing the code.

Each project is independent. It has its own `index.html`, `styles.css`, `script.js`, and `README.md`. No npm installation or build command is needed.

## Important notes

- Projects 01–03, 05–06, 08, and 10 work locally in the browser.
- Projects 04, 07, and 09 need an internet connection because they use public APIs.
- No project needs an API key.
- Browser storage is local to the browser and computer. It is not a secure database or cloud backup.
- The form-validation project is a front-end demonstration. It does not create accounts or send personal data.
- The shop project is a front-end demonstration. It does not process payments.

## Recommended study method

Run the project first. Then read `script.js` from top to bottom. Change one small feature at a time, refresh the browser, and explain what each function does in your own words.
