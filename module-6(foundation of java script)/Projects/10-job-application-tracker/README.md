# Project 10 — Job Application Tracker

## What you will build
Build a small dashboard to organize job applications and monitor their progress through a hiring pipeline.

## Features
- Add company, role, date, status, and optional job URL
- Update an application's status
- Search by company or role
- Filter by application status
- Track total applications, interviews, and offers
- Persist data in localStorage

## JavaScript concepts practiced
CRUD operations, arrays and objects, filter(), event delegation, select change events, URL validation, DOM creation, localStorage.

## Run in VS Code
1. Open this project folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Keep `index.html`, `styles.css`, and `script.js` in the same folder.

This is a local personal tracker. It does not submit applications, contact employers, or sync data between devices.

## Important files
- `index.html` — page structure and accessible controls.
- `styles.css` — responsive layout and visual design.
- `script.js` — application logic. Read the comments from top to bottom.

## Practice after it works
1. Add an edit application feature.
1. Add a notes field for interview feedback.
1. Add a chart showing applications by status.

## Learning note
First run the project, then read one function at a time. Change a small part, refresh the browser, and observe the result. Do not only copy the code.
