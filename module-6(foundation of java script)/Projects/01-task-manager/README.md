# Project 01 — Task Manager

## What you will build
Create a personal task list with priorities, completion controls, filters, and browser storage.

## Features
- Add and delete tasks
- Mark tasks complete or active
- Filter all, active, and completed tasks
- See live task statistics
- Keep tasks after a browser refresh

## JavaScript concepts practiced
variables and constants, arrays and objects, functions, DOM selection and creation, event listeners, event delegation, array filter and find, JSON, localStorage.

## Run in VS Code
1. Open this project folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Keep `index.html`, `styles.css`, and `script.js` in the same folder.

**No API key or build tool is required.** The app works offline after the page has loaded.

## Important files
- `index.html` — page structure and accessible controls.
- `styles.css` — responsive layout and visual design.
- `script.js` — application logic. Read the comments from top to bottom.

## Practice after it works
1. Add a due date to each task.
1. Add an edit button so a task title can be changed.
1. Sort tasks by priority.

## Learning note
First run the project, then read one function at a time. Change a small part, refresh the browser, and observe the result. Do not only copy the code.
