# JavaScript Functions Assignment (8 Problems)

Eight beginner-friendly JavaScript function solutions in a single `index.js` file, following the submission guideline to print a result using `console.log()` for each problem.

## Problems

1. `findMax(numbers)` — largest number in an array
2. `countWords(str)` — number of words in a string
3. `calculateDifference(first, second)` — first minus second
4. `filterEvenNumbers(numbers)` — new array of even numbers
5. `sortArrayDescending(numbers)` — new array sorted descending
6. `isLeapYear(year)` — leap-year check
7. `reverseString(str)` — reverse a string
8. `sumArray(numbers)` — sum all elements

## Run

```bash
node index.js
```

## Submission

Submit **only `index.js`** to the course website, as instructed. The README is for GitHub documentation.
