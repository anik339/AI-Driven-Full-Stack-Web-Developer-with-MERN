Review Checklist

1. Is the HTML structure clear?

There should be one page title and useful section headings.

2. Does the page fit a phone screen?

Reduce the browser width and check for horizontal scrolling.

3. Are buttons and links understandable?

Use meaningful labels and visible keyboard focus styles.

4. Have I reviewed AI changes?

Read the diff before accepting edits and never share secret keys.
