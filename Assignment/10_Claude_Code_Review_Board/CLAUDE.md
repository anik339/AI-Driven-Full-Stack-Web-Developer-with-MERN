# Claude Code - Project Instructions

This folder is a static HTML and CSS practice assignment for Modules 1-5.

## Scope
- Only edit `index.html` and `style.css` for this task.
- Use HTML5 and plain CSS already covered in the course.
- Do not add JavaScript, React, backend code, new dependencies, or CDNs.
- Keep the layout simple, accessible, and mobile friendly.
- Use short English comments on major code sections only.
- Explain each suggested change before making it.
- Ask before deleting or renaming any file.
- Do not put tokens, credentials, or private data into source code.

## Example safe prompt
Review `index.html` and `style.css` for readability and mobile layout issues.
Suggest three small changes, explain why, and wait before editing.

## Manual checks after changes
1. Open index.html in the browser.
2. Check 375px mobile and a wide desktop viewport.
3. Use keyboard Tab to reach links and details controls.
4. Review `git diff` before creating a commit.

These notes are an instruction template, not evidence that Claude Code was run.
