# Assignments

This folder contains ten original course and practice assignments.

## How to run
1. Open the repository in VS Code.
2. Open `index.html` in this folder to browse the assignments.
3. Open the chosen assignment folder.
4. Run its HTML file with Live Server.
5. Read the source, make your own changes, and test at mobile and desktop widths.

## Assignment list
01. Personal Portfolio
02. Student Registration Form
03. Smartphone Contact Information
04. Chess Board
05. CSS Service Cards
06. Cafe Landing Page
07. Tailwind Course Cards
08. Tailwind Pricing Cards
09. Responsive Campus Event
10. Claude Code Review Board

Some assignments are static front-end demonstrations. They do not connect to a backend or submit real data unless a separate service is configured.
