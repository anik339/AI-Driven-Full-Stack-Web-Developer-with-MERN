# Anik Chandra Dey — Complete Frontend Portfolio Pack

This repository contains five independent frontend learning projects and a root launch page.

## Projects

1. **Personal Portfolio** — profile, skills, project links, contact form.
2. **NOVA Market** — e-commerce storefront interactions.
3. **Northstar Dashboard** — analytics, management pages, workspace and settings.
4. **Taskflow** — project/workspace management and Kanban task board.
5. **Launchpad** — job and internship discovery portal with employer demo workspace.

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Browser `localStorage` for local demo persistence

No framework, package installation, backend, database, or payment integration is required.

## Run

Open the root `index.html` with VS Code Live Server, then choose a project. Each project can also run independently from its own `index.html`.

See [START_HERE_BN.md](START_HERE_BN.md) for Bangla setup instructions and limitations. See each project folder's `README.md` for project-specific details.
