# প্রথমে এটা পড়ো — Five Frontend Projects

এই ZIP-এর মধ্যে পাঁচটি আলাদা project এবং একটি root launch page আছে।

## কীভাবে চালাবে

1. ZIP Extract করো।
2. Extract করা `Anik-Chandra-Dey-Frontend-Portfolio-Pack` folder VS Code-এ Open করো।
3. প্রথমে root-এর `index.html` চালাও (Live Server দিয়ে)। এখান থেকে পাঁচটি project খুলতে পারবে।
4. প্রতিটি project আলাদাভাবেও চালানো যাবে: সংশ্লিষ্ট folder-এর `index.html` → **Open with Live Server**।
5. প্রতিটি project-এর `README.md`-এ feature, file structure, run instruction এবং limitation লেখা আছে।
