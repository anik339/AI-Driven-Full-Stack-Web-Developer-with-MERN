CSS Float and Clear

Learn float for legacy text wrapping and clear for old layouts.

HTML + CSS only

Float moves an element to the left or right so text can wrap around it. This technique is useful to understand older stylesheets, although Flexbox and Grid are usually better for modern page layouts.
