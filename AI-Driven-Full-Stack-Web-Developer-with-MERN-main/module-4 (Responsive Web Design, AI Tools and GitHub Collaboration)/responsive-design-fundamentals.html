01 — Responsive Design Intro

One website, different screen sizes.

Responsive design allows a website to change its layout according to the available screen size.

📱

Mobile

Single-column layout for smaller screens.

📲

Tablet

Balanced layout for medium screen sizes.

💻

Laptop

Multi-column layout for desktop screens.

🖥️

Desktop

Wider layout with maximum content width.

08 — Media Queries

CSS that changes with screen size.

Media queries allow us to apply different CSS rules for different viewport sizes. 

@media (max-width: 640px) {

    .hero-title {
        font-size: 36px;
    }

}
