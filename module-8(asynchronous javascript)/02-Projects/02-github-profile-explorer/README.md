# 02. GitHub Profile Explorer

## Project goal
Search for public GitHub users and show avatar, bio, repository count and follower statistics. Handles not-found and API rate-limit responses.

## Features
- Search public GitHub API
- Display profile and statistics
- Handle 404, 403 and network errors
- Encode user input

## Run in VS Code
1. Open this project folder in VS Code.
2. Open `index.html` using **Live Server**.
3. Read `script.js` comments from top to bottom.
4. Test normal, empty, loading and error states where available.

## Practice challenges
1. Fetch and render repositories.
2. Show the user's blog URL when available.
3. Add a loading spinner.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — application logic with comments.

API projects require an internet connection. These are learning projects, not production services.
