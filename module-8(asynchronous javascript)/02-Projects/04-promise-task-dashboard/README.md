# 04. Promise Task Dashboard

## Project goal
Run simulated asynchronous jobs concurrently. Compare Promise.allSettled and Promise.race and display each result.

## Features
- Simulated asynchronous jobs
- Concurrent execution
- Promise.allSettled
- Promise.race
- Success and failure rendering

## Run in VS Code
1. Open this project folder in VS Code.
2. Open `index.html` using **Live Server**.
3. Read `script.js` comments from top to bottom.
4. Test normal, empty, loading and error states where available.

## Practice challenges
1. Add a Promise.all button.
2. Add a progress bar.
3. Allow a custom task name and delay.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — application logic with comments.

API projects require an internet connection. These are learning projects, not production services.
