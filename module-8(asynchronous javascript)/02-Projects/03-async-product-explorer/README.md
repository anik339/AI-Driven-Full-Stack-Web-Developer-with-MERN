# 03. Async Product Explorer

## Project goal
Search products using DummyJSON. Demonstrates URLSearchParams, fetch, destructuring, map, loading and empty states.

## Features
- Fetch and search product API
- URLSearchParams
- map and destructuring
- Loading, empty and error states

## Run in VS Code
1. Open this project folder in VS Code.
2. Open `index.html` using **Live Server**.
3. Read `script.js` comments from top to bottom.
4. Test normal, empty, loading and error states where available.

## Practice challenges
1. Add category filtering.
2. Sort by price.
3. Add a product details modal.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — application logic with comments.

API projects require an internet connection. These are learning projects, not production services.
