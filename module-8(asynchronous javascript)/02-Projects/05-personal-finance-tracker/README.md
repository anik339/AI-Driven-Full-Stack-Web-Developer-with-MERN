# 05. Personal Finance Tracker

## Project goal
Track income and expenses locally. Calculate totals with reduce, render rows with map and persist data in localStorage.

## Features
- Add income and expenses
- Calculate totals with reduce
- Render transactions with map
- Persist with localStorage
- Remove entries and clear all

## Run in VS Code
1. Open this project folder in VS Code.
2. Open `index.html` using **Live Server**.
3. Read `script.js` comments from top to bottom.
4. Test normal, empty, loading and error states where available.

## Practice challenges
1. Add date filtering.
2. Group totals by category.
3. Export transactions as JSON.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — application logic with comments.

API projects require an internet connection. These are learning projects, not production services.
