# 01. Async User Directory

## Project goal
Fetch users from JSONPlaceholder. Search by name, username or email and handle loading, empty and error states.

## Features
- Fetch public JSON API
- Loading, success and error states
- Search loaded data
- Safe DOM rendering

## Run in VS Code
1. Open this project folder in VS Code.
2. Open `index.html` using **Live Server**.
3. Read `script.js` comments from top to bottom.
4. Test normal, empty, loading and error states where available.

## Practice challenges
1. Add sorting by name.
2. Show each user's city.
3. Add a retry button in the error state.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — application logic with comments.

API projects require an internet connection. These are learning projects, not production services.
