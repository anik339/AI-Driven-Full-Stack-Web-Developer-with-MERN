# 15. JavaScript map() Method

## What you will learn
Transform each array item with map(). It returns a new array and does not mutate the original array.

## Concepts
- map callback
- New array creation
- Transforming objects
- map vs forEach

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Convert Celsius to Fahrenheit.

3. Add a passed property without mutating original objects.
