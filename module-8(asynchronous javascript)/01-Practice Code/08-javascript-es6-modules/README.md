# 08. JavaScript Modules: ES6 import and export

## What you will learn
Split code into reusable files with named exports and default exports. Run through Live Server because browser modules need an HTTP origin.

## Concepts
- Named export/import
- Default export/import
- Module scope
- Reusable files

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Export subtract() from math.js.
2. Create config.js and import a constant.
3. Add another named utility function.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — commented JavaScript practice code.
- `math.js` — supporting ES module.
- `greeting.js` — supporting ES module.
