# 06. Promises and Async/Await in Depth

## What you will learn
Learn Promise states, resolve/reject, then/catch/finally, async/await and Promise combinators.

## Concepts
- Promise states
- resolve/reject
- then/catch/finally
- async and await
- Promise.all/allSettled/race/any

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Create a Promise that rejects after one second.
2. Use Promise.allSettled with one failed task.
3. Await two independent tasks with Promise.all.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — commented JavaScript practice code.
