# 03. JavaScript OOP: Objects and Classes

## What you will learn
Learn objects, classes, constructors, methods, inheritance, method overriding, static methods and encapsulation.

## Concepts
- Objects and classes
- constructor and this
- extends and super
- Method overriding
- Static methods
- Private fields

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Add a method to calculate a student's grade.
2. Create a Manager class extending Employee.
3. Add a private #salary field and a public getter.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — commented JavaScript practice code.
