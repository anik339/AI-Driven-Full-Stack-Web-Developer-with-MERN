# 07. Error Handling: try, catch and finally

## What you will learn
Handle invalid input and failed asynchronous operations with try, catch, finally, throw and Error objects.

## Concepts
- try/catch/finally
- throw and Error
- Input validation
- Rejected async functions

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Throw an error for an empty username.
2. Catch an invalid JSON.parse() call.
3. Use finally to re-enable a disabled submit button.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — commented JavaScript practice code.
