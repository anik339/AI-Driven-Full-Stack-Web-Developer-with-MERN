# 19. Event Loop: Microtasks and Macrotasks

## What you will learn
Extra essential topic: understand synchronous execution, Promise microtasks, queueMicrotask and setTimeout task ordering.

## Concepts
- Call stack
- Event loop
- Microtask queue
- Promise callbacks
- setTimeout task queue

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Predict the order of two Promises and two timers.
2. Add a synchronous log between callbacks.
3. Compare queueMicrotask() and setTimeout(..., 0).
