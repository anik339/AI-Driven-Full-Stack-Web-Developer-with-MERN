# 13. Immediately Invoked Function Expressions (IIFE)

## What you will learn
An IIFE is a function expression that is defined and executed immediately. It creates a private function scope.

## Concepts
- Function expressions
- Immediate invocation
- Private scope
- Classic and arrow IIFE

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Return the current year from an IIFE.
2. Calculate a sum inside an IIFE.
3. Explain how IIFE avoids global variables.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — commented JavaScript practice code.
