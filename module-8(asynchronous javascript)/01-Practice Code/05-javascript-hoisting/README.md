# 05. JavaScript Hoisting

## What you will learn
Understand function declaration hoisting, var initialization to undefined, and the temporal dead zone for let and const.

## Concepts
- Function declaration hoisting
- var and undefined
- let/const TDZ
- Function expressions and arrows

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Call a function declaration before its source line.
2. Compare var and let inside a block.
3. Explain why a const arrow function cannot be called before initialization.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — commented JavaScript practice code.
