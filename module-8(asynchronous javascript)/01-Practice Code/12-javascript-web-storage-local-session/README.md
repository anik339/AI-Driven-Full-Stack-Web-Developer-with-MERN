# 12. JavaScript Web Storage: localStorage and sessionStorage

## What you will learn
Store small strings in the browser. localStorage survives browser restarts; sessionStorage lasts for the current tab session.

## Concepts
- setItem/getItem/removeItem
- localStorage vs sessionStorage
- JSON stringify/parse
- Storage security

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Save a theme preference.
2. Store an array of skills as JSON.
3. Clear sessionStorage without clearing localStorage.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — commented JavaScript practice code.
