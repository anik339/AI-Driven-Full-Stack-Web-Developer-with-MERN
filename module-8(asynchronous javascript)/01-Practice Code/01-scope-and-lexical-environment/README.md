# 01. JavaScript Scope and Lexical Environment

## What you will learn
Understand global, function, block and lexical scope, variable shadowing, and the temporal dead zone.

## Concepts
- Global, function and block scope
- Lexical lookup
- var vs let/const
- Shadowing and TDZ

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Create a nested function that reads an outer variable.
2. Try shadowing a variable inside a block.
3. Explain why let cannot be read before declaration.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — commented JavaScript practice code.
