# 14. JavaScript reduce() Method

## What you will learn
Use reduce() to combine an array into one value, such as a sum, average, or grouped object.

## Concepts
- reduce callback
- Accumulator/current value
- Initial value
- Grouping data

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Calculate an average with reduce().
2. Find the most expensive product.
3. Group names by their first letter.
