# 16. JavaScript Optional Chaining

## What you will learn
Use ?. to safely access nested properties, array positions and optional functions when a value may be null or undefined.

## Concepts
- Optional property access
- Nested optional chaining
- Optional function calls
- Combining ?. and ??

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Read company?.address?.city safely.
2. Call an optional callback.
3. Use optional chaining with an array index.
