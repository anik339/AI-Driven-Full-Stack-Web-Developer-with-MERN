# 04. Arrow Functions vs Regular Functions

## What you will learn
Compare syntax, this binding, arguments and constructor behaviour. Arrow functions capture this lexically.

## Concepts
- Arrow and regular syntax
- Lexical this vs call-site this
- arguments object
- Arrow functions are not constructors

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Rewrite a function declaration as an arrow function.
2. Create an object method that reads this.name.
3. Use an arrow function as a map callback.
