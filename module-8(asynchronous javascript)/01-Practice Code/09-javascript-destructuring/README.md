# 09. JavaScript Destructuring: Arrays and Objects

## What you will learn
Extract values from arrays and objects using positions or property names. Includes defaults, aliases and nested destructuring.

## Concepts
- Array destructuring
- Object destructuring
- Aliases and defaults
- Nested destructuring

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Destructure the first two array items.
2. Rename email to userEmail.
3. Destructure company.address.city.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — commented JavaScript practice code.
