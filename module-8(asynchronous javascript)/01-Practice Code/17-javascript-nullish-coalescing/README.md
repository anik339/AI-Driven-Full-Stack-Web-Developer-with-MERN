# 17. JavaScript Nullish Coalescing

## What you will learn
The ?? operator uses a fallback only when the left value is null or undefined. Compare it with ||, which uses fallback for every falsy value.

## Concepts
- Nullish coalescing
- Null and undefined
- Difference between ?? and ||
- Preserving zero/false/empty string

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
