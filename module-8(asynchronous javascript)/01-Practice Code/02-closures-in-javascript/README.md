# 02. Closures in JavaScript

## What you will learn
A closure lets a function remember variables from the scope where it was created, even after the outer function has returned.

## Concepts
- Closure and lexical scope
- Private variables
- Factory functions
- Closure-based state

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks

2. Create a private bank balance with deposit() and getBalance().
3. Make two counters that keep separate values.
