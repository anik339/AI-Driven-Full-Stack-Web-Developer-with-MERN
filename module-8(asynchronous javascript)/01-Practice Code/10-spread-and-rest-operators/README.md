# 10. Spread and Rest Operators

## What you will learn
Spread expands array/object values. Rest collects remaining values into an array or object. Both use the ... syntax.

## Concepts
- Spread arrays and objects
- Rest parameters
- Rest destructuring
- Immutable copies

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Merge two objects with spread.
2. Write an average(...scores) function.
3. Copy an array and add a value without mutating the original.

- `index.html` — page structure.
