# 18. JavaScript Truthy and Falsy Values

## What you will learn
Learn Boolean conversion and the complete falsy list. Empty arrays and empty objects are truthy in JavaScript.

## Concepts
- Boolean conversion
- Falsy list
- Truthy values
- Empty array/object behaviour

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Check Boolean(-1), Boolean('0') and Boolean('false').
2. Write a fallback function for an empty name.
3. Explain why [] is truthy.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — commented JavaScript practice code.
