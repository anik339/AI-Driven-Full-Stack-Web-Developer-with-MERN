# 11. Fetch API and Async Data Handling

## What you will learn
Request JSON from an API, check response.ok, parse JSON and render loading, success, empty and error states safely.

## Concepts
- fetch and async/await
- response.ok and HTTP status
- response.json()
- Loading/error states
- Safe data display

## Run in VS Code
1. Open this lesson folder in VS Code.
2. Open `index.html` with **Live Server**.
3. Read `script.js` from top to bottom. Comments explain the important steps.
4. Click the example button and inspect the result.
5. Open DevTools with F12 when the lesson uses console.log().

## Practice tasks
1. Load 10 posts.
2. Display userId for each post.
3. Add a retry button after an error.

## Files
- `index.html` — page structure.
- `styles.css` — responsive design.
- `script.js` — commented JavaScript practice code.
