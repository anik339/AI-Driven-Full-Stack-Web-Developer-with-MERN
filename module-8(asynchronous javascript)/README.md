## Run in VS Code
1. Extract this ZIP.
2. Open a lesson or project subfolder in VS Code.
3. Open `index.html` using **Live Server**.
4. Read `script.js` comments from top to bottom.
5. Use F12 to inspect the browser console.

No npm installation or build command is required. API projects need an internet connection. The ES Modules lesson must run through Live Server, not directly with file://.

## Important notes
- Every lesson and project has its own `index.html`, `styles.css`, `script.js`, and `README.md`.
- The ES Modules lesson also includes `math.js` and `greeting.js`.
- Do not store passwords, tokens or sensitive information in localStorage/sessionStorage.
- Public demo APIs can be temporarily unavailable; error handling is included.
- The GitHub public API has unauthenticated rate limits.
- The finance tracker is a local learning exercise, not a banking service.

## Open the module dashboard

Open `index.html` in this folder to browse every practice lesson and project. Each lesson/project folder is standalone; use VS Code Live Server to run its `index.html`.
