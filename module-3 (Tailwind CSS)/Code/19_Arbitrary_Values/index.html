Arbitrary values and custom sizing

প্রয়োজনীয় value default scale-এ না থাকলে bracket syntax দিয়ে custom value লেখা যায়।

w-[min(100%,42rem)]

Custom width value; small viewport-এ 100%, বড় হলে 42rem পর্যন্ত।

text-[#14532d]

Arbitrary color example

grid-cols-[1fr_2fr]

Custom grid column ratio

Practice tip: change one utility class at a time and observe the result.
