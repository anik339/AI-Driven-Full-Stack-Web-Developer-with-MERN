Utility-first thinking

Tailwind-এ আলাদা CSS selector না লিখে HTML-এর class দিয়ে design করা হয়। একেকটি utility একটি নির্দিষ্ট style দেয়।

Plain content

এখানে design utility কম, তাই visual hierarchy কম।

Styled with utilities

bg, text, padding, rounded এবং shadow class দিয়ে design তৈরি হয়েছে।

সহজ মনে রাখুন: bg-* background, text-* text, p-* padding, m-* margin, rounded-* corner।
Practice tip: change one utility class at a time and observe the result.
