Spacing and sizing

Margin, padding, width, height এবং max-width দিয়ে layout-এ breathing room দিন।

w-full — parent-এর পুরো width
w-2/3 — parent-এর দুই-তৃতীয়াংশ
w-40 — fixed utility width
ভেতরের জায়গা = padding; বাইরের দূরত্ব = margin
Practice tip: change one utility class at a time and observe the result.
