Production setup: Vite + React

Browser CDN practice-এর জন্য। Production React app-এ official build workflow ব্যবহার করুন।

1. Create a Vite React app

npm create vite@latest my-app -- --template react
cd my-app
npm install

2. Install Tailwind CSS v4 for Vite

npm install tailwindcss @tailwindcss/vite

3. Import Tailwind in your CSS entry file

@import "tailwindcss";

Vite config-এ official @tailwindcss/vite plugin যোগ করতে হবে। এই lesson reference; বর্তমান Vite setup-এর exact steps official docs দেখে অনুসরণ করুন।

Important: Browser Play CDN prototype/learning-এর জন্য; production website-এ build করে optimized CSS ব্যবহার করবেন।
Practice tip: change one utility class at a time and observe the result.
