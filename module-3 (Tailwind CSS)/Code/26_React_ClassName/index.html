Tailwind in React: className

MERN-এর React অংশে HTML-এর class attribute-এর বদলে JSX-এ className লেখা হয়।

HTML version

<button class="rounded-lg bg-indigo-600 px-4 py-2 text-white">
  Save changes
</button>

React JSX version

<button className="rounded-lg bg-indigo-600 px-4 py-2 text-white">
  Save changes
</button>

Class list একই; React JSX-এ attribute-এর নাম className। এই example শেখার reference—এটি React app চালায় না।

Practice tip: change one utility class at a time and observe the result.
