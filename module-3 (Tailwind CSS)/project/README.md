# Module 3: Tailwind CSS Projects

This folder contains five static Tailwind CSS practice projects. Each project has its own `index.html`.

## Projects
1. Personal Portfolio
2. Digital Agency
3. Product Catalogue
4. Tech Conference
5. Media Creator Portfolio

## Run locally
Open `index.html` with Live Server or a browser. These learning demos use the Tailwind CSS CDN, so an internet connection is required.

## Practice task
Change spacing, colours, responsive breakpoints, and grid classes. Test at mobile and desktop widths.
