## The 11 lesson topics covered

1. JavaScript DOM — understanding the Document Object Model
2. Accessing elements
3. Modifying element text using textContent and innerText
4. Working with element attributes using getAttribute() and setAttribute()
5. Adding and removing classes with classList
6. Changing styles with the style property
7. Creating new elements using createElement()
8. Appending elements using append()
9. Removing elements using removeChild() and remove()
10. Event types — mouse, keyboard, form, and window events
11. The Event object and target property

## How to run any lesson or project

1. Open the required subfolder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Open `script.js` and read the comments in order.
5. Test the buttons and forms in the browser.
6. Change one small part of the code and run it again.

Every lesson and project is standalone and contains:
- `index.html`
- `styles.css`
- `script.js`
- `README.md`

No npm installation, framework, API key, or build step is required.

## Recommended study order

First complete the 11 Practice Code lessons in order. Then build the five projects in order. Do not skip the practice lessons: each project combines multiple ideas from the videos.

## Important learning note

The code comments are written in simple English. Try to explain each function in your own words after running it. This will help you understand and maintain the code later.
