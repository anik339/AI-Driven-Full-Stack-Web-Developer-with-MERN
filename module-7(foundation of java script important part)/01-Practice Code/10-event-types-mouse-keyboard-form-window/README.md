# 10. JavaScript Event Types

## What this lesson demonstrates
Events are actions or browser occurrences. This lesson demonstrates mouse events, keyboard events, form events, and window events with separate live outputs.

## JavaScript concepts
- click
- dblclick
- mouseenter
- mouseleave
- keydown
- submit
- resize
- preventDefault()

## Run the code
1. Open this lesson folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Open `script.js` and follow the comments from top to bottom.
5. Click the controls in the browser and compare the visible result with the code.

## Practice tasks
1. Add a mouseover listener to the event zone.
2. Listen for the Enter key in the keyboard input.
3. Add a reset button to the form.

## Files
- `index.html` — elements that JavaScript will select and update.
- `styles.css` — visual design and CSS classes.
- `script.js` — JavaScript examples with beginner-friendly comments.
