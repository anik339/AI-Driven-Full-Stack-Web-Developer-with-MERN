# 04. Working with Element Attributes

## What this lesson demonstrates
HTML attributes provide extra information about elements. JavaScript can read them with getAttribute() and change them with setAttribute().

## JavaScript concepts
- HTML attributes
- getAttribute()
- setAttribute()
- element properties
- disabled
- aria-label

## Run the code
1. Open this lesson folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Open `script.js` and follow the comments from top to bottom.
5. Click the controls in the browser and compare the visible result with the code.

## Practice tasks
1. Read the input title attribute.
2. Add an alt attribute to an image element.
3. Set a button's title attribute and check it by hovering.

## Files
- `index.html` — elements that JavaScript will select and update.
- `styles.css` — visual design and CSS classes.
- `script.js` — JavaScript examples with beginner-friendly comments.
