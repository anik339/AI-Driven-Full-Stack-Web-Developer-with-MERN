# 06. Changing Styles with the style Property

## What this lesson demonstrates
JavaScript can update an element's inline CSS through its style property. CSS property names written in JavaScript use camelCase, for example backgroundColor.

## JavaScript concepts
- element.style
- inline CSS
- camelCase CSS properties
- style.backgroundColor
- style.fontSize
- resetting inline styles

## Run the code
1. Open this lesson folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Open `script.js` and follow the comments from top to bottom.
5. Click the controls in the browser and compare the visible result with the code.

## Practice tasks
1. Change the card's padding using JavaScript.
2. Set its boxShadow property.
3. Add a button that changes the card width.

## Files
- `index.html` — elements that JavaScript will select and update.
- `styles.css` — visual design and CSS classes.
