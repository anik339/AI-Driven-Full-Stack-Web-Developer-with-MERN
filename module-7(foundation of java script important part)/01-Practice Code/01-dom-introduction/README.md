# 01. Understanding the DOM

## What this lesson demonstrates
The DOM (Document Object Model) is the browser's object-based representation of an HTML page. JavaScript can read and change this page through the DOM.

## JavaScript concepts
- document object
- DOM tree
- HTML elements as objects
- querySelector()
- textContent
- click event

## Run the code
1. Open this lesson folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Open `script.js` and follow the comments from top to bottom.
5. Click the controls in the browser and compare the visible result with the code.

## Practice tasks
1. Change the paragraph text to your own sentence.
2. Add a second heading and select it with querySelector().
3. Use console.log(document.body) and inspect the result in DevTools.

## Files
- `index.html` — elements that JavaScript will select and update.
- `styles.css` — visual design and CSS classes.
- `script.js` — JavaScript examples with beginner-friendly comments.
