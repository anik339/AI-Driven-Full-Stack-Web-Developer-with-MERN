# 09. Removing Elements with removeChild() and remove()

## What this lesson demonstrates
JavaScript can remove an element from the page. removeChild() is called on the parent and receives the child; remove() is called directly on the element.

## JavaScript concepts
- removeChild()
- remove()
- parentNode
- contains()
- checking before removal
- rebuilding child content

## Run the code
1. Open this lesson folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Open `script.js` and follow the comments from top to bottom.
5. Click the controls in the browser and compare the visible result with the code.

## Practice tasks
1. Remove the third item using remove().
2. Create a new li and then remove it.
3. Explain the difference between parent.removeChild(child) and child.remove().

## Files
- `index.html` — elements that JavaScript will select and update.
- `styles.css` — visual design and CSS classes.
- `script.js` — JavaScript examples with beginner-friendly comments.
