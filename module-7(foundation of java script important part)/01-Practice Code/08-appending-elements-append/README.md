# 08. Appending Elements with append()

## What this lesson demonstrates
append() inserts one or more nodes or text strings at the end of a parent element. It is commonly used after creating new elements with createElement().

## JavaScript concepts
- append()
- parent and child nodes
- multiple arguments
- createElement()
- replaceChildren()

## Run the code
1. Open this lesson folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Open `script.js` and follow the comments from top to bottom.
5. Click the controls in the browser and compare the visible result with the code.

## Practice tasks
1. Append a new heading and paragraph together.
2. Append a text string as well as an element.
3. Create a list and append five list items.

## Files
