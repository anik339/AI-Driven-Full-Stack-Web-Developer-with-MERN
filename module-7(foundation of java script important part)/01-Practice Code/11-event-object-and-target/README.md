# 11. The Event Object and target Property

## What this lesson demonstrates
When an event occurs, the browser passes an Event object to the event handler. event.target identifies the element that originally triggered the event.

## JavaScript concepts
- Event object
- event.target
- event.currentTarget
- closest()
- dataset
- event delegation

## Run the code
1. Open this lesson folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Open `script.js` and follow the comments from top to bottom.
5. Click the controls in the browser and compare the visible result with the code.
