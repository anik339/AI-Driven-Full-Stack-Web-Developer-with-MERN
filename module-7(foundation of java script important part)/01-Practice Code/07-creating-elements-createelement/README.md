# 07. Creating New Elements with createElement()

## What this lesson demonstrates
createElement() creates a new HTML element in memory. You can set its text, attributes, and classes before placing it into the visible page.

## JavaScript concepts
- document.createElement()
- new DOM nodes
- textContent
- classList.add()
- setAttribute()
- element creation

## Run the code
1. Open this lesson folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Open `script.js` and follow the comments from top to bottom.
5. Click the controls in the browser and compare the visible result with the code.

## Practice tasks
1. Create a paragraph instead of an li element.
2. Set a title attribute on the new element.
3. Create a button element and give it a class.

## Files
- `index.html` — elements that JavaScript will select and update.
- `styles.css` — visual design and CSS classes.
- `script.js` — JavaScript examples with beginner-friendly comments.
