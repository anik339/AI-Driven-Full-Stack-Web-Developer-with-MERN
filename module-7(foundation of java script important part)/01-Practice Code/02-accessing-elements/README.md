# 02. Accessing DOM Elements

## What this lesson demonstrates
Learn how to select HTML elements with getElementById(), querySelector(), and querySelectorAll(). These methods let JavaScript find the exact part of the page it needs.

## JavaScript concepts
- getElementById()
- querySelector()
- querySelectorAll()
- NodeList
- forEach()
- CSS selectors

## Run the code
1. Open this lesson folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Open `script.js` and follow the comments from top to bottom.
5. Click the controls in the browser and compare the visible result with the code.

## Practice tasks
1. Select the first button using querySelector('button').
2. Select all paragraphs and change their text one by one.
3. Create a class named highlight and apply it to all list items.

## Files
- `index.html` — elements that JavaScript will select and update.
- `styles.css` — visual design and CSS classes.
- `script.js` — JavaScript examples with beginner-friendly comments.
