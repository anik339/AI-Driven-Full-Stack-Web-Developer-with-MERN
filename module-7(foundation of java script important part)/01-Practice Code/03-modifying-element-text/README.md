# 03. Changing Text with textContent and innerText

## What this lesson demonstrates
Use textContent and innerText to read or update the text inside an element. Both are useful, but innerText reflects visible rendered text while textContent reads text in the DOM.

## JavaScript concepts
- textContent
- innerText
- reading element text
- updating element text
- hidden content

## Run the code
1. Open this lesson folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Open `script.js` and follow the comments from top to bottom.
5. Click the controls in the browser and compare the visible result with the code.

## Practice tasks
1. Change the heading with textContent.
2. Create a hidden paragraph and compare its textContent and innerText.
3. Explain in your own words why hidden DOM text can still be returned by textContent.

## Files
- `index.html` — elements that JavaScript will select and update.
- `styles.css` — visual design and CSS classes.
- `script.js` — JavaScript examples with beginner-friendly comments.
