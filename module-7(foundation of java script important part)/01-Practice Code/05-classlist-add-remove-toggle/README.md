# 05. Adding and Removing Classes with classList

## What this lesson demonstrates
classList provides methods to add, remove, toggle, and check CSS classes. It is a clean way to change an element's appearance without rewriting its full class attribute.

## JavaScript concepts
- classList
- add()
- remove()
- toggle()
- contains()
- CSS state classes

## Run the code
1. Open this lesson folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Open `script.js` and follow the comments from top to bottom.
5. Click the controls in the browser and compare the visible result with the code.

## Practice tasks
1. Add a success class to the card.
2. Create a warning class and toggle it.
3. Use contains() to show whether the card is in dark mode.

## Files
- `index.html` — elements that JavaScript will select and update.
- `styles.css` — visual design and CSS classes.
- `script.js` — JavaScript examples with beginner-friendly comments.
