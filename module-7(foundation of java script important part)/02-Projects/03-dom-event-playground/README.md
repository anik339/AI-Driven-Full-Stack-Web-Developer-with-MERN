# 03. DOM Event Playground

## Project goal
Create an event dashboard that demonstrates mouse, keyboard, form, and window events. The user can inspect event.target and event.currentTarget.

## Features
- Mouse click, double-click, enter, and leave events
- Keyboard keydown events
- Form submit and preventDefault
- Window resize events
- Event target and currentTarget
- Event delegation

## JavaScript concepts used
addEventListener, Event object, event.target, event.currentTarget, closest, classList, window events.

## Run in VS Code
1. Open this project folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Read `script.js` from the first comment. Comments explain the purpose of each important step.
5. Test every button and form before changing the code.

## Project structure
- `index.html` — page structure.
- `styles.css` — responsive styling and visual states.
- `script.js` — application logic and DOM interactions.
