# 01. DOM Profile Card Editor

## Project goal
Build an editable profile card. The form updates visible text, an avatar's accessible attributes, CSS classes, and inline styles.

## Features
- Edit name, role, bio, and profile link
- Generate avatar initials from the name
- Update availability status
- Toggle a dark profile card theme
- Use safe textContent updates and validate the URL

## JavaScript concepts used
querySelector, textContent, getAttribute/setAttribute, classList.toggle, style and form events, URL validation.

## Run in VS Code
1. Open this project folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Read `script.js` from the first comment. Comments explain the purpose of each important step.
5. Test every button and form before changing the code.

## Project structure
- `index.html` — page structure.
- `styles.css` — responsive styling and visual states.
- `script.js` — application logic and DOM interactions.
