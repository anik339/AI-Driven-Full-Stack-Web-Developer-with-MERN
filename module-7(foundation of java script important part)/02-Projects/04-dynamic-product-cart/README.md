# 04. Dynamic Product Cart

## Project goal
Build a small shopping cart interface. JavaScript creates product cards from an array, appends them to the page, and updates cart quantities through event delegation.

## Features
- Generate product cards dynamically
- Add products to the cart
- Increase and decrease quantities
- Remove a cart item or clear the cart
- Calculate item count and total price

## JavaScript concepts used
createElement, append, replaceChildren, event.target, closest, dataset, arrays, find, filter, reduce.

## Run in VS Code
1. Open this project folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Read `script.js` from the first comment. Comments explain the purpose of each important step.
5. Test every button and form before changing the code.

## Project structure
- `index.html` — page structure.
- `styles.css` — responsive styling and visual states.
- `script.js` — application logic and DOM interactions.
