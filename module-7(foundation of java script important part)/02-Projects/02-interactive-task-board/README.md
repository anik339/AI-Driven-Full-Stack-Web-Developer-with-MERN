# 02. Interactive Task Board

## Project goal
Build a task board that lets a user add tasks, mark them complete, filter the list, delete individual tasks, and keep the list after refreshing the browser.

## Features
- Add new tasks using a form
- Complete and delete tasks
- Filter all, active, and completed tasks
- Save tasks in localStorage
- Use event delegation for dynamically created controls

## JavaScript concepts used
createElement, append, remove via data update and rerender, event.target, closest, classList, localStorage, arrays and objects.

## Run in VS Code
1. Open this project folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Read `script.js` from the first comment. Comments explain the purpose of each important step.
5. Test every button and form before changing the code.

## Project structure
- `index.html` — page structure.
- `styles.css` — responsive styling and visual states.
- `script.js` — application logic and DOM interactions.
