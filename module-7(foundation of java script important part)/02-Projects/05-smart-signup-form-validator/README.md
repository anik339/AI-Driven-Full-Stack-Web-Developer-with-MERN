# 05. Smart Signup Form Validator

## Project goal
Build a polished front-end form that validates name, email, password, password confirmation, and a terms checkbox. It demonstrates input and submit events, attributes, classes, styles, and text updates.

## Features
- Validate all required fields
- Show errors beside the correct field
- Display password strength feedback
- Use input, blur, change, and submit events
- Update aria-invalid attributes and CSS classes
- Show a success message without sending data

## JavaScript concepts used
form events, input events, regular expressions, textContent, setAttribute, classList.toggle, style property, arrays and every.

## Run in VS Code
1. Open this project folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. Read `script.js` from the first comment. Comments explain the purpose of each important step.
5. Test every button and form before changing the code.

## Project structure
- `index.html` — page structure.
- `styles.css` — responsive styling and visual states.
- `script.js` — application logic and DOM interactions.
