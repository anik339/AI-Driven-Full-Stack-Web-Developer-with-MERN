Mobile-First and Breakpoints

Build a useful small-screen layout first, then add columns or spacing only when the available space supports them.

Core concepts

  • Viewport: the visible browser area, not the whole physical screen.
  • Mobile-first: base styles target small screens; min-width media queries enhance larger screens.
  • Breakpoint: a width where the layout changes because the content needs more room.
  • Fluid sizing: use percentages, max-width, flexible tracks and responsive type instead of fixed page widths.

Tailwind breakpoint prefixes

<div class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4">
  ...cards...
</div>

sm:, md:, lg: and xl: apply utilities at their breakpoint and above. They are not device detectors.

Test it properly

  1. Start around 320px wide.
  2. Increase the viewport slowly and look for awkward wrapping.
  3. Check navigation, forms, cards, tables and long words.
  4. Test at least one real phone when possible.
  5. Fix the content or layout instead of adding random breakpoints.
