AI Prompts and Code Review

A good prompt states context, constraints, expected output and how the answer should be verified.

Prompt 1: Explain code

Explain this HTML/CSS snippet for a beginner.
Describe the purpose of each important class or property.
Give one simple example and one common mistake.
Do not rewrite the whole file.

Prompt 2: Fix responsive overflow

At a 320px viewport, this page has horizontal scrolling.
Inspect the supplied code and list the likely causes in order.
Suggest the smallest fix first. Preserve the existing design.
Explain how I can test the result at 320px, 375px, 768px and 1280px.

Prompt 3: Review before a pull request

Review this change as a careful teammate.
Check responsive behavior, accessibility, semantic HTML, maintainability,
unused styles and unintended visual changes.
Report findings by severity and point to exact lines.
Do not invent problems. Separate confirmed issues from suggestions.

Verify before accepting AI output

  • Does the code use the requested technologies only?
  • Do all links, image paths and form labels work?
  • Does the layout work on small and large screens?
  • Can you explain why each important change is needed?
  • Did you check the browser console and Git diff?
  • Did you remove secrets, debug leftovers and unused code?
