Module 4 Practice Checklist

Use this list to check your understanding before moving to JavaScript.

Responsive design

  • Explain the viewport and the purpose of the viewport meta tag.
  • Build mobile-first layouts with CSS media queries and Tailwind prefixes.
  • Choose Flexbox or Grid based on the layout problem.
  • Make images, forms, navigation and tables usable on small screens.
  • Test at narrow, medium and wide viewport sizes.

AI-assisted development

  • Write a prompt with context, problem, constraints and expected output.
  • Ask AI to explain code before accepting changes.
  • Review the diff and manually test the generated result.
  • Keep secrets and private information out of prompts.
  • Follow course or team rules for AI assistance and attribution.

GitHub collaboration

  • Explain repository, commit, branch, push, pull and pull request.
  • Create a feature branch and commit one focused change.
  • Open a pull request with a summary and test notes.
  • Review a teammate's code respectfully.
  • Resolve a merge conflict and test the final version.

Ready to move on?

You are ready for the next module when you can build and explain a responsive page, verify AI suggestions, and describe how a feature branch becomes a reviewed pull request. You do not need to memorize every command; learn the workflow and practise it.
