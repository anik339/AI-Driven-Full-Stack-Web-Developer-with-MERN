# Figma design reference

Source provided by the user: **Agency Landing Page Ostad.fig**.

The `.fig` archive contains multiple artboards, including **Dream Agency**, **Agency**, **Landing**, and other landing pages. This implementation uses the **Dream Agency** artboard as the basis for sections, headings, color palette, and relevant embedded imagery.

Original palette interpreted from the Figma nodes:
- Purple/ink: `#331B3B`
- Yellow accent: `#FDC221`
- Pale blue section: `#ECF7FF`

See `figma-artboards-preview.png` for an overview. This preview is very small because the original .fig contains multiple artboards.

> The original `.fig` binary is 50 MB and is not copied into this ZIP. If you want to save it alongside your source code, place your own copy in this folder. GitHub file-size/repository growth is another reason to keep large design binaries separate if not required.
