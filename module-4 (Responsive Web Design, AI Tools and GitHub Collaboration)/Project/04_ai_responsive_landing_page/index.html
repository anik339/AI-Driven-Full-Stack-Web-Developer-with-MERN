A repeatable process

AI supports the developer; it does not replace review.

Understand the issue

Describe the current behavior, expected behavior, viewport size and relevant code.

Make a small change

Ask for the smallest appropriate fix and an explanation of the relevant utilities or CSS rules.

Verify and share

Test mobile and desktop, inspect the diff, then commit and request a peer review.

Quality principles

Build for real people and real screens.

Responsive design includes readable text, usable controls, keyboard access, sensible loading and content that adapts without breaking.

  • Mobile-first: start with the narrow layout and enhance it as space increases.
  • Accessible: use semantic HTML, labels, meaningful alt text and visible focus states.
  • Private: do not paste secrets or private customer data into AI tools.
  • Reviewable: keep changes small and describe them clearly in a pull request.
