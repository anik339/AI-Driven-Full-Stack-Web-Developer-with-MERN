BASIC WORKFLOW

Git Command Workflow 

# Check project status
git status

# Add changes
git add .

# Create a commit
git commit -m "Complete project"

# Connect remote repository
git remote add origin YOUR_GITHUB_URL

# Push changes
git push

# Get latest changes
git pull
