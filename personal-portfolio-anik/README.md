## How to run

1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. The website itself works offline. Optional Google Fonts load when internet is available; otherwise system fonts are used.

## Important note about the contact form

The contact form includes the required Name, Email, and Message fields as a front-end design. It does not send or store messages because no email address or form backend was supplied. The mobile navigation is implemented with CSS only. The contact form is a visual demo; the submit button is intentionally disabled to avoid pretending a message was delivered. All three sample projects are also HTML/CSS-only. The GitHub profile link is provided as the current professional contact link.
