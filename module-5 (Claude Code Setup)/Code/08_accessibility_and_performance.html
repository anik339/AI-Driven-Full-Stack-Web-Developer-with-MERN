LESSON 08 / MODULE 05

Accessibility, SEO and Performance

Check landmarks, descriptions, focus states, headings and image loading.

a11ySEOPerformance
PRACTICE SECTION

A small checklist

These checks improve readability and navigation for more people.

KeyboardTab to every link and button.
ContrastUse readable text colors.
HeadingsKeep H1–H3 in logical order.

CODE EXAMPLE

<html lang="en">
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="description" content="Concise description of this page">
  <title>Unique and descriptive title</title>
</head>

Remember: Run browser Lighthouse and test keyboard-only navigation.

PRACTICE SECTION

Image performance

Reserve layout space and lazy-load below-the-fold images.

CODE EXAMPLE

<img src="cover.webp" alt="Team discussing a website" width="960" height="640" loading="lazy" decoding="async">
Practice task: Try the example, then change one thing and reload the browser.
