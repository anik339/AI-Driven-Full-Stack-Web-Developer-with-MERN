LESSON 07 / MODULE 05

Forms, Labels and Validation

Build clear, accessible forms and understand what native browser validation can and cannot do.

Forms Validation Semantics
PRACTICE SECTION

Accessible form elements

Every input needs an associated label; required marks mandatory input.


Demo form uses GET; do not enter sensitive data.

CODE EXAMPLE 

<form action="/subscribe" method="post">
  <label for="email">Email address</label>
  <input type="email" id="email" name="email" autocomplete="email" required>
  <button type="submit">Subscribe</button>
</form>

Remember: Browser validation is not a substitute for backend validation.

PRACTICE SECTION

Grouping related inputs

Use fieldset and legend for related radio buttons and checkboxes.

CODE EXAMPLE 

<fieldset>
  <legend>Preferred contact</legend>
  <label><input type="radio" name="contact" value="email"> Email</label>
  <label><input type="radio" name="contact" value="phone"> Phone</label>
</fieldset>
Practice task: Try the example, then change one thing and reload the browser.
