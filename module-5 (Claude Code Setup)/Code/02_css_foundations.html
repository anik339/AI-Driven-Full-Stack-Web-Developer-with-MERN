CSS Fundamentals and the Cascade

Learn selectors, reusable classes, inheritance, specificity and readable stylesheets.

SelectorsBox modelSpecificity
PRACTICE SECTION

Three parts of a rule

The selector finds elements; the property names what changes; the value supplies the change.

Reusable classOne declaration can style many cards.

CODE EXAMPLE

/* This class is reused on multiple elements. */
.card { padding: 1.25rem; border: 1px solid #d9e4f0; border-radius: 12px; }
.card h2 { color: #17243c; }
.card:hover { border-color: #355ee8; }

Remember: Prefer classes for component styling; use IDs for unique anchors and labels.

PRACTICE SECTION

Box model and fluid width

Padding is inside the border; margin is outside. Use border-box to make sizes easier to control.

CODE EXAMPLE

*, *::before, *::after { box-sizing: border-box; }
.container { width: min(1100px, calc(100% - 2rem)); margin-inline: auto; }
.box { padding: 1rem; margin-block: 1rem; border: 1px solid #ddd; }

Remember: Avoid fixed page widths that break on phones.

PRACTICE SECTION

Cascade and specificity

In simplified terms, matched rules are resolved by origin/importance, cascade layers, specificity, scoping proximity and source order.

CODE EXAMPLE

p { color: #334155; }
.notice { color: #1d4ed8; } /* More specific than p. */
/* Keep selectors simple; avoid unnecessary !important. */
Practice task: Try the example, then change one thing and reload the browser.
