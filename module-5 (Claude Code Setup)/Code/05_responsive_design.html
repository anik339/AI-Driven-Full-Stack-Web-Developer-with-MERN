PRACTICE SECTION

A responsive pattern

The cards below automatically stack on smaller screens.

Mobile: 1 column
Tablet: 2 columns
Desktop: 3 columns

CODE EXAMPLE

/* Start with a single column. */
.grid { display: grid; grid-template-columns: 1fr; gap: 1rem; }
@media (min-width: 640px) { .grid { grid-template-columns: repeat(2, 1fr); } }
@media (min-width: 1024px) { .grid { grid-template-columns: repeat(3, 1fr); } }

Remember: Test real content at 375px, 768px and 1280px, then test widths in between.

PRACTICE SECTION

Fluid typography and images

Use clamp for responsive fonts and max-width for images.

CODE EXAMPLE

h1 { font-size: clamp(2rem, 5vw, 4.5rem); }
img { display: block; max-width: 100%; height: auto; }
/* Avoid overflow from long words. */
p { overflow-wrap: anywhere; }
Practice task: Try the example, then change one thing and reload the browser.
