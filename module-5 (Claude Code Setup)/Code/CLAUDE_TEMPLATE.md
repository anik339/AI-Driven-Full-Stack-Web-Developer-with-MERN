# Project Instructions

- This project uses semantic HTML5, plain CSS3, and Tailwind CSS v4.
- Do not add custom JavaScript, React, Node.js, or a backend in this module.
- Use short English comments only for major sections.
- Maintain working relative links and accessible form labels.
- Design mobile-first; check layouts at 375px, 768px, and 1280px.
- Explain and review every proposed change before committing.
- Never add API keys, passwords, credentials, or personal data to Git.
- Do not run destructive Git commands or push to remote without approval.
- The Tailwind browser CDN is used for practice, not a production build.
