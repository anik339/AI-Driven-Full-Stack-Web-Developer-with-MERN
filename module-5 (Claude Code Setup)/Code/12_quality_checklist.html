PRACTICE SECTION

GitHub Pages limitations

Static HTML/CSS and the Tailwind Play CDN can be hosted on GitHub Pages. Claude Code is installed on your computer and cannot run inside GitHub Pages.

CODE EXAMPLE

project-folder/
  index.html
  style.css
  assets/
    hero.svg

Remember: Tailwind Play CDN is development-only. For a deployable production build, compile Tailwind using its CLI or Vite integration.

PRACTICE SECTION

What “complete” means

This module prepares frontend layouts and Claude Code workflow. It is not a working backend, authentication system or MERN deployment.

Done when: you can install and sign in to Claude Code, explain how a page works, improve a responsive layout, review a diff and open a pull request.

Practice task: Try the example, then change one thing and reload the browser.
