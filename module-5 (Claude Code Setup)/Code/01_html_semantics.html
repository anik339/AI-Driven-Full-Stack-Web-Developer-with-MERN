LESSON 01 / MODULE 05

HTML Structure and Semantic Sections

Build an accessible page structure before you style anything. Semantics make content easier to navigate, test and maintain.

HTML5LandmarksAccessibility
PRACTICE SECTION

Page landmarks

A header identifies the site, nav holds navigation links, main contains the primary content, and footer provides closing information.

Northstar Studio
Home   About

Welcome to the studio

A simple, meaningful layout.

2026 © Northstar

CODE EXAMPLE

<!doctype html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My First Page</title>
</head>
<body>
  <!-- Site header -->
  <header><h1>Northstar Studio</h1></header>
  <!-- Primary navigation -->
  <nav aria-label="Primary"><a href="#about">About</a></nav>
  <!-- Main page content -->
  <main id="about"><h2>Our work</h2><p>Welcome.</p></main>
  <!-- Footer -->
  <footer><p>Copyright 2026</p></footer>
</body>
</html>

Remember: Use one visible main landmark; headings should form a logical hierarchy.

PRACTICE SECTION

Links and images

Use descriptive link text, meaningful alternative text on informative images, and width/height to reduce layout shift.

CODE EXAMPLE

<a href="https://example.com" target="_blank" rel="noopener noreferrer">Visit project website</a>
<img src="photo.jpg" alt="Student presenting a web app" width="800" height="500" loading="lazy">

Remember: A link navigates; a button performs an action.

Practice task: Try the example, then change one thing and reload the browser.
