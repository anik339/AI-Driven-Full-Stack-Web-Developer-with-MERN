Modern Layout: Flexbox and Grid

Use Flexbox for one-dimensional alignment and Grid for rows and columns.

FlexboxGridGap
PRACTICE SECTION

Flexbox for navigation

Items can align and wrap when space runs out.

HomeProjectsContact

CODE EXAMPLE

.navigation { display: flex; align-items: center; gap: 1rem; flex-wrap: wrap; }
.navigation a { text-decoration: none; }

Remember: Use justify-content for the main axis and align-items for the cross axis.

PRACTICE SECTION

Grid for cards

The minmax pattern fits as many columns as the space allows.

01 / Plan
02 / Design
03 / Build

CODE EXAMPLE

.cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(min(240px, 100%), 1fr)); gap: 1rem; }
