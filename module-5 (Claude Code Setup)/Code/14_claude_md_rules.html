LESSON 14 / MODULE 05

CLAUDE.md and Repository Context

A CLAUDE.md file helps communicate project standards to Claude Code. It does not enforce security policies.

CLAUDE.mdProject contextReview
PRACTICE SECTION

Example project instructions

For a real repository, put a file named CLAUDE.md at the repository root. This ZIP includes a sample at Code/CLAUDE_TEMPLATE.md.

CODE EXAMPLE

# Project Instructions
- This is a static HTML, CSS and Tailwind CSS learning project.
- Prefer semantic HTML and accessible labels.
- Use short English comments only above major sections.
- Do not add React or custom JavaScript yet.
- Ask before installing dependencies or modifying many files.
- Explain each file changed and how to test the result.
- Do not commit secrets, credentials or tokens.

Remember: Keep project guidance brief, specific and up to date.

PRACTICE SECTION

Start with questions

Ask Claude Code to read and summarize the repository before changing it.

CODE EXAMPLE

Summarize this repository and its CLAUDE.md rules.
Identify one small responsive issue that could be improved.
Do not edit any files until I approve the plan.
Practice task: Try the example, then change one thing and reload the browser.
