LESSON 09 / MODULE 05

Claude Code: Install and Sign In

Install the actual Claude Code CLI on Windows or macOS/Linux, verify it and start a project. Reading this file does not install the CLI.

Windows PowerShellAuthenticationCLI
PRACTICE SECTION

Option A — Windows PowerShell

Open PowerShell. Native installer is recommended by Claude Code documentation; review the official URL before running an internet-downloaded script.

CODE EXAMPLE

# Windows PowerShell: native installation
irm https://claude.ai/install.ps1 | iex
# Close and reopen PowerShell, then verify:
claude --version

Remember: This is a command to run manually in PowerShell, not an HTML command.

PRACTICE SECTION

Option B — Windows WinGet

Alternative installation managed through WinGet. WinGet installs must be updated through WinGet.

CODE EXAMPLE

winget install Anthropic.ClaudeCode
claude --version
# Later:
winget upgrade Anthropic.ClaudeCode
PRACTICE SECTION

Option C — macOS, Linux and WSL

Install natively in a Unix-style shell.

CODE EXAMPLE

curl -fsSL https://claude.ai/install.sh | bash
claude --version
PRACTICE SECTION

Start the first session

In VS Code open Terminal > New Terminal in a project directory. Then launch Claude Code and follow the sign-in flow. A compatible plan or API access may be required.

CODE EXAMPLE

# Run these commands inside YOUR project folder.
claude
# In the Claude Code interactive session (as needed):
/login
/help

Remember: Do not share API keys, private tokens, passwords or secrets in prompts. Obtain account access from Anthropic.

PRACTICE SECTION
