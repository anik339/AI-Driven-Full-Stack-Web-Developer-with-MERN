Tailwind CSS: Development vs Production

Practice with the v4 browser CDN now; learn the correct CLI build concept for later production work.

Tailwind v4Build processCLI
PRACTICE SECTION

Practice with a CDN

The v4 browser package works in an HTML file immediately when internet is available.

CODE EXAMPLE

<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
<div class="mx-auto max-w-4xl px-6 py-12 md:py-20">
  <h1 class="text-4xl font-black md:text-6xl">Project title</h1>
</div>
PRACTICE SECTION

Compile for production later

When you work with Node tooling, install Tailwind v4 and its CLI, create an input stylesheet, then generate an output CSS file.

CODE EXAMPLE

npm install -D tailwindcss @tailwindcss/cli
# Create src/input.css containing: @import "tailwindcss";
npx @tailwindcss/cli -i ./src/input.css -o ./dist/output.css --watch

Remember: The command does not automatically build or deploy the projects inside this ZIP.

PRACTICE SECTION

Important separation

Installing Claude Code is unrelated to installing Tailwind. Claude Code can assist with editing files; Tailwind itself is a CSS framework.
