LESSON 06 / MODULE 05

Design Tokens and Reusable Components

Use a consistent palette, spacing scale and component rules rather than random values.

CSS variablesConsistencyComponents
PRACTICE SECTION

CSS custom properties

Tokens provide a single place to change colors or dimensions.

Dark surface
Light accent

CODE EXAMPLE

/* Design tokens are shared across components. */
:root { --brand: #355ee8; --ink: #17243c; --space: 1rem; --radius: 14px; }
.button { background: var(--brand); border-radius: var(--radius); padding: var(--space); }
PRACTICE SECTION

Component states

Provide hover and keyboard focus styles to make controls usable.

CODE EXAMPLE

.button:hover { filter: brightness(.92); }
.button:focus-visible { outline: 3px solid #f1a82d; outline-offset: 3px; }
@media (prefers-reduced-motion: reduce) { *, *::before, *::after { scroll-behavior: auto !important; transition-duration: .01ms !important; } }
Practice task: Try the example, then change one thing and reload the browser.
