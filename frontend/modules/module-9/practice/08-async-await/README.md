# Async/Await and Error Handling

## Learning objective
Write asynchronous operations in a readable sequence and handle failures.

## Key concepts
`async`, `await`, `Promise`, `try/catch/finally`.

## How to practise
1. Open `index.html` with VS Code Live Server.
2. Read `script.js` line by line.
3. Predict the result before interacting with the page.
4. Open DevTools (`F12`) when you need to inspect the Console.

## Challenge
Create two asynchronous functions and run them together with Promise.all().

## Good practice
Use clear names, small functions, semantic HTML, and safe text insertion. Do not put untrusted user input into `innerHTML`.
