# Local Storage and Session Storage

## Learning objective
Save and restore simple browser data using JSON and Web Storage.

## Key concepts
`localStorage`, `sessionStorage`, `JSON.stringify()`, `JSON.parse()`, and storage errors.

## How to practise
1. Open `index.html` with VS Code Live Server.
2. Read `script.js` line by line.
3. Predict the result before interacting with the page.
4. Open DevTools (`F12`) when you need to inspect the Console.

## Challenge
Save an array of three notes as JSON and render them after refreshing the page.

## Good practice
Use clear names, small functions, semantic HTML, and safe text insertion. Do not put untrusted user input into `innerHTML`.
