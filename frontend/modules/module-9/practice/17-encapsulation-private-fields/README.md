# Encapsulation, Private Fields and Accessors

Protect internal state with private fields and expose controlled methods and getters.

## Example
Open `index.html` with VS Code Live Server. The example runs from `script.js` and prints its result on the page and in DevTools Console.

## Expected result
25

## Challenge
Add a `spendPoints()` method that refuses to spend more points than the wallet contains. Try to access `wallet.#points` directly and observe the syntax error.

## Review questions
1. What problem does this concept solve?
2. What would happen if you changed one input or method?
3. Can you explain the example without reading the code?
