# Constructor Functions and Prototypes

Create reusable objects with constructor functions and share methods through the prototype.

## Example
Open `index.html` with VS Code Live Server. The example runs from `script.js` and prints its result on the page and in DevTools Console.

## Expected result
JavaScript is a 4-week course. | Git and GitHub is a 2-week course.

## Challenge
Create a `Student` constructor with name and studentId. Add a shared `introduce()` method to `Student.prototype`. Check `Object.getPrototypeOf(student) === Student.prototype`.
