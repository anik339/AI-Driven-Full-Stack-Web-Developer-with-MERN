# Accessibility and Keyboard Support

## Learning objective
Use semantic controls and provide visible focus and announced updates.

## Key concepts
Semantic HTML, labels, native buttons, `aria-live`, and `:focus-visible`.

## How to practise
1. Open `index.html` with VS Code Live Server.
2. Read `script.js` line by line.
3. Predict the result before interacting with the page.
4. Open DevTools (`F12`) when you need to inspect the Console.

## Challenge
Set a maximum value of 10 and disable the increase button at the limit.

## Good practice
Use clear names, small functions, semantic HTML, and safe text insertion. Do not put untrusted user input into `innerHTML`.
