# Static Methods and Factory Methods

Use static methods for class-level utilities and factory methods for controlled object creation.

## Example
Open `index.html` with VS Code Live Server. The example runs from `script.js` and prints its result on the page and in DevTools Console.

## Expected result
git-github-workflow | valid: true

## Challenge
Create a `Course.fromJSON(data)` static factory method that validates the input and returns a Course instance.

## Review questions
1. What problem does this concept solve?
2. What would happen if you changed one input or method?
3. Can you explain the example without reading the code?
