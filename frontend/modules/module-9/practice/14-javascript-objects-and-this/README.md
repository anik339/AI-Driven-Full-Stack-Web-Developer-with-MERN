# JavaScript Objects, Methods and `this`

Understand object properties, methods, references, and how `this` is determined by the call site.

## Example
Open `index.html` with VS Code Live Server. The example runs from `script.js` and prints its result on the page and in DevTools Console.

## Expected result
Anik is a Junior Developer. | HTML, CSS, JavaScript

## Challenge
Add a `yearsLearning` property and a method that returns a short profile. Then detach a method reference and investigate why `this` behaves differently.

2. What would happen if you changed one input or method?
