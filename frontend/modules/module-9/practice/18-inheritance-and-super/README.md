# Inheritance, `extends` and `super`

Extend a base class, reuse its constructor, and specialize behavior in a child class.

## Example
Open `index.html` with VS Code Live Server. The example runs from `script.js` and prints its result on the page and in DevTools Console.

## Expected result
Anik is a user. Permissions: manage-users, review-content.

## Challenge
Create a `PremiumMember` class extending `Member`. Add one extra property and override one method while calling `super` where appropriate.

## Review questions
1. What problem does this concept solve?
2. What would happen if you changed one input or method?
3. Can you explain the example without reading the code?
