# ES6 Classes, Constructors and Methods

Use class syntax to define object blueprints, initialize instances, and share methods.

## Example
Open `index.html` with VS Code Live Server. The example runs from `script.js` and prints its result on the page and in DevTools Console.

## Expected result
Object-Oriented JavaScript (Intermediate)

## Challenge
Create a `Book` class with title, author, and a `summary()` method. Instantiate two books and call the method on both.

## Review questions
1. What problem does this concept solve?
2. What would happen if you changed one input or method?
3. Can you explain the example without reading the code?
