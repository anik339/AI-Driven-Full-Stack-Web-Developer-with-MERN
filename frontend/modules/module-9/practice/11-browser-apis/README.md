# Useful Browser APIs

## Learning objective
Feature-detect browser capabilities and handle permission failures.

## Key concepts
`navigator.clipboard`, `matchMedia()`, secure contexts, and Promise rejection.

## How to practise
1. Open `index.html` with VS Code Live Server.
2. Read `script.js` line by line.
3. Predict the result before interacting with the page.
4. Open DevTools (`F12`) when you need to inspect the Console.

## Challenge
Add a manual-copy fallback for browsers where Clipboard API access is unavailable.

## Good practice
Use clear names, small functions, semantic HTML, and safe text insertion. Do not put untrusted user input into `innerHTML`.
