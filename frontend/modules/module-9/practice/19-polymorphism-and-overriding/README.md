# Polymorphism and Method Overriding

Call the same method on different object types and let each object provide its own implementation.

## Example
Open `index.html` with VS Code Live Server. The example runs from `script.js` and prints its result on the page and in DevTools Console.

## Expected result
Email sent: Build completed | Console alert: Build completed

## Challenge
Add an `InAppNotifier` with its own `send()` implementation. Run all notifier objects through the same loop without checking their class names.

## Review questions
1. What problem does this concept solve?
2. What would happen if you changed one input or method?
3. Can you explain the example without reading the code?
