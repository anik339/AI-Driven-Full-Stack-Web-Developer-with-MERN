# Practice Lessons

| # | Lesson | Main concepts |
|---|---|---|
| 01 | DOM selection | `querySelector`, `querySelectorAll`, `textContent`, `classList` |
| 02 | Create elements | `createElement`, `append`, `remove`, safe text insertion |
| 03 | Events | `addEventListener`, event object, `preventDefault` |
| 04 | Event delegation | bubbling, `closest`, dynamic lists |
| 05 | Form validation | HTML constraints, custom validity, accessible errors |
| 06 | Web storage | `localStorage`, `sessionStorage`, JSON |
| 07 | Fetch API | `fetch`, HTTP status, JSON, loading and error states |
| 08 | Async/await | Promises, `try`, `catch`, `finally` |
| 09 | ES modules | `export`, `import`, module scope |
| 10 | Accessibility | semantic controls, keyboard support, focus |
| 11 | Browser APIs | Clipboard API, `matchMedia`, feature detection |

For each lesson: read the notes → predict the result → run the page → inspect the code → change one thing → complete the challenge independently.
