## Recommended routine
1. Read the lesson README.
2. For Git lessons, use a separate practice repository such as `git-practice-lab`.
3. Predict each command's effect before running it.
4. For JavaScript lessons, open the lesson `index.html` with Live Server.
5. Inspect the output and browser Console.
6. Complete the challenge without copying.
7. Explain the concept in your own words.

**Important:** The main course repository already has Git history. Never run `git init` inside it for these exercises.
