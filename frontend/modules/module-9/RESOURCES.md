# Module 09 — Git, GitHub, JavaScript and OOP

> Manage code professionally, collaborate through GitHub, and design maintainable JavaScript applications.

## Why this resource library exists
Module 9 has two learning tracks. Use Pro Git and GitHub's official learning paths for version control and collaboration; use MDN for JavaScript's object model and classes.

## Start here — primary resource
- [Pro Git — The Git Book](https://git-scm.com/book/en/v2) — A detailed book covering version control concepts, Git basics, branching, remotes, and distributed workflows.

## Additional trusted resources
- [GitHub Skills](https://skills.github.com/) — Practise pull requests, repositories, Pages, and collaboration through interactive GitHub lessons. *(Interactive practice)*
- [GitHub Docs — Git and GitHub learning resources](https://docs.github.com/en/get-started/start-your-journey/git-and-github-learning-resources) — A curated official starting point for Git basics, GitHub Skills, and further learning. *(Official learning hub)*
- [MDN — Object-oriented programming](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Advanced_JavaScript_objects/Object-oriented_programming) — Learn objects, encapsulation, inheritance, and how OOP concepts apply to JavaScript. *(Official guided lesson)*
- [MDN — Using Classes](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Using_classes) — Understand JavaScript class syntax, constructors, methods, inheritance, and the prototype-based model underneath. *(Language guide)*
- [MDN — Inheritance and the prototype chain](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Inheritance_and_the_prototype_chain) — Go deeper into prototypes, delegation, and JavaScript's object model. *(Advanced reference)*

## Topics to revisit
- Git working tree, staging, commits, history and recovery
- Branches, merging, conflicts, remotes and GitHub collaboration
- Issues, pull requests, reviews and project workflows
- Objects, this, prototypes, classes, encapsulation and inheritance

## Recommended study method
Complete the Git lessons in a separate practice repository, not by experimenting on your main course repository. Then use GitHub Skills for guided collaboration. For OOP, read the MDN lesson and compare each concept with the CodeTrack project classes and services.

1. Open the matching lesson in this module and read the existing comments first.
2. Search for the exact concept in the recommended documentation.
3. Compare the documentation example with the local code; do not copy it blindly.
4. Change one thing, run the page or project, and inspect the browser console.
5. Write a short explanation in your own words so you can understand it again months later.
