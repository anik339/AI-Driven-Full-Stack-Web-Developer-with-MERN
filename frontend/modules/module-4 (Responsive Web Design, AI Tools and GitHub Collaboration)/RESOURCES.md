# Module 04 — Responsive Design, AI Tools and GitHub Collaboration

> Create mobile-first layouts, review AI-assisted changes, and collaborate through GitHub.

## Why this resource library exists
This module combines responsive interface design with practical collaboration habits. Use the resources below to deepen each area without losing the connection to your local projects.

## Start here — primary resource
- [web.dev — Learn Responsive Design](https://web.dev/learn/design) — A focused course on responsive design, media queries, layouts, and adapting interfaces to different screens.

## Additional trusted resources
- [MDN — Responsive Web Design](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design) — Study responsive design principles, flexible layouts, media queries, and viewport adaptation. *(Official guide)*
- [web.dev — Learn Accessibility](https://web.dev/learn/accessibility/) — Improve keyboard access, semantic structure, contrast, and inclusive interface behaviour. *(Guided course)*
- [GitHub Skills](https://skills.github.com/) — Practise pull requests, repositories, Pages, and collaboration through interactive GitHub lessons. *(Interactive practice)*
- [GitHub Docs — Git and GitHub learning resources](https://docs.github.com/en/get-started/start-your-journey/git-and-github-learning-resources) — Find Git basics, GitHub collaboration learning paths, and recommended training. *(Official learning hub)*
- [Claude Code — Overview](https://code.claude.com/docs/en/overview) — See how an AI coding assistant can explore a codebase, edit files, and support development workflows. Module 5 covers setup in more detail. *(Official AI-tool documentation)*

## Topics to revisit
- Mobile-first layouts, viewport and breakpoints
- Flexible images, media queries and responsive testing
- Accessibility and quality checks across screen sizes
- GitHub collaboration, pull requests and careful AI-assisted review

## Recommended study method
Use the responsive-design course while rebuilding your projects at mobile, tablet, and desktop widths. Use GitHub Skills to practise collaboration in a safe learning repository. Review AI-generated changes yourself and run the project before accepting them.

1. Open the matching lesson in this module and read the existing comments first.
2. Search for the exact concept in the recommended documentation.
3. Compare the documentation example with the local code; do not copy it blindly.
4. Change one thing, run the page or project, and inspect the browser console.
5. Write a short explanation in your own words so you can understand it again months later.
