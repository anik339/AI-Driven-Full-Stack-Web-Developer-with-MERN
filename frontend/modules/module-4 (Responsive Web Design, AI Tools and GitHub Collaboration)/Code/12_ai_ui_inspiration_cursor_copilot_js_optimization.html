Cursor, Copilot and AI-assisted frontend workflow

Use AI for inspiration, debugging and optimization while keeping design and code decisions under your control.

Cursor AI editor

Use project-aware chat, code selection, inline edits and codebase questions. Review every diff before accepting changes.

  1. Open the project folder.
  2. Ask it to explain the selected file first.
  3. Request one small change.
  4. Inspect the diff and run the page.

GitHub Copilot

Use inline code completion and chat inside the editor. Treat suggestions as drafts, not verified answers.

  1. Write a clear function name and expected behavior.
  2. Review suggested code line by line.
  3. Test normal, empty and invalid inputs.
  4. Keep only code you understand.

Prompt: generate UI inspiration

Act as a frontend design assistant. Propose three distinct visual directions for a responsive [portfolio / dashboard / landing page].
Target audience: [describe audience].
Brand mood: [describe mood].
Required sections: [list sections].
For each direction, describe layout, typography, color palette, spacing and mobile behavior. Do not copy a named website. Do not write code yet.

Prompt: debug HTML/CSS

Inspect these HTML and CSS files. At viewport [width], [describe actual problem].
First identify the exact cause and relevant selector. Suggest the smallest safe fix. Preserve the current design and semantic HTML. Do not rewrite unrelated files. Give me a test checklist.

Prompt: optimize JavaScript

Review this JavaScript for unnecessary DOM queries, repeated work, inefficient loops, duplicate event listeners and avoidable re-renders.
Do not optimize based on guesswork. Explain the current complexity or repeated work, propose one measurable improvement, preserve behavior, and show how to test before and after.

Before accepting an AI change

  • Check the changed files and Git diff.
  • Run the page at mobile and desktop widths.
  • Check keyboard accessibility and browser Console.
  • Test forms, empty states and invalid inputs.
  • Never paste secrets, passwords or private customer data into prompts.
