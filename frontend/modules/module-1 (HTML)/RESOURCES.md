# Module 01 — HTML Fundamentals

> Structure accessible, semantic web pages with modern HTML.

## Why this resource library exists
Use this library when you need to understand a tag, choose the right semantic element, build a form, or check whether your markup is valid.

## Start here — primary resource
- [MDN — Structuring content with HTML](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content) — A guided learning module covering HTML syntax, document structure, links, lists, images, tables, forms, and skill checks.

## Additional trusted resources
- [MDN — HTML Reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference) — Look up elements, attributes, global attributes, and browser-supported HTML details. *(Official reference)*
- [MDN — Basic HTML syntax](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax) — Review element anatomy, nesting, void elements, and document structure. *(Guided lesson)*
- [W3C — Nu HTML Checker](https://validator.w3.org/nu/) — Validate your HTML and investigate structural or conformance errors. *(Validation tool)*
- [W3C WAI — Tutorials](https://www.w3.org/WAI/tutorials/) — Learn accessible page structure, images, tables, forms, and navigation patterns. *(Accessibility guide)*

## Topics to revisit
- Document structure, tags, attributes and metadata
- Semantic elements, headings, paragraphs, links and lists
- Images, audio/video, tables and forms
- Accessibility, validation and responsive images

## Recommended study method
Start with the MDN HTML module. Use the HTML Reference when you forget an element or attribute. After changing a lesson, run the page through the Nu HTML Checker and fix meaningful errors.

1. Open the matching lesson in this module and read the existing comments first.
2. Search for the exact concept in the recommended documentation.
3. Compare the documentation example with the local code; do not copy it blindly.
4. Change one thing, run the page or project, and inspect the browser console.
5. Write a short explanation in your own words so you can understand it again months later.
