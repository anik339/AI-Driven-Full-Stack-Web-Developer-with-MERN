When you get stuck — follow this method

Follow the v3 documentation for this repository. First check the local package.json and config, then compare the matching v3 docs. Do not copy v4-only setup instructions into this v3 project without intentionally upgrading and testing it.

  1. Read the relevant local lesson and its code comments.
  2. Open the matching topic in the primary documentation.
  3. Compare the official example with your own code.
  4. Make one small change, run it, and inspect the result.
  5. Explain the concept in your own words before moving on.
