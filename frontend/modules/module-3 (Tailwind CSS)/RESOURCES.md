## Recommended study method
Follow the v3 documentation for this repository. First check the local package.json and config, then compare the matching v3 docs. Do not copy v4-only setup instructions into this v3 project without intentionally upgrading and testing it.

1. Open the matching lesson in this module and read the existing comments first.
2. Search for the exact concept in the recommended documentation.
3. Compare the documentation example with the local code; do not copy it blindly.
4. Change one thing, run the page or project, and inspect the browser console.
5. Write a short explanation in your own words so you can understand it again months later.
