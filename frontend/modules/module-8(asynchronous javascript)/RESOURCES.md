# Module 08 — Advanced and Asynchronous JavaScript

> Understand scope, closures, modern syntax, promises, Fetch, async/await, and the event loop.

## Why this resource library exists
This is the deeper JavaScript reference set for the module's 19 lessons and five projects. Use MDN for browser APIs and language behaviour, and JavaScript.info for conceptual explanations.

## Start here — primary resource
- [MDN — Asynchronous JavaScript](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Async_JS) — A structured learning module covering asynchronous programming, promises, and promise-based APIs.

## Additional trusted resources
- [MDN — How to use Promises](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Async_JS/Promises) — Learn promise states, chaining, error handling, combining promises, and async/await. *(Guided lesson)*
- [MDN — Using the Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch) — Understand requests, responses, JSON, HTTP errors, request options, and handling fetch results. *(Web API guide)*
- [JavaScript.info — Event Loop](https://javascript.info/event-loop) — Understand tasks, microtasks, timers, and how browser JavaScript execution is scheduled. *(In-depth tutorial)*
- [MDN — JavaScript Guide: Promises](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Using_promises) — Use the language guide for promise concepts and links to related reference entries. *(Language guide)*

## Topics to revisit
- Scope, lexical environment, closures and hoisting
- Destructuring, spread/rest, modules and array methods
- Promises, async/await, try/catch and Fetch
- Web Storage, event loop, microtasks and macrotasks

## Recommended study method
First understand the concept in the local lesson, then read the matching MDN article. For Fetch projects, inspect the Network and Console tabs in DevTools. Test both success and failure paths; public demo APIs can be rate-limited or temporarily unavailable.

1. Open the matching lesson in this module and read the existing comments first.
2. Search for the exact concept in the recommended documentation.
3. Compare the documentation example with the local code; do not copy it blindly.
4. Change one thing, run the page or project, and inspect the browser console.
5. Write a short explanation in your own words so you can understand it again months later.
