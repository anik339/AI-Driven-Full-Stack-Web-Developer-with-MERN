MODULE 02 · CSS SUPPLEMENTARY

CSS Units: px, em, rem, %, vw, vh and fr

Compare fixed, font-relative, parent-relative, viewport-relative and Grid fractional units.

24px — fixed CSS pixels

1.5em — relative to the parent font size

1.5rem — relative to the root font size

70% width — relative to the containing block
50vw width — relative to viewport width
20vh height — relative to viewport height

fr unit in CSS Grid

1fr
2fr
1fr

The available grid space is divided into four fractions: 1 + 2 + 1.

.em { font-size: 1.5em; }
.rem { font-size: 1.5rem; }
.percent { width: 70%; }
.vw { width: 50vw; }
.vh { min-height: 20vh; }
.fr-grid { display: grid; grid-template-columns: 1fr 2fr 1fr; }
