CSS Transform: Translate, Scale, Rotate and Skew

Compare the four common 2D transform functions and see how transform-origin changes the result.

Translate

Move
translate(12px, -8px)

Scale

Resize
scale(1.08)

Rotate

Turn

Skew

Slant

Hover each shape. Transform changes visual rendering without changing the normal document flow.

.shape:hover { transform: translate(12px, -8px) scale(1.05) rotate(4deg) skew(-5deg); }
.shape { transform-origin: center; transition: transform .25s ease; }
