# Module 06 — JavaScript Fundamentals

> Build a strong foundation in JavaScript syntax, data, control flow, functions, arrays, and objects.

## Why this resource library exists
Use these resources to revisit the 28 beginner topics in this module, check exact language behaviour, and move from examples to independent coding.

## Start here — primary resource
- [MDN — JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) — A comprehensive, regularly updated guide covering grammar, types, control flow, functions, arrays, objects, classes, promises, modules, and advanced topics.

## Additional trusted resources
- [MDN — JavaScript Reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference) — Look up exact syntax and behaviour for operators, statements, built-in objects, functions, and APIs. *(Official reference)*
- [JavaScript.info — The Modern JavaScript Tutorial](https://javascript.info/) — A detailed tutorial with explanations and examples, from language basics through objects and browser programming. *(In-depth tutorial)*
- [MDN — Dynamic Scripting with JavaScript](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting) — Bridge the fundamentals into browser scripting, DOM work, and interactive pages. *(Guided course)*

## Topics to revisit
- Variables, data types, operators and conditions
- Loops, functions, parameters and return values
- Objects, arrays, strings, dates and math
- Reading errors, using the console and writing small programs

## Recommended study method
Use the local 28-topic lessons as your hands-on workbook. Read the matching JavaScript Guide section, then close the example and recreate it from memory. Use the Reference when you need exact behaviour or syntax.

1. Open the matching lesson in this module and read the existing comments first.
2. Search for the exact concept in the recommended documentation.
3. Compare the documentation example with the local code; do not copy it blindly.
4. Change one thing, run the page or project, and inspect the browser console.
5. Write a short explanation in your own words so you can understand it again months later.
