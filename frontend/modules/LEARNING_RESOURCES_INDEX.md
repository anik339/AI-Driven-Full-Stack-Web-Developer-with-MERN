## How to use this library

1. Start with the primary resource listed at the top of the module page.
2. Use the additional references when you need exact syntax, another explanation, or deeper coverage.
3. Compare documentation examples with the local lessons and projects in this repository.
4. Test changes locally and explain the concept in your own words.
5. For versioned tools, follow the version used by the local project. Module 03 intentionally links to Tailwind CSS v3 documentation because its supplied package uses Tailwind CSS 3.4.x.

The external resources are official documentation, guided learning courses, or established references. Websites may update their content or URLs over time.
