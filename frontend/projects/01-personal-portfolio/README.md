# Project 01 — Anik Chandra Dey Personal Portfolio

A responsive personal portfolio built with HTML5, CSS3, and vanilla JavaScript. It introduces Anik Chandra Dey, a CSE student at American International University-Bangladesh (AIUB), and links to the four other frontend projects in this pack.

## Included sections
- Introduction and profile photo
- About, skills, and current learning journey
- Links to all five projects in this pack
- Contact form validation with a `mailto:` handoff
- GitHub profile link (no LinkedIn link is shown)
- Responsive mobile navigation and saved light/dark theme
